# 📌 1. Що роблять cp, mv і rm

У Linux команди `cp`, `mv` і `rm` використовуються для керування файлами та директоріями.

| Команда | Призначення | Англійське значення |
|---|---|---|
| `cp` | Копіювати файли та директорії | Copy |
| `mv` | Переміщувати або перейменовувати | Move |
| `rm` | Видаляти файли та директорії | Remove |

## ✔ Приклади

    cp notes.txt notes-copy.txt

Створює копію файла `notes.txt` під назвою `notes-copy.txt`.

    mv notes.txt documents/

Переміщує `notes.txt` у директорію `documents/`.

    mv old-name.txt new-name.txt

Перейменовує файл `old-name.txt` на `new-name.txt`.

    rm notes-copy.txt

Видаляє файл `notes-copy.txt`.

## 🎯 Що важливо

- `cp` створює копію, залишаючи оригінал.
- `mv` переміщує об'єкт або змінює його назву.
- `rm` видаляє об'єкт.
- Для копіювання та видалення директорій часто потрібні спеціальні опції.
- Команди виконуються відносно поточної директорії, якщо шлях не вказаний повністю.
- Видалення через `rm` зазвичай не переміщує файли до кошика.

# 📌 2. Основні поняття

## 2.1. Файл і директорія

Файл містить дані, наприклад текст, програмний код або зображення.

Директорія містить записи про файли та інші директорії.

Приклад структури:

    projects/
    ├── notes.txt
    ├── report.txt
    └── documents/
        └── lesson.txt

Тут:

- `projects/` — директорія.
- `notes.txt` — файл.
- `documents/` — вкладена директорія.
- `lesson.txt` — файл усередині `documents/`.

## 2.2. Джерело та призначення

У командах копіювання й переміщення потрібно розрізняти два поняття:

- **Джерело (source)** — об'єкт, з яким працюємо.
- **Призначення (destination)** — місце або назва, куди копіюємо чи переміщуємо об'єкт.

Загальний принцип:

    command source destination

Наприклад:

    cp notes.txt backup.txt

- Джерело: `notes.txt`.
- Призначення: `backup.txt`.

## 2.3. Поточна директорія

Дізнатися поточну директорію можна командою:

    pwd

Подивитися її вміст:

    ls

Перейти до іншої директорії:

    cd documents

Команди `cp`, `mv` та `rm` використовують поточну директорію для інтерпретації відносних шляхів.

## 2.4. Чи потрібно використовувати sudo?

Зазвичай команди виконують від звичайного користувача.

    cp notes.txt backup.txt
    mv draft.txt final.txt
    rm temporary.txt

`sudo` потрібен лише тоді, коли операція вимагає прав адміністратора, наприклад для роботи з деякими системними файлами.

Не використовуй `sudo` автоматично: воно може дозволити змінювати або видаляти важливі системні дані.

# 📌 3. Команда cp — копіювання

## 3.1. Синтаксис

Загальний синтаксис:

    cp [опції] джерело призначення

`cp` створює копію файла або директорії.

## 3.2. Копіювання файла під новою назвою

    cp notes.txt notes-copy.txt

Якщо `notes.txt` існує, команда створить `notes-copy.txt` з його вмістом.

Оригінал залишиться на місці.

Приклад:

    ls

    notes.txt

Виконуємо:

    cp notes.txt backup.txt

Тепер:

    ls

    backup.txt  notes.txt

## 3.3. Копіювання файла в іншу директорію

    cp notes.txt documents/

Файл `notes.txt` буде скопійований у директорію `documents/`.

Результат:

    documents/
    └── notes.txt

Якщо файл має залишитися з іншою назвою:

    cp notes.txt documents/notes-backup.txt

Результат:

    documents/
    └── notes-backup.txt

## 3.4. Копіювання кількох файлів

Можна скопіювати кілька файлів в одну директорію.

    cp notes.txt report.txt summary.txt documents/

Усі три файли будуть скопійовані до `documents/`.

Загальний синтаксис:

    cp файл1 файл2 файл3 директорія/

**Важливо:** коли вказано кілька джерел, останній аргумент має бути директорією.

## 3.5. Копіювання з підтвердженням перезапису — `-i`

Опція `-i` означає interactive.

    cp -i notes.txt backup.txt

Якщо `backup.txt` уже існує, команда запитає підтвердження перед перезаписом.

Приклад запиту:

    cp: overwrite 'backup.txt'?

Можна підтвердити або відмовитися.

- `y` — погодитися.
- `n` — відмовитися.

Це корисно, коли потрібно захистити наявні файли від випадкового перезапису.

## 3.6. Копіювання з повідомленням — `-v`

Опція `-v` означає verbose.

    cp -v notes.txt backup.txt

Приклад результату:

    'notes.txt' -> 'backup.txt'

Команда показує, які операції виконує.

Для кількох файлів:

    cp -v notes.txt report.txt documents/

Це зручно під час навчання та роботи з великою кількістю файлів.

## 3.7. Копіювання з рекурсією — `-r`

Звичайний `cp` не копіює директорії так само, як звичайні файли.

Для копіювання директорії використовують `-r` або `-R`.

    cp -r documents documents-backup

Буде створена копія директорії `documents` з її вмістом.

Наприклад, якщо структура початково така:

    documents/
    ├── notes.txt
    └── lessons/
        └── linux.txt

Після команди:

    cp -r documents documents-backup

Отримаємо:

    documents-backup/
    ├── notes.txt
    └── lessons/
        └── linux.txt

Опція `-r` дозволяє копіювати вкладені директорії та їхній вміст.

## 3.8. Копіювання зі збереженням атрибутів — `-p`

Опція `-p` намагається зберегти важливі атрибути файла:

- час останньої модифікації;
- час останнього доступу;
- права доступу;
- власника та групу — якщо дозволяють права користувача.

Приклад:

    cp -p notes.txt backup.txt

Для директорії:

    cp -rp documents documents-backup

Для більш повного збереження атрибутів часто використовують `-a`.

## 3.9. Архівне копіювання — `-a`

Опція `-a` означає archive.

    cp -a documents documents-backup

Вона призначена для копіювання директорій зі збереженням структури та атрибутів, зокрема символічних посилань.

`-a` особливо корисна для резервних копій.

Порівняння:

    cp -r documents documents-copy

    cp -a documents documents-backup

- `-r` — рекурсивне копіювання вмісту.
- `-a` — архівне копіювання зі збереженням більшої кількості атрибутів.

Для звичайної практики достатньо спочатку добре засвоїти `cp` і `cp -r`.

## 3.10. Копіювання без перезапису — `-n`

Опція `-n` означає no-clobber.

    cp -n notes.txt backup.txt

Якщо `backup.txt` уже існує, команда не повинна його перезаписувати.

Це корисно, коли потрібно зберегти попередню версію файла.

**Застереження:** поведінка деяких опцій може залежати від реалізації та версії утиліти. На Ubuntu використовується GNU `cp`.

## 3.11. Копіювання та перезапис

Якщо файл призначення вже існує, звичайна команда `cp` може перезаписати його вміст.

    cp new-notes.txt notes.txt

Якщо `notes.txt` існує, його вміст може бути замінений вмістом `new-notes.txt`.

Для безпечнішої роботи використовуй:

    cp -i new-notes.txt notes.txt

Або перевіряй наявність файла заздалегідь:

    ls -l notes.txt

## ✔ Основні опції cp

| Опція | Призначення |
|---|---|
| `-i` | Запитувати підтвердження перед перезаписом |
| `-v` | Показувати виконувані операції |
| `-r` | Рекурсивно копіювати директорії |
| `-R` | Рекурсивне копіювання |
| `-p` | Зберігати основні атрибути |
| `-a` | Архівне копіювання зі збереженням атрибутів |
| `-n` | Не перезаписувати наявні файли |
| `-u` | Копіювати, якщо джерело новіше за призначення або призначення відсутнє |

Приклад використання кількох опцій:

    cp -iv notes.txt backup.txt

Команда показуватиме операцію та запитуватиме підтвердження перед перезаписом.

# 📌 4. Команда mv — переміщення та перейменування

## 4.1. Синтаксис

Загальний синтаксис:

    mv [опції] джерело призначення

Команда `mv` використовується для:

- переміщення файлів;
- переміщення директорій;
- перейменування файлів;
- перейменування директорій.

## 4.2. Перейменування файла

    mv old-name.txt new-name.txt

Файл `old-name.txt` буде перейменований на `new-name.txt`.

До цього він існував під старою назвою, а після операції — під новою.

Перевірити результат:

    ls

## 4.3. Переміщення файла в директорію

    mv notes.txt documents/

Файл `notes.txt` переміститься до директорії `documents/`.

Після успішного переміщення він більше не буде лежати в початковій директорії.

## 4.4. Переміщення з одночасним перейменуванням

    mv notes.txt documents/linux-notes.txt

Команда перемістить файл `notes.txt` до `documents/` і назве його `linux-notes.txt`.

Це поєднання двох операцій:

1. Переміщення в іншу директорію.
2. Зміна назви файла.

## 4.5. Перейменування директорії

    mv old-folder new-folder

Директорія `old-folder` буде перейменована на `new-folder`.

Якщо потрібно перемістити директорію в інше місце:

    mv documents backup/

Тут `documents` переміщується до наявної директорії `backup/`.

## 4.6. Переміщення кількох файлів

    mv notes.txt report.txt summary.txt documents/

Усі зазначені файли будуть переміщені до `documents/`.

Як і в `cp`, якщо джерел кілька, останній аргумент має бути директорією.

## 4.7. Переміщення з підтвердженням — `-i`

Опція `-i` запитує підтвердження, якщо операція може перезаписати наявний файл.

    mv -i draft.txt final.txt

Якщо `final.txt` уже існує, команда запитає, чи потрібно його замінити.

Це допомагає уникнути випадкової втрати даних.

## 4.8. Переміщення без перезапису — `-n`

    mv -n draft.txt final.txt

Якщо файл `final.txt` уже існує, команда не повинна його перезаписувати.

Використовуй цю опцію, коли важливо зберегти попередній файл.

## 4.9. Повідомлення про операцію — `-v`

    mv -v notes.txt documents/

Приклад результату:

    renamed 'notes.txt' -> 'documents/notes.txt'

Точний текст повідомлення може відрізнятися залежно від версії системи та виду операції.

## 4.10. Переміщення лише новіших файлів — `-u`

    mv -u notes.txt backup/

Опція `-u` дозволяє переміщувати файл, якщо призначення відсутнє або джерело новіше за наявне призначення.

Це спеціальніша опція. Для початкового рівня достатньо запам'ятати `mv`, `mv -i` та `mv -v`.

## 4.11. Що відбувається під час переміщення?

У межах однієї файлової системи переміщення зазвичай виконується зміною записів про розташування файла.

Між різними файловими системами `mv` може виконати копіювання з подальшим видаленням початкового файла.

Тому переміщення не завжди є миттєвим.

## ✔ Основні опції mv

| Опція | Призначення |
|---|---|
| `-i` | Запитувати підтвердження перед перезаписом |
| `-n` | Не перезаписувати наявні файли |
| `-v` | Показувати виконувані операції |
| `-u` | Переміщувати, якщо джерело новіше або призначення відсутнє |

# 📌 5. Команда rm — видалення

## ⚠️ Важливо

`rm` — команда, з якою потрібно бути особливо уважним.

Зазвичай вона видаляє файли без переміщення до графічного кошика.

Відновлення видалених даних може бути складним або неможливим.

Перед виконанням команди завжди перевіряй:

- поточну директорію;
- правильність шляху;
- назви файлів;
- використані опції;
- чи справді потрібно видалити ці дані.

## 5.1. Синтаксис

    rm [опції] файл

Наприклад:

    rm temporary.txt

Файл `temporary.txt` буде видалений.

## 5.2. Видалення кількох файлів

    rm notes.txt draft.txt temporary.txt

Команда видалить усі три файли, якщо вони існують і користувач має достатні права.

## 5.3. Видалення з підтвердженням — `-i`

    rm -i temporary.txt

Команда запитає підтвердження перед видаленням.

Приклад:

    rm: remove regular file 'temporary.txt'?

Підтверджуй видалення лише тоді, коли впевнений у правильності вибору.

Для кількох файлів:

    rm -i notes.txt draft.txt

## 5.4. Примусове видалення — `-f`

Опція `-f` означає force.

    rm -f temporary.txt

Вона прибирає запити підтвердження та ігнорує відсутні файли.

**Не використовуй `-f` без потреби.**

Наприклад:

    rm -f file1.txt file2.txt

Команда не запитуватиме підтвердження. Якщо файли існують і доступні для видалення, вони будуть видалені.

Особливо небезпечно поєднувати `-f` з рекурсивним видаленням.

## 5.5. Видалення директорії — `-r`

Звичайна команда `rm` не видаляє непорожню директорію.

Для рекурсивного видалення використовують `-r` або `-R`.

    rm -r old-folder

Команда видалить директорію `old-folder` разом із її вмістом.

Наприклад:

    old-folder/
    ├── notes.txt
    └── lessons/
        └── linux.txt

Після:

    rm -r old-folder

директорія та всі її вкладені файли й директорії будуть видалені.

**Перед використанням `rm -r` перевіряй шлях особливо уважно.**

## 5.6. Видалення директорії з підтвердженням

    rm -ri old-folder

Опція `-i` запитуватиме підтвердження під час рекурсивного видалення.

Це безпечніше для навчання, хоча для великої кількості файлів може бути незручно.

## 5.7. Видалення без зайвих повідомлень — `-f`

    rm -rf old-folder

Ця команда рекурсивно видаляє `old-folder` і намагається не запитувати підтвердження.

**Це одна з найризикованіших комбінацій для початківця.**

Не запускай її, якщо не можеш чітко пояснити:

- що саме видаляється;
- з якої директорії виконується команда;
- як інтерпретуються всі зазначені шляхи;
- чи немає помилки в назві.

Під час навчання віддавай перевагу:

    ls -la old-folder

    rm -ri old-folder

## 5.8. Видалення порожньої директорії

Для видалення порожньої директорії краще використовувати `rmdir`.

    rmdir empty-folder

`rmdir` видаляє тільки порожні директорії.

Якщо директорія містить файли, команда повідомить про помилку.

Це зручно, коли потрібно уникнути випадкового видалення вмісту.

## 5.9. Чи можна скасувати rm?

Звичайна команда `rm` не має вбудованої функції скасування.

Якщо файл був видалений:

    rm notes.txt

не можна просто виконати команду на кшталт:

    undo rm

Такої стандартної команди немає.

Тому перед видаленням важливих даних варто створити резервну копію.

## ✔ Основні опції rm

| Опція | Призначення |
|---|---|
| `-i` | Запитувати підтвердження перед видаленням |
| `-r` | Рекурсивно видаляти директорії та їхній вміст |
| `-R` | Рекурсивне видалення |
| `-f` | Не запитувати підтвердження та ігнорувати відсутні файли |
| `-v` | Показувати, що видаляється |

Приклад:

    rm -iv temporary.txt

Команда показуватиме операцію та запитуватиме підтвердження.

# 📌 6. Робота з директоріями

## 6.1. Копіювання директорії

    cp -r source-folder destination-folder

Якщо `destination-folder` не існує, команда створить його як копію `source-folder`.

Якщо `destination-folder` уже існує, результат залежить від того, як саме задані шляхи та структура директорій.

Щоб уникнути плутанини, перевіряй результат командою:

    ls -la

## 6.2. Переміщення директорії

    mv source-folder destination/

Переміщує `source-folder` усередину наявної директорії `destination/`.

## 6.3. Перейменування директорії

    mv source-folder new-folder

Змінює назву директорії `source-folder` на `new-folder`, якщо призначення не створює конфлікту.

## 6.4. Видалення директорії

Порожня директорія:

    rmdir old-folder

Непорожня директорія:

    rm -r old-folder

Видалення з підтвердженням:

    rm -ri old-folder

## 6.5. Копіювання директорії з прихованими файлами

Якщо скопіювати директорію командою:

    cp -r project project-backup

то буде скопійовано вміст директорії `project`, включно з прихованими файлами, що входять до неї.

Наприклад:

    project/
    ├── .gitignore
    ├── README.md
    └── src/
        └── app.js

Копія міститиме `.gitignore`, `README.md` та `src/`.

При цьому приховані файли не показуються звичайною командою `ls`.

Для перевірки використовуй:

    ls -la project-backup

# 📌 7. Відносні та абсолютні шляхи

Команди `cp`, `mv` і `rm` працюють із відносними й абсолютними шляхами.

## 7.1. Відносний шлях

Відносний шлях задається відносно поточної директорії.

Наприклад, поточна директорія:

    /home/taubu/projects

Команда:

    cp notes.txt backup.txt

означає копіювання:

    /home/taubu/projects/notes.txt

у:

    /home/taubu/projects/backup.txt

## 7.2. Абсолютний шлях

Абсолютний шлях починається з `/`.

    cp /home/taubu/projects/notes.txt /home/taubu/backup.txt

Така команда не залежить від того, у якій директорії ти перебуваєш.

## 7.3. Використання `..`

`..` означає батьківську директорію.

Приклад структури:

    projects/
    ├── notes.txt
    └── backups/

Якщо поточна директорія — `backups/`, можна виконати:

    cp ../notes.txt notes-copy.txt

Файл буде скопійований із батьківської директорії в поточну.

## 7.4. Видалення за відносним шляхом

    rm ../temporary.txt

Ця команда видалить `temporary.txt` із батьківської директорії.

Перед виконанням перевір:

    pwd

    ls -l ../temporary.txt

Не покладайся лише на назву файла: важливо знати його точне розташування.

# 📌 8. Спеціальні символи та шаблони

Shell дозволяє використовувати шаблони, щоб працювати з групами файлів.

## 8.1. Символ `*`

`*` відповідає послідовності символів у назві файла.

Наприклад:

    cp *.txt backup/

Скопіює всі файли з розширенням `.txt` у директорію `backup/`, якщо такі файли є в поточній директорії.

Ще приклади:

    ls *.js

    cp report*.txt backup/

    mv draft*.md drafts/

Будь уважним: шаблон може відповідати більшій кількості файлів, ніж очікується.

## 8.2. Символ `?`

`?` відповідає одному символу.

    ls file?.txt

Може знайти:

    file1.txt
    file2.txt
    fileA.txt

Але не відповідає `file10.txt`, оскільки перед `.txt` там два символи.

## 8.3. Видалення за шаблоном

Наприклад:

    rm *.tmp

Видалить усі файли, що відповідають шаблону `*.tmp` у поточній директорії.

Перед видаленням перевір список:

    ls *.tmp

Якщо відповідних файлів немає, shell зазвичай передасть шаблон без змін, а `rm` повідомить про помилку. Точна поведінка залежить від налаштувань shell.

**Безпечний принцип:** спочатку переглянь список файлів, а потім виконуй команду видалення.

## 8.4. Файли з пробілами в назвах

Якщо назва містить пробіли, використовуй лапки.

    cp "my notes.txt" "my notes backup.txt"

Переміщення:

    mv "final report.txt" documents/

Видалення:

    rm -i "old notes.txt"

Без лапок shell може сприйняти частини назви як окремі аргументи.

## 8.5. Екранування символів

Можна використовувати зворотну косу риску `\`, щоб екранувати пробіл.

    cp my\ notes.txt backup.txt

Але лапки зазвичай зручніші:

    cp "my notes.txt" backup.txt

# 📌 9. Безпечна робота з файлами

## 9.1. Перевіряй поточну директорію

Перед важливими операціями:

    pwd

    ls -la

Це допомагає переконатися, що команда виконується в потрібному місці.

## 9.2. Перевіряй джерело та призначення

Перед копіюванням:

    ls -l notes.txt

Перед переміщенням:

    ls -ld documents/

Перед видаленням:

    ls -l temporary.txt

Якщо йдеться про директорію:

    ls -la old-folder/

## 9.3. Використовуй інтерактивні опції

Для копіювання:

    cp -i source.txt destination.txt

Для переміщення:

    mv -i source.txt destination.txt

Для видалення:

    rm -i temporary.txt

Для рекурсивного видалення:

    rm -ri old-folder

Ці опції особливо корисні, коли ти ще вивчаєш Linux.

## 9.4. Не плутай cp і mv

Копіювання:

    cp notes.txt backup.txt

Результат: два файли.

Переміщення або перейменування:

    mv notes.txt backup.txt

Результат: файл із новою назвою, якщо операція успішна, а старої назви більше немає.

## 9.5. Не плутай rm і rmdir

    rm file.txt

Видаляє файл.

    rmdir empty-folder

Видаляє порожню директорію.

    rm -r folder

Видаляє директорію разом із вмістом.

## 9.6. Особлива увага до rm -rf

Комбінація:

    rm -rf directory/

може видалити багато файлів без підтвердження.

Перед виконанням таких команд перевіряй шлях, поточну директорію та список вмісту.

Не запускай команди видалення, якщо не розумієш, які саме шляхи вони охоплюють.

## 9.7. Резервне копіювання

Перед зміною або видаленням важливих файлів можна створити копію.

    cp -i config.json config.backup.json

Для директорії:

    cp -a project project-backup

Після цього перевір результат:

    ls -la project-backup

Пам'ятай, що резервна копія в тій самій директорії або на тому самому диску не захищає від усіх можливих втрат даних.

# 📌 10. Типові помилки

## ❌ Помилка 1. Копіювання директорії без `-r`

Команда:

    cp project project-backup

Може завершитися помилкою, якщо `project` — директорія.

Правильно:

    cp -r project project-backup

Або, для збереження атрибутів:

    cp -a project project-backup

## ❌ Помилка 2. Переміщення файла в неіснуючу директорію

Команда:

    mv notes.txt documents/

Якщо `documents/` не існує, `mv` може сприйняти `documents/` як нову назву файла.

Тому спочатку перевір:

    ls -ld documents/

Якщо директорія існує, команда перемістить файл усередину неї.

## ❌ Помилка 3. Видалення непорожньої директорії без `-r`

Команда:

    rm documents/

Не видалить непорожню директорію звичайним способом.

Для порожньої директорії:

    rmdir documents/

Для непорожньої:

    rm -r documents/

Використовуй рекурсивне видалення лише тоді, коли впевнений у результаті.

## ❌ Помилка 4. Випадковий перезапис файла

Команда:

    cp new.txt existing.txt

може замінити вміст `existing.txt`.

Безпечніший варіант:

    cp -i new.txt existing.txt

## ❌ Помилка 5. Пробіли в назві без лапок

Неправильно:

    cp my notes.txt backup.txt

Shell сприйме `my`, `notes.txt` і `backup.txt` як окремі аргументи.

Правильно:

    cp "my notes.txt" backup.txt

## ❌ Помилка 6. Неправильний шлях

Команда:

    rm ../notes.txt

видаляє файл із батьківської директорії, а не з поточної.

Перевір:

    pwd

    ls -l ../notes.txt

## ❌ Помилка 7. Очікування, що rm перемістить файл до кошика

Команда:

    rm notes.txt

зазвичай видаляє файл без використання графічного кошика.

Якщо потрібно перемістити файл до кошика, використовуй відповідну команду або інструмент, який підтримує кошик.

## ❌ Помилка 8. Надмірне використання sudo

Не потрібно виконувати всі команди через `sudo`.

Звичайна робота у власній директорії:

    cp notes.txt backup.txt

    mv draft.txt final.txt

    rm -i temporary.txt

Якщо виникає помилка доступу, спочатку з'ясуй її причину.

## ❌ Помилка 9. Використання rm -rf без перевірки

Небезпечна команда:

    rm -rf *

Вона може видалити всі об'єкти, які відповідають шаблону `*` у поточній директорії, якщо користувач має необхідні права.

Перед видаленням перевір:

    pwd

    ls -la

Для навчання краще працювати з конкретними назвами файлів і директорій.

# 📌 13. Рівні вивчення

## 🟢 Core — базові навички

Ти повинен уміти:

- копіювати один файл за допомогою `cp`;
- переміщувати файл за допомогою `mv`;
- перейменовувати файл;
- видаляти файл за допомогою `rm`;
- переглядати результат через `ls`;
- перевіряти поточну директорію через `pwd`;
- використовувати відносні та абсолютні шляхи;
- застосовувати `-i` для підтвердження.

## 🟡 Junior — упевнена робота

Ти повинен уміти:

- копіювати директорії за допомогою `cp -r`;
- створювати резервні копії за допомогою `cp -a`;
- переміщувати кілька файлів;
- видаляти директорії за допомогою `rm -r`;
- відрізняти `rm` від `rmdir`;
- використовувати `-v`, `-n` та `-u`;
- працювати з шаблонами `*` і `?`;
- правильно обробляти пробіли в назвах файлів;
- перевіряти результати операцій.

## 🔵 Middle — практична робота з проєктами

Ти повинен розуміти:

- як копіювання впливає на структуру проєкту;
- чому важливо зберігати приховані файли;
- для чого потрібні архівні копії;
- чим відрізняється переміщення в межах однієї файлової системи від переміщення між різними файловими системами;
- як права доступу впливають на операції;
- як уникати випадкового перезапису;
- як безпечно видаляти непотрібні файли та директорії.

## 🟣 Senior — додаткові теми

Пізніше можна вивчити:

- резервне копіювання великих структур;
- поведінку символічних і жорстких посилань під час копіювання;
- атрибути файлів і права доступу;
- взаємодію `cp`, `mv`, `rm` із файловими системами;
- використання `rsync` для синхронізації та резервного копіювання;
- пошук файлів за допомогою `find`;
- сценарії Bash для автоматизації роботи з файлами.

На початковому етапі достатньо впевнено володіти `cp`, `mv`, `rm`, `ls`, `pwd` і `mkdir`.

# 📌 14. Мінішпаргалка

## Копіювання — cp

    cp file.txt copy.txt

Скопіювати файл під новою назвою.

    cp file.txt documents/

Скопіювати файл у директорію.

    cp file1.txt file2.txt documents/

Скопіювати кілька файлів у директорію.

    cp -r project project-copy

Скопіювати директорію рекурсивно.

    cp -a project project-backup

Скопіювати директорію зі збереженням атрибутів.

    cp -i file.txt copy.txt

Запитати підтвердження перед перезаписом.

    cp -v file.txt copy.txt

Показати виконувану операцію.

## Переміщення та перейменування — mv

    mv old.txt new.txt

Перейменувати файл.

    mv file.txt documents/

Перемістити файл у директорію.

    mv file.txt documents/new-name.txt

Перемістити файл і змінити його назву.

    mv old-folder new-folder

Перейменувати директорію.

    mv -i file.txt destination.txt

Запитати підтвердження перед перезаписом.

    mv -v file.txt documents/

Показати виконувану операцію.

## Видалення — rm

    rm file.txt

Видалити файл.

    rm -i file.txt

Запитати підтвердження.

    rm -r folder

Рекурсивно видалити директорію та її вміст.

    rm -ri folder

Видаляти директорію з підтвердженням.

    rm -f file.txt

Видалити без запитів підтвердження та ігнорувати відсутній файл.

    rmdir empty-folder

Видалити порожню директорію.

## Перевірка

    pwd

Показати поточну директорію.

    ls -la

Переглянути всі файли, включно з прихованими.

    ls -l file.txt

Перевірити конкретний файл.

    ls -la folder/

Переглянути вміст директорії.

# 📌 15. Головне, що потрібно запам'ятати

✔ `cp` — копіює файли та директорії.

✔ `mv` — переміщує або перейменовує файли та директорії.

✔ `rm` — видаляє файли.

✔ `cp -r` — копіює директорії рекурсивно.

✔ `cp -a` — копіює директорії зі збереженням важливих атрибутів.

✔ `rm -r` — видаляє директорію разом із вмістом.

✔ `rmdir` — видаляє тільки порожні директорії.

✔ `-i` — допомагає уникати випадкового перезапису або видалення.

✔ `-v` — показує виконувані операції.

✔ `-n` — допомагає не перезаписувати наявні файли.

✔ `pwd` і `ls -la` — корисні команди для перевірки перед операціями.

✔ `rm` зазвичай не використовує кошик, тому видалення потрібно виконувати уважно.

✔ Перед рекурсивним видаленням перевіряй шлях і вміст директорії.

✔ Для важливих даних створюй резервні копії.

## 🎯 Підсумок

Для початкового рівня Linux найважливіше впевнено виконувати п'ять основних операцій:

    cp notes.txt backup.txt

    mv draft.txt final.txt

    rm -i temporary.txt

    cp -r project project-copy

    rm -ri old-folder

Запам'ятай простий принцип:

- **Копіювати** — `cp`.
- **Переміщувати або перейменовувати** — `mv`.
- **Видаляти** — `rm`.
- **Перевіряти результат** — `ls -la`.
- **Перевіряти своє розташування** — `pwd`.

Спочатку практикуйся на тестових файлах у власній навчальній директорії. Коли команди стануть зрозумілими, переходь до роботи зі структурою реальних проєктів.

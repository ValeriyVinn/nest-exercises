# 04. wc, sort, uniq — підрахунок, сортування та унікальні значення

`wc`, `sort` і `uniq` — це команди Linux для обробки текстових даних у терміналі.

Вони особливо корисні під час роботи з файлами, логами, списками, результатами інших команд і даними, які потрібно підрахувати, впорядкувати або очистити від повторень.

- `wc` — підраховує рядки, слова, байти та символи.
- `sort` — сортує рядки за алфавітом, числовим значенням або іншими правилами.
- `uniq` — знаходить або видаляє сусідні повторювані рядки.

Ці команди часто використовують разом із каналами `|`, щоб послідовно обробляти дані без створення проміжних файлів.

## ✔ Основні поняття

- `wc file.txt` — підрахунок рядків, слів і байтів.
- `wc -l` — підрахунок рядків.
- `wc -w` — підрахунок слів.
- `wc -c` — підрахунок байтів.
- `wc -m` — підрахунок символів.
- `sort file.txt` — сортування рядків.
- `sort -n` — числове сортування.
- `sort -r` — сортування у зворотному порядку.
- `sort -u` — сортування з видаленням повторів.
- `sort -k` — сортування за певним полем.
- `sort -t` — визначення роздільника полів.
- `uniq` — обробка сусідніх однакових рядків.
- `uniq -c` — підрахунок кількості повторень сусідніх рядків.
- `uniq -d` — показ лише повторюваних рядків.
- `uniq -u` — показ лише рядків, що не повторюються.
- `sort file.txt | uniq` — отримання унікальних рядків.
- `sort file.txt | uniq -c` — підрахунок частоти кожного значення після сортування.

    mkdir -p ~/linux-practice/wc-sort-uniq

    cat > fruits.txt <<'EOF'
    apple
    banana

    apple
    mango
    banana
    apple
    EOF

Перевіримо вміст:

Результат:

    apple
    banana
    orange
    apple
    mango
    banana
    apple

Цей файл використовуватимемо для практики підрахунку, сортування та пошуку повторень.

## 2. Команда `wc` — підрахунок тексту

`wc` означає *word count*. Команда підраховує кількість рядків, слів і байтів або символів у тексті.

Загальний синтаксис:

    wc [OPTIONS] [FILE...]

### 2.1. Базовий підрахунок

Виконай:

    wc fruits.txt

Приклад результату:

    7  7  47 fruits.txt

Тут:

- `7` — кількість рядків;
- `7` — кількість слів;
- `47` — кількість байтів;
- `fruits.txt` — назва файлу.

Точна кількість байтів залежить від вмісту файла та символів, які в ньому записані.

Якщо команда отримує дані зі стандартного введення, назва файла не відображається:

    cat fruits.txt | wc

Однак для простого підрахунку одного файла краще передавати його безпосередньо команді `wc`.

### 2.2. Підрахунок рядків — `-l`

Параметр `-l` показує кількість рядків:

    wc -l fruits.txt

Результат:

    7 fruits.txt

Це один із найчастіше використовуваних варіантів `wc`.

Приклади:

    wc -l app.log
    wc -l users.txt
    wc -l package.json

Можна рахувати рядки в результатах інших команд:

    grep "ERROR" app.log | wc -l

Команда підрахує, скільки рядків вивів `grep`.

**Важливо:** `wc -l` рахує символи нового рядка, а не абстрактні логічні записи. Тому файл, що містить один рядок без завершального символу нового рядка, може дати результат `0`.

### 2.3. Підрахунок слів — `-w`

Параметр `-w` підраховує слова:

    wc -w fruits.txt

У нашому файлі кожен рядок містить одне слово, тому результат буде:

    7 fruits.txt

Приклад для звичайного тексту:

    printf 'Linux is powerful and flexible\n' | wc -w

Результат:

    5

`wc` визначає слова за розділенням пробільними символами. Це не повноцінний лінгвістичний аналіз тексту.

### 2.4. Підрахунок байтів — `-c`

Параметр `-c` показує кількість байтів:

    wc -c fruits.txt

Байти — це одиниці зберігання даних. Вони не завжди дорівнюють кількості символів.

Наприклад, у UTF-8 англійська літера `A` займає один байт, а українська літера `і` зазвичай займає два байти.

    printf 'A\n' | wc -c
    printf 'і\n' | wc -c

Типовий результат:

    2
    3

До підрахунку входить і символ нового рядка `\n`, який займає один байт.

### 2.5. Підрахунок символів — `-m`

Параметр `-m` підраховує символи відповідно до поточної локалі:

    printf 'Привіт\n' | wc -m

У типовому UTF-8 середовищі результат буде:

    7

Це шість літер і символ нового рядка.

Порівняй:

    printf 'Привіт\n' | wc -c
    printf 'Привіт\n' | wc -m

Перша команда рахує байти, друга — символи.

**Запам'ятай:**

- `-c` — bytes;
- `-m` — characters.

Для українського тексту ця різниця особливо важлива.

### 2.6. Підрахунок найдовшого рядка — `-L`

У GNU `wc` параметр `-L` показує довжину найдовшого рядка в символах:

    wc -L fruits.txt

Це може бути корисно для перевірки текстових файлів, логів і форматованих списків.

Зверни увагу: `-L` є розширенням GNU, тому на деяких інших Unix-системах його підтримка може відрізнятися.

### 2.7. Комбінування параметрів

Можна поєднувати декілька параметрів:

    wc -lw fruits.txt

Команда покаже кількість рядків і слів.

Інші приклади:

    wc -lc fruits.txt
    wc -wm fruits.txt

Якщо потрібен тільки один показник, краще використовувати відповідний параметр окремо.

### 2.8. Підрахунок декількох файлів

Команда може приймати кілька файлів:

    wc -l fruits.txt technologies.txt

Результат міститиме кількість рядків у кожному файлі та загальну суму.

Це зручно, коли потрібно швидко порівняти розмір кількох текстових файлів.

## 3. Команда `sort` — сортування рядків

`sort` сортує рядки тексту за заданими правилами.

Загальний синтаксис:

    sort [OPTIONS] [FILE...]

### 3.1. Звичайне сортування

Виконай:

    sort fruits.txt

Результат:

    apple
    apple
    apple
    banana
    banana
    mango
    orange

За замовчуванням `sort` сортує рядки відповідно до правил поточної локалі.

**Важливо:** звичайне сортування тексту не завжди означає сортування за числовим значенням.

### 3.2. Сортування у зворотному порядку — `-r`

Параметр `-r` змінює порядок сортування на зворотний:

    sort -r fruits.txt

Результат:

    orange
    mango
    banana
    banana
    apple
    apple
    apple

Це зручно для зворотного алфавітного порядку.

### 3.3. Сортування без урахування регістру — `-f`

Параметр `-f` дозволяє сортувати без урахування регістру для літер, які підтримуються поточною локаллю:

    printf 'banana\nApple\napple\nOrange\n' | sort -f

Це допомагає уникнути розділення слів на групи через великі й малі літери.

Результат може дещо залежати від локалі системи.

### 3.4. Числове сортування — `-n`

Створимо файл `numbers.txt`:

    printf '100\n20\n3\n45\n' > numbers.txt

Звичайне сортування:

    sort numbers.txt

Текстовий порядок може відрізнятися від числового, наприклад:

    100
    20
    3
    45

Для сортування за числовим значенням використовуй `-n`:

    sort -n numbers.txt

Результат:

    3
    20
    45
    100

**Запам'ятай:** якщо рядки містять числа, а потрібен числовий порядок, використовуй `sort -n`.

### 3.5. Числове сортування у зворотному порядку

Можна поєднувати параметри:

    sort -nr numbers.txt

Результат:

    100
    45
    20
    3

Це корисно для сортування значень від найбільшого до найменшого.

### 3.6. Сортування з видаленням повторів — `-u`

Параметр `-u` сортує рядки й залишає лише унікальні значення:

    sort -u fruits.txt

Результат:

    apple
    banana
    mango
    orange

Це короткий спосіб отримати унікальні рядки без окремого виклику `uniq`.

Порівняй:

    sort fruits.txt | uniq

І:

    sort -u fruits.txt

Для типового текстового пошуку обидва варіанти часто дають однаковий результат.

### 3.7. Запис результату у файл

Щоб зберегти відсортований список:

    sort fruits.txt > fruits-sorted.txt

Перевір:

    cat fruits-sorted.txt

Оригінальний `fruits.txt` не зміниться.

**Обережно:** оператор `>` перезаписує цільовий файл, якщо він уже існує.

Не використовуй такий варіант бездумно:

    sort fruits.txt > fruits.txt

Оболонка може очистити файл до того, як `sort` прочитає його.

Для сортування на місці в GNU/Linux можна використовувати `sort -o`:

    sort -o fruits.txt fruits.txt

Ця команда записує результат у вказаний файл. Проте для навчання безпечніше спочатку створювати окремий файл результату.

## 4. Сортування за певним полем — `-k`

Файли часто містять не одне значення в рядку, а декілька полів.

Створимо `scores.txt`:

    cat > scores.txt <<'EOF'
    Anna 85
    Petro 72
    Olena 96
    Ivan 78
    EOF

Кожен рядок містить ім'я та бал.

### 4.1. Сортування за першим полем

Параметр `-k` визначає поле сортування:

    sort -k1 scores.txt

Команда сортує записи за першим полем — іменем.

### 4.2. Сортування за другим полем

Щоб сортувати за балом:

    sort -k2,2n scores.txt

Тут:

- `-k2,2` — використовувати друге поле як ключ сортування;
- `n` — сортувати це поле числовим способом.

Результат:

    Petro 72
    Ivan 78
    Anna 85
    Olena 96

Щоб відсортувати від найбільшого бала до найменшого:

    sort -k2,2nr scores.txt

Результат:

    Olena 96
    Anna 85
    Ivan 78
    Petro 72

### 4.3. Чому важливо задавати межі поля

Запис `-k2,2n` явно вказує, що ключем є тільки друге поле.

Це робить команду зрозумілішою й допомагає уникати несподіваних результатів, коли в рядках є додаткові поля.

### 4.4. Сортування за роздільником — `-t`

За замовчуванням `sort` визначає поля за пробільними символами.

Якщо дані розділені комами, можна задати роздільник через `-t`.

Створимо CSV-подібний файл:

    cat > products.csv <<'EOF'
    keyboard,1200
    mouse,450
    monitor,8500
    headphones,2300
    EOF

Сортуємо за другою колонкою числовим способом:

    sort -t ',' -k2,2n products.csv

Результат:

    mouse,450
    keyboard,1200
    headphones,2300
    monitor,8500

Тут:

- `-t ','` — роздільник полів кома;
- `-k2,2` — друге поле;
- `n` — числове сортування.

**Важливо:** це просте сортування рядків CSV. Воно не є повноцінним CSV-парсером і не враховує складні випадки, наприклад коми всередині лапок.

## 5. Команда `uniq` — робота з повтореннями

`uniq` призначена для виявлення або обробки сусідніх однакових рядків.

Загальний синтаксис:

    uniq [OPTIONS] [INPUT [OUTPUT]]

Головна особливість: **`uniq` зазвичай обробляє тільки сусідні повторення**.

### 5.1. Базове використання

Виконай:

    uniq fruits.txt

Результат:

    apple
    banana
    orange
    apple
    mango
    banana
    apple

На перший погляд нічого не змінилося. Це тому, що однакові рядки у файлі не розташовані поруч.

`uniq` не шукає всі повторення в усьому файлі незалежно від їхнього розташування.

### 5.2. Приклад із сусідніми повтореннями

Створимо файл:

    cat > repeated.txt <<'EOF'
    apple
    apple
    apple
    banana
    banana
    orange
    apple
    EOF

Виконай:

    uniq repeated.txt

Результат:

    apple
    banana
    orange
    apple

Сусідні повторення `apple` і `banana` скорочуються до одного рядка.

Але останній `apple` залишається, оскільки він не сусідній із першою групою `apple`.

### 5.3. Чому `sort` часто використовують разом із `uniq`

Щоб знайти всі унікальні значення незалежно від початкового порядку, спочатку потрібно згрупувати однакові рядки:

    sort fruits.txt | uniq

Результат:

    apple
    banana
    mango
    orange

Спочатку `sort` розташовує однакові значення поруч, потім `uniq` прибирає повторення.

Це одна з найважливіших комбінацій Linux:

    sort file.txt | uniq

### 5.4. Підрахунок повторень — `uniq -c`

Параметр `-c` показує кількість рядків у кожній групі сусідніх повторень:

    sort fruits.txt | uniq -c

Приклад результату:

    3 apple
    2 banana
    1 mango
    1 orange

Тепер можна побачити, скільки разів кожне значення зустрічається у файлі.

**Зверни увагу:** у цьому прикладі `sort` потрібен, щоб згрупувати однакові фрукти перед підрахунком.

### 5.5. Показати тільки повторювані рядки — `-d`

Параметр `-d` показує лише рядки, що повторюються в межах сусідніх груп.

    sort fruits.txt | uniq -d

Результат:

    apple
    banana

Це зручно для пошуку дублікатів у списках.

### 5.6. Показати тільки неповторювані рядки — `-u`

Параметр `-u` у `uniq` має інше значення, ніж у `sort`.

    sort fruits.txt | uniq -u

Результат:

    mango
    orange

`uniq -u` показує лише рядки, які зустрічаються один раз у відповідній групі.

Порівняй:

- `sort -u` — сортує й залишає унікальні значення, тобто по одному екземпляру кожного значення;
- `uniq -u` — показує лише значення, які не повторюються.

Це важлива різниця, яку часто запитують на співбесідах.

### 5.7. Показати всі рядки, що повторюються, разом із кількістю

    sort fruits.txt | uniq -c | sort -nr

Результат:

    3 apple
    2 banana
    1 orange
    1 mango

Команда складається з трьох етапів:

1. `sort fruits.txt` — групує однакові значення.
2. `uniq -c` — рахує кількість кожного значення.
3. `sort -nr` — сортує кількість за спаданням.

Якщо кількість однакова, порядок таких рядків залежить від додаткових правил сортування.

### 5.8. Ігнорування регістру — `uniq -i`

Параметр `-i` дозволяє не враховувати регістр під час порівняння рядків:

    printf 'Apple\napple\nAPPLE\nbanana\n' | sort -f | uniq -i

Це дає змогу об'єднувати рядки, які відрізняються лише регістром, за умови що вони розташовані поруч.

Для стабільної обробки такого списку часто зручно поєднувати `sort -f` і `uniq -i`.

**Примітка:** правила порівняння тексту можуть залежати від локалі системи.

## 6. Важлива різниця між `sort -u` та `uniq -u`

Ці команди легко переплутати, але вони виконують різні завдання.

Нехай є файл:

    cat > colors.txt <<'EOF'
    red
    blue
    red
    green
    blue
    yellow
    EOF

### `sort -u`

    sort -u colors.txt

Результат:

    blue
    green
    red
    yellow

Команда сортує дані й залишає по одному екземпляру кожного значення.

### `sort | uniq -u`

    sort colors.txt | uniq -u

Результат:

    green
    yellow

Команда залишає тільки значення, які зустрілися один раз.

### Порівняння

| Команда | Результат |
|---|---|
| `sort file.txt` | Відсортовані рядки, включно з повторами |
| `sort -u file.txt` | Відсортовані унікальні значення |
| `uniq file.txt` | Прибирає сусідні повторення |
| `sort file.txt \| uniq` | Прибирає повторення після сортування |
| `sort file.txt \| uniq -c` | Підраховує кількість кожного значення |
| `sort file.txt \| uniq -d` | Показує значення, які повторюються |
| `sort file.txt \| uniq -u` | Показує значення, які зустрічаються лише один раз |

## 7. Комбінування `wc`, `sort` і `uniq`

Справжня користь цих команд розкривається під час спільного використання.

### 7.1. Порахувати кількість рядків у файлі

    wc -l fruits.txt

### 7.2. Отримати унікальні значення

    sort -u fruits.txt

### 7.3. Порахувати кількість кожного значення

    sort fruits.txt | uniq -c

### 7.4. Відсортувати значення за частотою

    sort fruits.txt | uniq -c | sort -nr

### 7.5. Знайти найчастіше значення

    sort fruits.txt | uniq -c | sort -nr | head -n 1

Ця команда виводить рядок із найбільшою кількістю повторень.

### 7.6. Порахувати кількість унікальних рядків

    sort -u fruits.txt | wc -l

Або:

    sort fruits.txt | uniq | wc -l

### 7.7. Порахувати кількість рядків, які повторюються

    sort fruits.txt | uniq -d | wc -l

Це рахує кількість різних значень, що повторюються, а не загальну кількість усіх зайвих копій.

Наприклад, якщо `apple` зустрічається тричі, `uniq -d` виведе `apple` один раз.

### 7.8. Порахувати всі рядки, що містять певне слово

    grep "ERROR" app.log | wc -l

Це поєднання вже вивчених команд `grep` і `wc`.

### 7.9. Знайти найчастіші повідомлення в логах

    grep "ERROR" app.log | sort | uniq -c | sort -nr | head -n 10

Послідовність:

1. `grep` відбирає рядки з помилками.
2. `sort` групує однакові повідомлення.
3. `uniq -c` підраховує кількість повторень.
4. `sort -nr` сортує за кількістю.
5. `head -n 10` показує перші десять результатів.

Це простий спосіб знайти найчастіші повідомлення в текстовому журналі.

## 8. Використання разом із `grep`

`grep` відбирає рядки за шаблоном, `sort` упорядковує їх, а `uniq` обробляє повторення.

Наприклад, знайдемо унікальні повідомлення про помилки:

    grep "ERROR" app.log | sort -u

Порахуємо кількість кожного типу помилок:

    grep "ERROR" app.log | sort | uniq -c

Відсортуємо помилки за частотою:

    grep "ERROR" app.log | sort | uniq -c | sort -nr

Порахуємо кількість рядків із попередженнями:

    grep "WARNING" app.log | wc -l

**Практичне правило:** спочатку відфільтруй потрібні дані, потім сортуй, після цього групуй або підраховуй.

## 9. Обробка списків файлів

Ці команди корисні не лише для звичайного тексту, а й для списків назв файлів.

Наприклад, знайдемо всі файли `.js` у поточному каталозі та підкаталогах:

    find . -type f -name "*.js"

Порахуємо кількість таких файлів:

    find . -type f -name "*.js" | wc -l

Знайдемо кількість файлів для кожного розширення в простому списку:

    find . -type f | grep -E "\.[^./]+$" | sort | uniq -c

Остання команда приблизно групує назви за їхніми розширеннями, але фактично рахує повні рядки, а не витягує розширення. Тому вона не дасть коректної статистики за розширеннями, якщо файли мають різні назви.

Для пошуку файлів певного типу надійніше використовувати `find`:

    find . -type f -name "*.ts"
    find . -type f -name "*.tsx"
    find . -type f -name "*.css"

Для початкового навчання важливо розуміти, що `wc`, `sort` і `uniq` обробляють текстовий потік, а не структуру файлової системи.

## 10. Сортування чисел і форматованих даних

### 10.1. Числа в окремих рядках

Створимо `numbers.txt`:

    printf '9\n100\n25\n3\n' > numbers.txt

Числове сортування:

    sort -n numbers.txt

Зворотне числове сортування:

    sort -nr numbers.txt

### 10.2. Сортування за розміром файлів

Якщо команда `ls -l` виводить список файлів із розмірами, можна спробувати сортування за відповідним полем:

    ls -l | sort -k5,5n

Це простий навчальний приклад, але для роботи зі списками файлів краще враховувати особливості формату виводу `ls`.

Для сортування файлів за розміром практичніше використовувати спеціалізовані параметри `find` або `du`.

### 10.3. Сортування чисел у рядках із текстом

Для файла:

    cat > users-scores.txt <<'EOF'
    Anna 85
    Petro 72
    Olena 96
    Ivan 78
    EOF

Сортуємо за балами:

    sort -k2,2n users-scores.txt

Сортуємо за балами від найбільшого до найменшого:

    sort -k2,2nr users-scores.txt

Такі операції корисні для простих таблиць і текстових звітів.

## 11. Стандартне введення, виведення та перенаправлення

`wc`, `sort` і `uniq` можуть читати дані не лише з файла, а й зі стандартного введення.

### 11.1. Передача через канал

    printf 'banana\napple\norange\n' | sort

Результат:

    apple
    banana
    orange

### 11.2. Запис у файл

    sort fruits.txt > sorted.txt

### 11.3. Додавання результату в кінець файла

    sort fruits.txt >> sorted-history.txt

Різниця:

- `>` — створює або перезаписує файл;
- `>>` — додає результат у кінець файла.

### 11.4. Комбінований приклад

    sort fruits.txt | uniq -c > fruit-counts.txt

Переглянь результат:

    cat fruit-counts.txt

Так можна створювати невеликі текстові звіти без написання окремого скрипту.

## 12. Типові помилки

### 12.1. Очікувати, що `uniq` знайде всі повторення без сортування

Команда:

    uniq fruits.txt

не об'єднує однакові рядки, розташовані в різних частинах файла.

Щоб знайти повторення в усьому списку:

    sort fruits.txt | uniq

### 12.2. Плутати `sort -u` та `uniq -u`

- `sort -u` залишає по одному екземпляру кожного значення.
- `uniq -u` залишає тільки значення, які не повторюються в межах сусідніх груп.

Приклади:

    sort -u fruits.txt
    sort fruits.txt | uniq -u

Результати будуть різними.

### 12.3. Сортувати числа як текст

Команда:

    sort numbers.txt

не обов'язково впорядкує числа за їхнім числовим значенням.

Правильний варіант:

    sort -n numbers.txt

### 12.4. Плутати байти та символи

Команди:

    wc -c file.txt
    wc -m file.txt

можуть показувати різні результати, особливо для українського тексту в UTF-8.

### 12.5. Вважати, що `wc -l` рахує всі видимі рядки незалежно від завершення файла

`wc -l` рахує символи нового рядка. Якщо останній рядок не закінчується символом нового рядка, результат може бути меншим за очікувану кількість текстових рядків.

### 12.6. Випадково перезаписати файл

Небезпечно:

    sort file.txt > file.txt

Для навчання використовуй інший файл:

    sort file.txt > sorted.txt

### 12.7. Сприймати `sort -k2,2n` як універсальний парсер таблиць

`sort` працює з текстовими полями, а не з повноцінною структурою CSV чи бази даних.

Якщо дані складні, містять лапки, роздільники всередині значень або багаторядкові поля, краще використовувати відповідний інструмент.

## 17. Мінішпаргалка

    # Порахувати рядки
    wc -l file.txt

    # Порахувати слова
    wc -w file.txt

    # Порахувати байти
    wc -c file.txt

    # Порахувати символи
    wc -m file.txt

    # Показати довжину найдовшого рядка (GNU wc)
    wc -L file.txt

    # Сортувати рядки
    sort file.txt

    # Зворотне сортування
    sort -r file.txt

    # Числове сортування
    sort -n numbers.txt

    # Числове сортування за спаданням
    sort -nr numbers.txt

    # Сортувати й прибрати повторення
    sort -u file.txt

    # Сортувати за другим полем числовим способом
    sort -k2,2n file.txt

    # Сортувати за другим полем у зворотному числовому порядку
    sort -k2,2nr file.txt

    # Задати роздільник полів
    sort -t ',' -k2,2n products.csv

    # Прибрати сусідні повторення
    uniq file.txt

    # Порахувати сусідні повторення
    uniq -c file.txt

    # Показати повторювані рядки
    uniq -d file.txt

    # Показати рядки, які зустрічаються один раз
    uniq -u file.txt

    # Знайти всі унікальні рядки
    sort file.txt | uniq

    # Порахувати кількість кожного значення
    sort file.txt | uniq -c

    # Відсортувати значення за частотою
    sort file.txt | uniq -c | sort -nr

    # Показати десять найчастіших значень
    sort file.txt | uniq -c | sort -nr | head -n 10

    # Порахувати кількість рядків із помилками
    grep "ERROR" app.log | wc -l

    # Зберегти відсортований результат у файл
    sort file.txt > sorted.txt

    # Додати результат у кінець файла
    sort file.txt >> sorted-history.txt

## 18. Головне, що потрібно запам'ятати

- `wc` підраховує рядки, слова, байти та символи.
- `wc -l` рахує символи нового рядка, а не просто візуальні рядки тексту.
- `wc -c` рахує байти, а `wc -m` — символи.
- `sort` упорядковує рядки; для чисел зазвичай потрібен `sort -n`.
- `sort -u` сортує дані й залишає по одному екземпляру кожного значення.
- `uniq` зазвичай працює лише із сусідніми однаковими рядками.
- `sort file.txt | uniq` — стандартний спосіб отримати унікальні значення.
- `uniq -c` рахує кількість рядків у кожній групі повторень.
- `uniq -d` показує повторювані рядки, а `uniq -u` — ті, що не повторюються.
- `sort -k` дозволяє сортувати за полями.
- Канал `|` об'єднує команди в послідовний конвеєр обробки даних.
- Оператори `>` і `>>` дозволяють записувати результати у файли.

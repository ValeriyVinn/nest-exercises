# 05. cut, paste, tr — вибір полів, об'єднання тексту та перетворення символів

`cut`, `paste` і `tr` — це стандартні утиліти Linux для обробки тексту в терміналі.

Вони дозволяють витягувати окремі частини рядків, об'єднувати дані з різних джерел і перетворювати символи без відкривання файлів у текстовому редакторі.

- `cut` — вибирає символи, байти або поля з кожного рядка.
- `paste` — об'єднує рядки з декількох файлів у спільний результат.
- `tr` — перетворює, видаляє або стискає послідовності символів.

Ці команди особливо корисні для обробки CSV-подібних файлів, списків, логів, результатів інших команд і простих текстових даних.

## ✔ Основні поняття

- `cut -c` — вибір символів за позицією.
- `cut -b` — вибір байтів.
- `cut -d` — визначення роздільника полів.
- `cut -f` — вибір полів.
- `cut -f1,3` — вибір першого та третього полів.
- `cut -f2-` — вибір другого поля й усіх наступних.
- `paste` — об'єднання рядків із декількох файлів.
- `paste -d` — визначення роздільника між полями.
- `paste -s` — об'єднання рядків одного файла в один рядок.
- `tr 'a-z' 'A-Z'` — перетворення малих літер на великі.
- `tr -d` — видалення заданих символів.
- `tr -s` — стискання повторюваних символів.
- `tr -c` — операція над символами, які не входять до заданого набору.
- `|` — передавання результату однієї команди іншій.
- `>` — запис результату у файл із перезаписуванням.
- `>>` — додавання результату в кінець файла.

## 1. Підготовка робочого каталогу

Створи каталог для практики:

    mkdir -p ~/linux-practice/cut-paste-tr
    cd ~/linux-practice/cut-paste-tr

Створимо файл `users.txt`:

    cat > users.txt <<'EOF'
    1:Valeriy:developer:Ukraine
    2:Anna:designer:Poland
    3:Petro:tester:Germany
    4:Olena:developer:Ukraine
    EOF

Перевір його вміст:

    cat users.txt

Результат:

    1:Valeriy:developer:Ukraine
    2:Anna:designer:Poland
    3:Petro:tester:Germany
    4:Olena:developer:Ukraine

У кожному рядку чотири поля, розділені двокрапкою:

1. ID користувача.
2. Ім'я.
3. Професія.
4. Країна.

Цей файл використовуватимемо для вивчення `cut`.

## 2. Команда `cut` — вибір частин рядка

`cut` витягує певні частини кожного рядка тексту.

Загальний синтаксис:

    cut [OPTIONS] [FILE...]

Основні режими роботи:

- `-b` — вибір байтів;
- `-c` — вибір символів за позицією;
- `-f` — вибір полів;
- `-d` — визначення роздільника полів.

За замовчуванням `cut` читає файл построково й виводить вибрані частини.

## 3. Вибір символів — `cut -c`

Параметр `-c` дозволяє вибирати символи за їхніми позиціями в кожному рядку.

Створимо файл:

    printf 'Linux\nUbuntu\nDebian\n' > systems.txt

Виведемо перший символ кожного рядка:

    cut -c1 systems.txt

Результат:

    L
    U
    D

Виведемо перші три символи:

    cut -c1-3 systems.txt

Результат:

    Lin
    Ubu
    Deb

### 3.1. Вибір окремих позицій

Можна вибирати не лише послідовні символи, а й окремі позиції.

    cut -c1,3,5 systems.txt

Команда виведе перший, третій і п'ятий символи кожного рядка, якщо ці позиції існують.

### 3.2. Вибір діапазону від певної позиції до кінця

Запис `N-` означає: від позиції `N` до кінця рядка.

    cut -c3- systems.txt

Команда виведе текст, починаючи з третього символу.

### 3.3. Вибір символів від початку до певної позиції

Запис `-N` означає: від початку рядка до позиції `N`.

    cut -c-4 systems.txt

Команда виведе перші чотири символи кожного рядка.

**Запам'ятай:**

- `-c1` — перший символ;
- `-c1-3` — символи з першого по третій;
- `-c3-` — від третього символу до кінця;
- `-c-4` — від початку до четвертого символу;
- `-c1,3,5` — окремі позиції.

### 3.4. Важливе зауваження про Unicode

Хоча параметр називається `-c`, поведінка `cut` залежить від реалізації та локалі. У GNU `cut` режим `-c` працює з позиціями символів у багатобайтових кодуваннях за підтримки відповідної локалі, але не всі реалізації поводяться однаково.

Якщо працюєш з українським текстом, перевір локаль:

    locale

У типовому UTF-8 середовищі англійські й українські літери зазвичай обробляються як символи в режимі `-c`.

## 4. Вибір байтів — `cut -b`

Параметр `-b` вибирає байти за позиціями.

    cut -b1 systems.txt

Для звичайного ASCII-тексту результати `cut -b` і `cut -c` часто збігаються.

Однак у UTF-8 один символ може займати декілька байтів. Тому `cut -b` може розрізати багатобайтовий символ і створити некоректний фрагмент тексту.

Наприклад, українська літера `і` в UTF-8 зазвичай займає два байти.

**Правило для практики:**

- використовуй `cut -c`, якщо працюєш із позиціями символів;
- використовуй `cut -b`, якщо свідомо працюєш із байтовими позиціями.

Для звичайної обробки українського тексту режим `-c` зазвичай доречніший.

## 5. Вибір полів — `cut -f`

Параметр `-f` вибирає поля рядка.

За замовчуванням роздільником полів у `cut` є символ табуляції.

Створимо файл із табуляціями:

    printf '1\tValeriy\tdeveloper\n2\tAnna\tdesigner\n3\tPetro\ttester\n' > users-tab.txt

Виведемо перше поле:

    cut -f1 users-tab.txt

Результат:

    1
    2
    3

Виведемо друге поле:

    cut -f2 users-tab.txt

Результат:

    Valeriy
    Anna
    Petro

Виведемо третє поле:

    cut -f3 users-tab.txt

Результат:

    developer
    designer
    tester

### 5.1. Вибір декількох полів

Можна вибирати декілька полів одночасно:

    cut -f1,3 users-tab.txt

Результат:

    1	developer
    2	designer
    3	tester

Між вибраними полями за замовчуванням залишається табуляція.

### 5.2. Вибір діапазону полів

Щоб вибрати перші два поля:

    cut -f1-2 users-tab.txt

Щоб вибрати друге поле й усі наступні:

    cut -f2- users-tab.txt

Щоб вибрати всі поля, крім першого:

    cut -f2- users-tab.txt

### 5.3. Інвертування вибору — `--complement`

У GNU `cut` параметр `--complement` дозволяє вибрати всі поля, крім зазначених.

Наприклад:

    cut -f1 --complement users-tab.txt

Результат:

    Valeriy	developer
    Anna	designer
    Petro	tester

Це зручно, коли потрібно прибрати одне поле, зберігши решту.

`--complement` підтримується GNU `cut`; на інших Unix-системах підтримка може відрізнятися.

## 6. Визначення роздільника — `cut -d`

Наш файл `users.txt` використовує двокрапку `:` замість табуляції.

Якщо спробувати:

    cut -f2 users.txt

команда не розділить рядки за двокрапкою, тому що `cut` за замовчуванням шукає табуляції.

Потрібно вказати роздільник через `-d`:

    cut -d ':' -f2 users.txt

Результат:

    Valeriy
    Anna
    Petro
    Olena

Тут:

- `-d ':'` — роздільник полів двокрапка;
- `-f2` — вибрати друге поле.

### 6.1. Вибір декількох полів у файлі

Виведемо ім'я та професію:

    cut -d ':' -f2,3 users.txt

Результат:

    Valeriy:developer
    Anna:designer
    Petro:tester
    Olena:developer

За замовчуванням `cut` використовує той самий роздільник між вибраними полями, який було задано через `-d`.

### 6.2. Вибір ID та країни

    cut -d ':' -f1,4 users.txt

Результат:

    1:Ukraine
    2:Poland
    3:Germany
    4:Ukraine

### 6.3. Вибір усіх полів, крім ID

    cut -d ':' -f2- users.txt

Результат:

    Valeriy:developer:Ukraine
    Anna:designer:Poland
    Petro:tester:Germany
    Olena:developer:Ukraine

### 6.4. Пропуск рядків без роздільника — `-s`

За замовчуванням `cut -f` може виводити рядки, у яких немає заданого роздільника, без змін.

Параметр `-s` дозволяє пропускати такі рядки.

    printf 'Valeriy:developer\nAnna:designer\nUnknown format\n' > mixed.txt

Без `-s`:

    cut -d ':' -f1 mixed.txt

Результат:

    Valeriy
    Anna
    Unknown format

Із `-s`:

    cut -s -d ':' -f1 mixed.txt

Результат:

    Valeriy
    Anna

Це корисно, коли файл містить рядки різного формату.

## 7. Практичні приклади `cut`

### 7.1. Отримати список імен

    cut -d ':' -f2 users.txt

### 7.2. Отримати список професій

    cut -d ':' -f3 users.txt

### 7.3. Отримати список країн

    cut -d ':' -f4 users.txt

### 7.4. Витягнути імена розробників

Спочатку відфільтруємо рядки за професією:

    grep ':developer:' users.txt | cut -d ':' -f2

Результат:

    Valeriy
    Olena

Тут `grep` знаходить відповідні рядки, а `cut` витягує друге поле.

### 7.5. Отримати унікальні професії

    cut -d ':' -f3 users.txt | sort -u

Результат:

    developer
    designer
    tester

Це приклад спільного використання `cut` і `sort`.

### 7.6. Порахувати користувачів за країнами

    cut -d ':' -f4 users.txt | sort | uniq -c

Приклад результату:

    1 Germany
    1 Poland
    2 Ukraine

Команди працюють послідовно:

1. `cut` витягує країни.
2. `sort` групує однакові значення.
3. `uniq -c` підраховує кількість кожної країни.

## 8. Команда `paste` — об'єднання рядків

`paste` об'єднує рядки з декількох файлів.

За замовчуванням відповідні рядки з'єднуються символом табуляції.

Загальний синтаксис:

    paste [OPTIONS] FILE...

Створимо два файли.

Файл `names.txt`:

    cat > names.txt <<'EOF'
    Valeriy
    Anna
    Petro
    EOF

Файл `jobs.txt`:

    cat > jobs.txt <<'EOF'
    developer
    designer
    tester
    EOF

### 8.1. Об'єднання двох файлів

    paste names.txt jobs.txt

Результат:

    Valeriy	developer
    Anna	designer
    Petro	tester

Перший рядок `names.txt` поєднується з першим рядком `jobs.txt`, другий — із другим, третій — із третім.

За замовчуванням між значеннями вставляється табуляція.

### 8.2. Об'єднання з власним роздільником — `-d`

Якщо замість табуляції потрібна кома:

    paste -d ',' names.txt jobs.txt

Результат:

    Valeriy,developer
    Anna,designer
    Petro,tester

Можна використовувати й інші роздільники:

    paste -d ':' names.txt jobs.txt
    paste -d '|' names.txt jobs.txt

Це зручно для створення простих текстових таблиць.

### 8.3. Об'єднання трьох файлів

Створимо `countries.txt`:

    cat > countries.txt <<'EOF'
    Ukraine
    Poland
    Germany
    EOF

Об'єднаємо всі три файли:

    paste -d ',' names.txt jobs.txt countries.txt

Результат:

    Valeriy,developer,Ukraine
    Anna,designer,Poland
    Petro,tester,Germany

Тепер кожен рядок містить три поля.

### 8.4. Об'єднання рядків одного файла — `paste -s`

Параметр `-s` працює в серійному режимі: замість об'єднання відповідних рядків декількох файлів він об'єднує рядки одного файла в рядок результату.

    paste -s names.txt

Результат:

    Valeriy	Anna	Petro

З власним роздільником:

    paste -s -d ',' names.txt

Результат:

    Valeriy,Anna,Petro

### 8.5. Об'єднання рядків із різними роздільниками

Можна передавати послідовність роздільників:

    paste -s -d ',;' names.txt

У GNU `paste` символи з набору роздільників використовуються циклічно між сусідніми полями.

Для трьох імен результат буде:

    Valeriy,Anna;Petro

Це не те саме, що використовувати один роздільник для всіх полів.

### 8.6. Що відбувається, якщо кількість рядків різна

`paste` об'єднує рядки за їхніми позиціями. Якщо один файл коротший, відсутні значення для відповідних позицій будуть порожніми.

Наприклад:

    printf 'A\nB\nC\n' > first.txt
    printf '1\n2\n' > second.txt

Виконай:

    paste -d ',' first.txt second.txt

Результат:

    A,1
    B,2
    C,

Останній рядок не має другого значення, тому після коми буде порожнє поле.

## 9. Практичні приклади `paste`

### 9.1. Створити простий список користувачів

    paste -d ':' names.txt jobs.txt

### 9.2. Створити файл із трьома колонками

    paste -d ',' names.txt jobs.txt countries.txt > users.csv

Перевір результат:

    cat users.csv

### 9.3. Об'єднати список значень в один рядок

    paste -s -d ',' names.txt

### 9.4. Об'єднати два списки з вертикальною рискою

    paste -d '|' names.txt jobs.txt

Результат:

    Valeriy|developer
    Anna|designer
    Petro|tester

**Важливо:** `paste` об'єднує рядки за позиціями, а не шукає відповідність за іменем, ID чи іншим ключем. Для повноцінного об'єднання таблиць за ключами потрібні інші інструменти.

## 10. Команда `tr` — перетворення символів

`tr` означає *translate*. Команда перетворює, видаляє або стискає символи у вхідному потоці.

Загальний синтаксис:

    tr [OPTIONS] SET1 [SET2]

`tr` зазвичай читає дані зі стандартного введення та виводить результат у стандартний вивід. Тому часто його використовують через канал `|`.

### 10.1. Перетворення малих літер на великі

    printf 'hello linux\n' | tr 'a-z' 'A-Z'

Результат:

    HELLO LINUX

Тут:

- `'a-z'` — набір малих латинських літер;
- `'A-Z'` — відповідний набір великих латинських літер.

### 10.2. Перетворення великих літер на малі

    printf 'HELLO LINUX\n' | tr 'A-Z' 'a-z'

Результат:

    hello linux

Це зручно для нормалізації простого англомовного тексту перед подальшою обробкою.

**Важливо:** діапазони `a-z` та `A-Z` не слід вважати універсальним способом перетворення всіх літер Unicode. Для повноцінної зміни регістру українського чи іншого багатомовного тексту `tr` має обмеження. Для таких завдань можуть бути потрібні інші інструменти.

### 10.3. Заміна одного символу іншим

Наприклад, замінимо двокрапки на коми:

    printf 'Valeriy:developer:Ukraine\n' | tr ':' ','

Результат:

    Valeriy,developer,Ukraine

Ще один приклад:

    printf '2026-10-17\n' | tr '-' '/'

Результат:

    2026/10/17

`tr` замінює окремі символи, а не довільні текстові слова чи підрядки.

### 10.4. Перетворення табуляцій на пробіли

    printf 'Valeriy\tdeveloper\n' | tr '\t' ' '

Результат:

    Valeriy developer

Це корисно, коли потрібно спростити форматування тексту.

## 11. Видалення символів — `tr -d`

Параметр `-d` видаляє символи, що належать до заданого набору.

### 11.1. Видалення цифр

    printf 'user123\nadmin456\n' | tr -d '0-9'

Результат:

    user
    admin

### 11.2. Видалення двокрапок

    printf 'Valeriy:developer:Ukraine\n' | tr -d ':'

Результат:

    ValeriydeveloperUkraine

Усі двокрапки видаляються, а інші символи залишаються.

### 11.3. Видалення пробілів

    printf 'Linux terminal\n' | tr -d ' '

Результат:

    Linuxterminal

Ця команда видаляє звичайні пробіли, але не обов'язково табуляції чи інші пробільні символи.

### 11.4. Видалення символів нового рядка

    printf 'Linux\nUbuntu\nDebian\n' | tr -d '\n'

Результат буде виведено без розділення рядками:

    LinuxUbuntuDebian

Будь обережний із видаленням `\n`: воно з'єднує рядки, тому межі між значеннями можуть зникнути.

## 12. Стискання повторюваних символів — `tr -s`

Параметр `-s` стискає послідовності повторюваних символів із заданого набору до одного символу.

### 12.1. Стискання пробілів

    printf 'Linux     is      useful\n' | tr -s ' '

Результат:

    Linux is useful

Кілька послідовних звичайних пробілів перетворюються на один.

### 12.2. Стискання повторюваних символів

    printf 'Helloooo!!!!\n' | tr -s 'o!'

Результат:

    Helo!

Послідовності `oooo` та `!!!!` стискаються до одного `o` і одного `!`.

### 12.3. Стискання табуляцій

    printf 'A\t\t\tB\n' | tr -s '\t'

Результат міститиме лише одну табуляцію між `A` і `B`.

### 12.4. Стискання всіх пробільних символів

У GNU `tr` можна використовувати класи символів:

    printf 'Linux\t\tis\n\nuseful\n' | tr -s '[:space:]' ' '

Результат:

    Linux is useful

Тут `[:space:]` позначає пробільні символи, зокрема пробіли, табуляції та символи нового рядка. Команда стискає послідовності цих символів до одного звичайного пробілу.

**Зверни увагу:** оскільки символ нового рядка також входить до набору, цей приклад може об'єднати кілька рядків в один. Використовуй його лише тоді, коли таке перетворення потрібне.

## 13. Інвертування набору символів — `tr -c`

Параметр `-c` дозволяє працювати з усіма символами, які не входять до заданого набору.

### 13.1. Замінити всі символи, крім латинських літер і цифр

    printf 'user_123@example.com\n' | tr -c 'a-zA-Z0-9' '_'

Результат у типовому ASCII-прикладі:

    user_123_example_com_

Символи `_`, `@` і `.` замінено на `_`.

Оскільки символ нового рядка також не входить до набору латинських літер і цифр, він теж замінюється на `_`.

Якщо потрібно зберегти кінцевий символ нового рядка, можна виконати:

    printf 'user_123@example.com\n' | tr -c 'a-zA-Z0-9\n' '_'

### 13.2. Залишити тільки цифри

    printf 'Phone: +380-67-123-45-67\n' | tr -cd '0-9'

Результат:

    380671234567

Тут:

- `-c` — вибрати символи поза набором цифр;
- `-d` — видалити вибрані символи.

Команда `tr -cd '0-9'` видаляє все, крім цифр.

### 13.3. Видалити все, крім латинських літер

    printf 'Linux 2026 Ubuntu!\n' | tr -cd 'a-zA-Z'

Результат:

    LinuxUbuntu

Це може бути корисно для простих навчальних прикладів, але не є універсальним способом очищення довільного багатомовного тексту.

## 14. Класи символів у `tr`

`tr` підтримує стандартні класи символів, які позначаються у форматі `[:class:]`.

| Клас | Призначення |
|---|---|
| `[:lower:]` | Малі літери |
| `[:upper:]` | Великі літери |
| `[:alpha:]` | Літери |
| `[:digit:]` | Цифри |
| `[:alnum:]` | Літери та цифри |
| `[:space:]` | Пробільні символи |
| `[:blank:]` | Пробіл і табуляція |
| `[:punct:]` | Знаки пунктуації |
| `[:print:]` | Друковані символи |
| `[:cntrl:]` | Керівні символи |

### 14.1. Перетворення малих літер на великі через класи

    printf 'hello linux\n' | tr '[:lower:]' '[:upper:]'

Результат:

    HELLO LINUX

### 14.2. Видалення цифр

    printf 'user123\n' | tr -d '[:digit:]'

Результат:

    user

### 14.3. Видалення знаків пунктуації

    printf 'Hello, Linux!\n' | tr -d '[:punct:]'

Результат:

    Hello Linux

### 14.4. Залишити тільки цифри

    printf 'Order: AB-1234\n' | tr -cd '[:digit:]'

Результат:

    1234

Класи символів допомагають писати зрозуміліші команди, ніж довгі переліки окремих символів.

## 15. Комбінування `cut`, `paste` і `tr`

Ці утиліти можна поєднувати, створюючи конвеєри обробки тексту.

### 15.1. Отримати імена та перетворити їх на великі літери

    cut -d ':' -f2 users.txt | tr 'a-z' 'A-Z'

Результат:

    VALERIY
    ANNA
    PETRO
    OLENA

Спочатку `cut` вибирає друге поле, потім `tr` перетворює латинські малі літери на великі.

### 15.2. Отримати професії та порахувати кількість кожної

    cut -d ':' -f3 users.txt | sort | uniq -c

Результат:

    1 designer
    2 developer
    1 tester

### 15.3. Отримати список країн без повторень

    cut -d ':' -f4 users.txt | sort -u

Результат:

    Germany
    Poland
    Ukraine

### 15.4. Замінити роздільник

    cut -d ':' -f2- users.txt | tr ':' ','

Результат:

    Valeriy,developer,Ukraine
    Anna,designer,Poland
    Petro,tester,Germany
    Olena,developer,Ukraine

### 15.5. Об'єднати два списки та замінити роздільник

    paste names.txt jobs.txt | tr '\t' ','

Результат:

    Valeriy,developer
    Anna,designer
    Petro,tester

### 15.6. Витягнути дані й записати у файл

    cut -d ':' -f2,3 users.txt > names-and-jobs.txt

Перевір результат:

    cat names-and-jobs.txt

Оригінальний файл `users.txt` залишиться без змін.

## 16. Практичні приклади для розробника

### 16.1. Отримати значення з простого конфігураційного файла

Створимо `app.conf`:

    cat > app.conf <<'EOF'
    APP_NAME=Parish
    APP_ENV=development
    APP_PORT=3000
    EOF

Витягнемо назви параметрів:

    cut -d '=' -f1 app.conf

Результат:

    APP_NAME
    APP_ENV
    APP_PORT

Витягнемо значення:

    cut -d '=' -f2 app.conf

Результат:

    Parish
    development
    3000

Це підходить для простого навчального формату `KEY=VALUE`, але не є повноцінним парсером `.env` або конфігураційних файлів. У складніших форматах можуть бути лапки, коментарі, додаткові знаки `=` та інші правила.

### 16.2. Порахувати країни в списку користувачів

    cut -d ':' -f4 users.txt | sort | uniq -c | sort -nr

Ця команда показує країни за кількістю користувачів.

### 16.3. Нормалізувати пробіли в тексті

    printf 'Linux     terminal\tis   useful\n' | tr -s '[:space:]' ' '

Це стискає послідовності пробільних символів і замінює їх одним звичайним пробілом. У результаті рядки можуть об'єднатися, тому враховуй це під час обробки багаторядкового тексту.

### 16.4. Підготувати простий список для подальшої обробки

    cut -d ':' -f2 users.txt | sort > sorted-names.txt

Переглянь:

    cat sorted-names.txt

Так можна отримати відсортований список імен в окремому файлі.

## 17. Типові помилки

### 17.1. Забути вказати роздільник у `cut`

Неправильне очікування:

    cut -f2 users.txt

Якщо поля розділені двокрапкою, потрібно явно вказати роздільник:

    cut -d ':' -f2 users.txt

### 17.2. Плутати `-c` та `-b`

- `-c` — вибір позицій символів;
- `-b` — вибір позицій байтів.

Для UTF-8-тексту ці режими можуть давати різні результати.

### 17.3. Вважати `cut` повноцінним парсером CSV

Команда:

    cut -d ',' -f2 products.csv

підходить для простих рядків, розділених комами.

Але якщо значення містить кому всередині лапок, `cut` не розуміє структуру CSV і може розділити рядок неправильно.

### 17.4. Очікувати, що `paste` об'єднує дані за ключем

`paste` з'єднує рядки за позицією, а не за ID або іменем.

Якщо рядки розташовані в різному порядку, результат може бути логічно неправильним, навіть якщо команда виконалася успішно.

### 17.5. Очікувати від `tr` заміни слів

`tr` працює із символами, а не з довільними підрядками.

Для заміни текстового слова або складного шаблону краще використовувати інші інструменти, наприклад `sed` або `awk`.

### 17.6. Вважати `tr 'a-z' 'A-Z'` універсальним для Unicode

Цей приклад добре підходить для базової латиниці, але не гарантує коректної зміни регістру всіх українських або інших Unicode-літер.

### 17.7. Видаляти символ нового рядка без потреби

Команда:

    tr -d '\n'

об'єднує рядки. Якщо потрібно зберегти структуру тексту, не видаляй `\n` без чіткої причини.

### 17.8. Випадково перезаписати файл

Небезпечно:

    cut -d ':' -f2 users.txt > users.txt

Оператор `>` може очистити цільовий файл до того, як команда прочитає його.

Краще:

    cut -d ':' -f2 users.txt > names-only.txt

## 22. Мінішпаргалка

    # Вибрати перший символ кожного рядка
    cut -c1 file.txt

    # Вибрати перші три символи
    cut -c1-3 file.txt

    # Вибрати символи від третього до кінця
    cut -c3- file.txt

    # Вибрати байти
    cut -b1-5 file.txt

    # Вибрати друге поле з табуляцією як роздільником
    cut -f2 file.txt

    # Вибрати друге поле з двокрапкою як роздільником
    cut -d ':' -f2 file.txt

    # Вибрати перше й третє поля
    cut -d ':' -f1,3 file.txt

    # Вибрати всі поля, крім першого (GNU cut)
    cut -d ':' -f1 --complement file.txt

    # Пропускати рядки без роздільника
    cut -s -d ':' -f1 file.txt

    # Об'єднати рядки двох файлів
    paste first.txt second.txt

    # Об'єднати через кому
    paste -d ',' first.txt second.txt

    # Об'єднати рядки одного файла в один рядок
    paste -s file.txt

    # Об'єднати рядки через кому
    paste -s -d ',' file.txt

    # Перетворити малі латинські літери на великі
    tr 'a-z' 'A-Z'

    # Перетворити великі латинські літери на малі
    tr 'A-Z' 'a-z'

    # Замінити двокрапки на коми
    tr ':' ','

    # Видалити цифри
    tr -d '0-9'

    # Стиснути повторювані пробіли
    tr -s ' '

    # Видалити все, крім цифр
    tr -cd '0-9'

    # Витягнути професії та порахувати повторення
    cut -d ':' -f3 users.txt | sort | uniq -c

    # Об'єднати три файли через кому
    paste -d ',' names.txt jobs.txt countries.txt

    # Записати результат у файл
    cut -d ':' -f2 users.txt > names-only.txt

## 23. Головне, що потрібно запам'ятати

- `cut` витягує символи, байти або поля з кожного рядка.
- `cut -d` задає роздільник, а `cut -f` вибирає поля.
- За замовчуванням `cut -f` використовує табуляцію як роздільник.
- `paste` об'єднує відповідні рядки з декількох файлів.
- `paste -d` задає роздільник, а `paste -s` об'єднує рядки одного файла в один рядок.
- `tr` перетворює, видаляє або стискає символи у вхідному потоці.
- `tr -d` видаляє задані символи, `tr -s` стискає їхні повторення, а `tr -c` інвертує набір символів.
- `cut`, `paste` і `tr` часто використовують разом із каналами `|`.
- Ці команди підходять для простих текстових форматів, але не замінюють повноцінні парсери CSV, JSON або конфігураційних файлів.
- Для складнішої обробки тексту варто поступово вивчати `sed` та `awk`.

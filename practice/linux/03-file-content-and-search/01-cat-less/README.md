# 01. cat-less

`cat` і `less` — команди Linux для перегляду вмісту текстових файлів у терміналі.

Вони використовуються, коли потрібно:

- переглянути вміст текстового файлу;
- прочитати конфігураційний файл;
- переглянути README або журнал подій;
- об'єднати вміст кількох файлів;
- передати вміст файлу іншій команді;
- читати великі файли без завантаження всього вмісту на екран;
- переглядати системні та програмні конфігурації;
- перевіряти результати роботи програм і скриптів.

Основні команди:

    cat
    less
    tac
    nl

Додатково варто знати:

    more
    head
    tail

Команди `head` і `tail` детально розглядаються в наступному розділі:

    02-head-tail

## Що потрібно пам'ятати

• `cat` виводить вміст файлу в стандартний вивід, зазвичай у термінал.

• `less` відкриває файл у посторінковому переглядачі (pager).

• `cat` зручний для коротких файлів, швидкого перегляду та передавання вмісту іншим командам.

• `less` зручний для великих файлів, довгих логів і конфігурацій.

• `cat file.txt` не змінює файл, а лише читає його та виводить вміст.

• `less file.txt` також не змінює файл.

• Щоб вийти з `less`, потрібно натиснути `q`.

• У `less` можна шукати текст за допомогою `/pattern` і `?pattern`.

• `cat file1.txt file2.txt` виводить файли послідовно один за одним.

• `cat` може читати дані зі стандартного вводу, якщо ім'я файлу не вказано.

• `tac` виводить рядки у зворотному порядку.

• `nl` виводить текст із нумерацією рядків.

• Для читання системних файлів, до яких немає доступу, може знадобитися `sudo`.

• Не варто використовувати `cat` для перегляду великих файлів, якщо це призводить до надмірного виведення в термінал.

• Якщо потрібно лише прочитати файл, не використовуйте команди, які можуть перезаписати його вміст.

# File Content

## Що таке вміст файлу

Файл може містити текст, конфігурацію, програмний код, журнали подій або інші дані.

Наприклад, створимо файл:

    notes.txt

Його вміст:

    Linux
    Terminal
    Bash
    Files

Переглянути цей вміст можна командою:

    cat notes.txt

Результат:

    Linux
    Terminal
    Bash
    Files

Команда читає файл і передає його вміст до стандартного виводу.

# cat

`cat` — команда для виведення вмісту файлів у стандартний вивід.

Назва походить від слова *concatenate* — об'єднувати.

Основний синтаксис:

    cat [OPTIONS] [FILE...]

Де:

    cat       → команда
    OPTIONS   → необов'язкові параметри
    FILE      → один або декілька файлів

Наприклад:

    cat notes.txt

Команда виведе вміст `notes.txt`.

---

## Перегляд одного файлу

    cat README.md

Приклад результату:

    # Linux Course

    My Linux learning notes.

    Commands:
    - pwd
    - ls
    - cd

Команда виводить увесь доступний для читання вміст файлу.

---

## Перегляд кількох файлів

`cat` може приймати декілька файлів як аргументи.

    cat first.txt second.txt

Спочатку буде виведено вміст `first.txt`, а потім — `second.txt`.

Наприклад:

`first.txt`:

    Hello

`second.txt`:

    Linux

Команда:

    cat first.txt second.txt

Результат:

    Hello
    Linux

Важливо: `cat` не обов'язково додає роздільник між файлами. Якщо перший файл не закінчується символом нового рядка, вміст другого може продовжити той самий рядок.

Наприклад, якщо перший файл містить `Hello` без завершального перенесення рядка, а другий — `Linux`, результат може бути таким:

    HelloLinux

---

## Перегляд усіх текстових файлів у каталозі

Якщо потрібно переглянути кілька файлів, можна використовувати шаблони оболонки.

    cat *.txt

Shell спочатку розгорне `*.txt` у список відповідних файлів, а потім передасть їх команді `cat`.

Наприклад, якщо каталог містить:

    first.txt
    second.txt
    third.txt

Команда виведе вміст усіх трьох файлів.

Увага: не використовуйте такі шаблони бездумно. Якщо файлів багато, результат може бути дуже великим.

---

## cat із відносним шляхом

Якщо файл розташований у підкаталозі:

    cat notes/README.md

Тут:

    notes/README.md → відносний шлях до файлу

Відносний шлях обчислюється від поточного робочого каталогу.

Перевірити поточний каталог:

    pwd

---

## cat з абсолютним шляхом

Можна вказати повний шлях до файлу:

    cat /etc/hostname

Приклад результату:

    taubu-lap

Фактичний результат залежить від імені комп'ютера.

Абсолютний шлях починається з `/`.

Приклади:

    /etc/hostname
    /etc/os-release
    /etc/hosts

# Основні параметри cat

## -n — нумерація всіх рядків

    cat -n notes.txt

Приклад результату:

         1  Linux
         2  Terminal
         3  Bash
         4  Files

Параметр `-n` нумерує всі рядки, включно з порожніми.

Це нумерація лише під час виведення. Вміст самого файлу не змінюється.

---

## -b — нумерація непорожніх рядків

    cat -b notes.txt

Параметр `-b` нумерує тільки непорожні рядки.

Наприклад, якщо файл містить:

    Linux

    Bash
    Terminal

Результат може виглядати так:

         1  Linux

         2  Bash
         3  Terminal

Порожній рядок не отримує номера.

---

## -s — об'єднання послідовних порожніх рядків

    cat -s notes.txt

Параметр `-s` стискає послідовності порожніх рядків до одного порожнього рядка.

Це корисно, коли текст містить багато зайвих порожніх рядків.

Важливо: параметр змінює лише вигляд виведення, а не сам файл.

---

## -A — показати спеціальні символи

    cat -A notes.txt

Цей параметр допомагає побачити деякі невидимі символи.

Наприклад:

    Linux$
    Bash$
    Terminal$

Символ `$` у типовому виведенні GNU `cat -A` позначає кінець рядка.

Це корисно для перевірки:

- перенесень рядків;
- зайвих пробілів;
- порожніх рядків;
- форматування текстових файлів.

Параметр `-A` є скороченням для комбінації параметрів, які показують недруковані символи та кінці рядків.

---

## -T — показати символи табуляції

    cat -T notes.txt

Символ табуляції зазвичай відображається як:

    ^I

Це допомагає відрізнити табуляцію від звичайних пробілів.

---

## -E — показати кінці рядків

    cat -E notes.txt

Кінець рядка позначається символом `$`.

Це корисно, коли потрібно перевірити форматування тексту.

---

# cat: стандартний ввід

Команда `cat` може працювати без зазначення файлу.

    cat

Після запуску команда очікує введення з клавіатури.

Введи:

    Hello Linux

Натисни Enter.

Текст буде виведений на екран:

    Hello Linux

Щоб завершити введення з клавіатури в терміналі, натисни:

    Ctrl + D

`Ctrl + D` передає ознаку завершення стандартного вводу (EOF), якщо введення перебуває на початку нового рядка.

Важливо: `cat` у такому режимі не створює файл автоматично. Він лише читає стандартний ввід і передає отримані дані до стандартного виводу.

---

# cat: об'єднання файлів

Одна з важливих можливостей `cat` — послідовне об'єднання вмісту файлів у потоці виводу.

Наприклад:

    cat header.txt body.txt footer.txt

Результат:

    вміст header.txt
    вміст body.txt
    вміст footer.txt

Це може бути корисно для:

- об'єднання текстових фрагментів;
- передавання кількох файлів іншій команді;
- створення потоку даних для подальшої обробки.

Однак `cat` не аналізує структуру файлів і не перевіряє, чи коректно їх об'єднувати.

Наприклад, механічне об'єднання двох JavaScript-файлів не гарантує правильності отриманого коду.

---

# less

`less` — інтерактивний посторінковий переглядач тексту.

Він дозволяє читати файл частинами, переміщуватися вгору та вниз, шукати текст і переглядати великі файли без необхідності виводити весь вміст на екран одночасно.

Основний синтаксис:

    less [OPTIONS] FILE

Наприклад:

    less README.md

Після запуску ти потрапляєш у режим перегляду файлу.

На екрані буде показано частину тексту, яка поміщається у вікно термінала.

---

## Чому less зручніший для великих файлів

Уявімо, що файл містить 10 000 рядків.

Команда:

    cat application.log

спробує вивести весь доступний вміст у термінал.

Читати такий потік незручно.

Натомість:

    less application.log

дозволяє:

- переглядати текст частинами;
- рухатися вгору та вниз;
- шукати слова;
- переходити до початку або кінця файлу;
- виходити з перегляду без зміни файлу.

Для великих логів і конфігурацій `less` зазвичай практичніший за `cat`.

---

# Навігація в less

Після відкриття файлу команда `less` працює в інтерактивному режимі.

Основні клавіші:

    q           → вийти
    Space       → наступна сторінка
    b           → попередня сторінка
    Enter       → вниз на один рядок
    ↑           → вгору на один рядок
    ↓           → вниз на один рядок
    g           → на початок файлу
    G           → у кінець файлу
    /pattern    → пошук уперед
    ?pattern    → пошук назад
    n           → наступний результат пошуку
    N           → попередній результат пошуку
    h           → довідка

Найважливіша клавіша:

    q

Вона завершує роботу переглядача та повертає до командного рядка.

---

## Перехід на наступну сторінку

Відкрий файл:

    less README.md

Натисни:

    Space

Переглядач покаже наступну сторінку тексту.

Якщо файл короткий, наступної сторінки може не бути.

---

## Перехід на попередню сторінку

Натисни:

    b

Переглядач повернеться до попередньої сторінки.

---

## Переміщення на один рядок

Для переміщення на один рядок можна використовувати:

    Enter
    ↓
    ↑

Це зручно, коли потрібно уважно прочитати текст.

---

## Перехід на початок файлу

Натисни:

    g

Переглядач перейде до початку файлу.

---

## Перехід у кінець файлу

Натисни:

    G

Переглядач перейде до кінця файлу.

Це корисно під час перегляду логів, де найновіші записи часто розташовані наприкінці.

---

# Пошук у less

`less` дозволяє шукати текст усередині відкритого файлу.

## Пошук уперед

Натисни:

    /error

Потім Enter.

Переглядач шукатиме наступний збіг слова `error` від поточної позиції до кінця файлу.

Наприклад, якщо файл містить:

    Application started
    User connected
    Error: database unavailable
    Application stopped

Пошук:

    /error

може привести до рядка:

    Error: database unavailable

Результат залежить від параметрів пошуку та регістру символів.

---

## Пошук назад

Натисни:

    ?error

Потім Enter.

Пошук відбуватиметься в напрямку початку файлу.

Різниця:

    /pattern → пошук уперед
    ?pattern → пошук назад

---

## Наступний результат

Після пошуку натисни:

    n

Переглядач перейде до наступного збігу в напрямку поточного пошуку.

---

## Попередній результат

Натисни:

    N

Переглядач перейде до попереднього збігу.

---

## Пошук без урахування регістру

У типовій конфігурації `less` пошук може залежати від регістру.

Для пошуку без урахування регістру можна використовувати:

    less -i application.log

Параметр `-i` вмикає нечутливий до регістру пошук для відповідних пошукових запитів.

Наприклад, пошук:

    /error

може знаходити:

    error
    Error
    ERROR

Поведінка залежить також від налаштувань `less` та конкретного пошукового шаблону.

---

# less із номерами рядків

Щоб показати номери рядків під час перегляду файлу:

    less -N README.md

Параметр `-N` відображає номери рядків.

Це зручно, коли потрібно:

- знайти помилку в конфігурації;
- послатися на конкретний рядок;
- перевірити великий текстовий файл;
- дослідити програмний код.

Нумерація відображається у переглядачі та не змінює файл.

---

# less із переходом до конкретного рядка

Можна відкрити файл і перейти до певного рядка.

Наприклад:

    less +100 application.log

Команда відкриє файл приблизно з позиції 100-го рядка.

Це корисно для великих файлів, коли приблизно відомо, де розташована потрібна інформація.

Ще один варіант — відкрити файл звичайним способом:

    less application.log

А потім перейти до початку або іншої позиції клавішами навігації.

---

# less і системні файли

`less` особливо зручний для перегляду конфігурацій Linux.

Наприклад:

    less /etc/os-release

Цей файл містить інформацію про операційну систему.

Інший приклад:

    less /etc/hosts

Цей файл містить локальні зіставлення IP-адрес та імен вузлів.

Для системних журналів можна використовувати:

    less /var/log/syslog

Але цей шлях і доступність файлу залежать від дистрибутива та конфігурації системи. На деяких системах журнали переглядають через `journalctl`.

Якщо виникає помилка доступу, спочатку перевір права читання. За потреби можна використати:

    sudo less /var/log/syslog

Використовуй `sudo` лише тоді, коли це справді потрібно.

---

# less і stdin

`less` може читати не тільки файл, але й дані зі стандартного вводу.

Наприклад:

    cat README.md | less

Тут:

    cat README.md → читає файл
    |             → передає вивід наступній команді
    less          → переглядає отриманий текст

Однак для простого перегляду файла краще одразу написати:

    less README.md

Це коротше й зазвичай зручніше.

Передавання через pipe корисне, коли потрібно переглянути результат іншої команди:

    ls -la | less

Так можна прокручувати довгий список файлів.

---

# less: вихід і керування

Під час роботи в `less` важливо пам'ятати, що ти перебуваєш не в звичайному командному рядку.

Наприклад, якщо ввести:

    ls

це не обов'язково виконає команду оболонки. Символи можуть інтерпретуватися як введення для самого переглядача.

Щоб повернутися до командного рядка:

    q

Після цього можна знову виконувати команди:

    pwd
    ls
    cat README.md

Якщо не пам'ятаєш клавіші, натисни:

    h

Щоб повернутися до перегляду, зазвичай натисни `q` у довідці.

# cat vs less

Це одна з найважливіших відмінностей у цьому розділі.

## cat

    cat README.md

Особливості:

- виводить вміст файла безпосередньо в термінал;
- зручно працює з короткими файлами;
- дозволяє передавати вміст далі через pipe;
- може об'єднувати кілька файлів;
- не має інтерактивної навігації по файлу.

## less

    less README.md

Особливості:

- відкриває інтерактивний переглядач;
- дозволяє читати текст частинами;
- підтримує навігацію вгору та вниз;
- дозволяє шукати текст;
- зручний для великих файлів;
- потребує виходу клавішею `q`.

Порівняння:

    cat  → швидко вивести вміст
    less → інтерактивно читати вміст

---

# tac

`tac` виводить рядки файлу у зворотному порядку.

Це протилежність звичайному порядку виведення `cat`.

Наприклад, файл `numbers.txt`:

    one
    two
    three

Команда:

    tac numbers.txt

Результат:

    three
    two
    one

Важливо: `tac` змінює порядок рядків у виведенні, а не сам файл.

Команда може бути корисною для швидкого перегляду логів, коли цікаві останні записи.

Проте для постійного перегляду останніх рядків логів зазвичай зручніша команда `tail`, яку розглядають у наступному розділі.

---

# nl

`nl` — команда для виведення тексту з нумерацією рядків.

Наприклад:

    nl README.md

Результат може виглядати так:

         1  # Linux Course
         2
         3  My Linux learning notes.
         4
         5  Commands:
         6  - pwd
         7  - ls

За замовчуванням `nl` має правила нумерації, які відрізняються від `cat -n`, зокрема щодо порожніх рядків.

---

## nl vs cat -n

`cat -n`:

    cat -n README.md

Нумерує всі рядки, включно з порожніми.

`nl`:

    nl README.md

За типовими налаштуваннями нумерує непорожні рядки, а поведінку можна змінювати параметрами.

Тому для простого показу номерів усіх рядків зручно використовувати `cat -n`, а для гнучкішого форматування нумерації — `nl`.

---

# more

`more` — простий посторінковий переглядач тексту.

Приклад:

    more README.md

Він дозволяє переглядати текст частинами.

Основні клавіші можуть включати:

    Space → наступна сторінка
    Enter → наступний рядок
    q     → вихід

У сучасному Linux зазвичай зручніше використовувати `less`, оскільки він надає гнучкішу навігацію та пошук.

Достатньо знати, що `more` існує, і вміти розпізнати його під час роботи в терміналі.

# Типові помилки

## ❌ Забувати виходити з less

Після виконання:

    less README.md

термінал залишається в режимі перегляду.

Рішення:

    q

---

## ❌ Використовувати cat для надто великого файла

    cat huge.log

Якщо файл дуже великий, у терміналі з'явиться надмірна кількість тексту.

Краще:

    less huge.log

---

## ❌ Вважати, що cat змінює файл

Команда:

    cat notes.txt

лише читає файл і виводить його вміст.

Вона не редагує файл.

---

## ❌ Плутати перегляд із перенаправленням

Команда:

    cat notes.txt

виводить вміст на екран.

А команда:

    cat notes.txt > copy.txt

перенаправляє вивід у файл `copy.txt`.

Якщо `copy.txt` уже існує, його вміст буде перезаписано.

Якщо вказати той самий файл як джерело й призначення:

    cat notes.txt > notes.txt

можна втратити вміст файла через особливості перенаправлення оболонки.

Не використовуй таку команду.

Перенаправлення детально розглядається в розділі:

    06-redirection

---

## ❌ Думати, що cat завжди додає новий рядок

`cat` не додає автоматично символ нового рядка після кожного файла.

Якщо файл не має завершального перенесення рядка, наступний файл може починатися в тому самому рядку.

---

## ❌ Плутати великі та малі літери в параметрах

Наприклад:

    cat -n notes.txt

і

    cat -N notes.txt

не є еквівалентними командами. У `cat` параметр `-n` підтримується, а `-N` не є стандартним еквівалентом.

У Linux регістр параметрів має значення.

---

## ❌ Вважати, що less редагує файл

`less` призначений для перегляду, а не для редагування.

Для редагування використовують текстові редактори, наприклад:

    nano notes.txt

або:

    vim notes.txt

---

## ❌ Використовувати sudo без потреби

Не кожен системний файл потребує підвищених прав.

Спочатку спробуй:

    less /etc/hosts

Якщо доступ дозволений, `sudo` не потрібен.

    cat -A blank-lines.txt

    $
    ^I

# Міні-шпаргалка

## cat

    cat file.txt

Вивести вміст файла.

    cat file1.txt file2.txt

Вивести вміст декількох файлів послідовно.

    cat -n file.txt

Пронумерувати всі рядки.

    cat -b file.txt

Пронумерувати непорожні рядки.

    cat -A file.txt

Показати кінці рядків та інші спеціальні символи.

---

## less

    less file.txt

Відкрити файл для інтерактивного перегляду.

    less -N file.txt

Перегляд із номерами рядків.

    less -i file.txt

Пошук без урахування регістру для відповідних запитів.

Клавіші:

    q        → вихід
    Space    → наступна сторінка
    b        → попередня сторінка
    g        → початок
    G        → кінець
    /word    → пошук уперед
    ?word    → пошук назад
    n        → наступний результат
    N        → попередній результат
    h        → довідка

---

## tac

    tac file.txt

Вивести рядки у зворотному порядку.

---

## nl

    nl file.txt

Вивести текст із нумерацією рядків.

---

## Pipe

    cat file.txt | less

Передати вміст файла до посторінкового переглядача.

Для звичайного читання файла простіше:

    less file.txt

---

## Основні правила

    cat  → швидке виведення тексту
    less → інтерактивний перегляд
    tac  → рядки у зворотному порядку
    nl   → нумерація рядків
    q    → вихід із less
    /    → пошук уперед у less
    ?    → пошук назад у less
    n    → наступний результат пошуку
    N    → попередній результат пошуку

# Головне

• `cat` використовується для швидкого виведення вмісту файлів.

• `less` використовується для зручного читання файлів частинами.

• Для великих логів і конфігурацій зазвичай краще починати з `less`.

• `cat -n` нумерує всі рядки, а `cat -b` — лише непорожні.

• `cat -A` допомагає побачити кінці рядків і спеціальні символи.

• `less` дозволяє прокручувати текст, шукати слова та переходити між результатами.

• Клавіша `q` повертає з `less` до командного рядка.

• `tac` виводить рядки у зворотному порядку.

• `nl` дозволяє гнучко нумерувати рядки.

• `cat` може об'єднувати вивід кількох файлів, але не додає автоматично роздільники між ними.

• `cat` і `less` у звичайному режимі перегляду не редагують початковий файл.

• Оператор `|` дозволяє передавати вивід однієї команди на вхід іншої.

• Для простого читання файла не потрібно використовувати pipe без необхідності.

• Команди читання файлів — одна з основ роботи з Linux, конфігураціями, логами та програмним кодом.

# 06. Terminal Shortcuts — Гарячі клавіші термінала

> Шпаргалка з основних комбінацій клавіш для роботи в Linux-терміналі: редагування команд, навігація по рядку, керування процесами, історія команд і робота з Bash.

---

## 1. Що таке гарячі клавіші термінала?

**Гарячі клавіші термінала (Terminal Shortcuts)** — це комбінації клавіш, які дозволяють виконувати типові дії без використання миші та без введення додаткових команд.

У Linux більшість стандартних комбінацій для роботи з командним рядком визначає оболонка **Bash**, використовуючи бібліотеку редагування рядків Readline.

Гарячі клавіші допомагають:

- швидше вводити та редагувати команди;
- переміщатися по довгих командних рядках;
- повторно використовувати раніше введені команди;
- переривати або призупиняти виконання програм;
- очищати екран і керувати введенням;
- працювати в терміналі без миші.

### Основні поняття

- **Terminal** — програма, у якій працюють із командним рядком.
- **Shell** — оболонка, яка приймає та виконує команди, наприклад Bash.
- **Bash** — одна з найпоширеніших командних оболонок Linux.
- **Readline** — бібліотека, яка забезпечує редагування командного рядка та історію команд у Bash.
- **Shortcut** — комбінація клавіш для виконання певної дії.
- **`Ctrl`** — клавіша Control.
- **`Alt`** — клавіша Alt; у деяких терміналах її поведінка може залежати від налаштувань.

> Важливо: гарячі клавіші можуть відрізнятися залежно від оболонки, емулятора термінала, графічного середовища та його налаштувань. Нижче наведені стандартні комбінації для Bash у типовому Linux-терміналі.

---

## 2. Навігація по командному рядку

Коли команда довга, не потрібно видаляти її повністю та вводити заново. Можна переміщатися по рядку й редагувати тільки потрібну частину.

| Комбінація | Дія |
|---|---|
| `Ctrl + A` | Перейти на початок командного рядка |
| `Ctrl + E` | Перейти в кінець командного рядка |
| `Alt + B` | Переміститися на одне слово назад |
| `Alt + F` | Переміститися на одне слово вперед |
| `Ctrl + B` | Переміститися на один символ назад |
| `Ctrl + F` | Переміститися на один символ вперед |
| `Home` | Перейти на початок рядка |
| `End` | Перейти в кінець рядка |
| `←` | Переміститися на один символ назад |
| `→` | Переміститися на один символ вперед |

### Приклад

Припустимо, ти ввів команду:

    mkdir -p projects/linux/practice

Курсор перебуває в кінці рядка.

- `Ctrl + A` — курсор переходить на початок.
- `Ctrl + E` — курсор повертається в кінець.
- `Alt + B` — курсор переміщується на одне слово назад.
- `Alt + F` — курсор переміщується на одне слово вперед.

Ці комбінації особливо корисні, коли потрібно виправити шлях або параметр у довгій команді.

### Особливість `Alt`

На деяких клавіатурах або в окремих терміналах `Alt + B` і `Alt + F` можуть не працювати так, як очікується.

У такому випадку можна спробувати натискати `Esc`, а потім окремо `B` або `F`.

    Alt + B  → слово назад
    Esc, B   → альтернативний спосіб
    Alt + F  → слово вперед
    Esc, F   → альтернативний спосіб

## 3. Редагування командного рядка

Ці комбінації дозволяють швидко видаляти символи, слова або частини команди.

| Комбінація | Дія |
|---|---|
| `Backspace` | Видалити символ ліворуч від курсора |
| `Delete` | Видалити символ праворуч від курсора |
| `Ctrl + H` | Видалити символ ліворуч від курсора |
| `Ctrl + D` | Видалити символ праворуч від курсора; на порожньому рядку може завершити оболонку |
| `Ctrl + W` | Видалити слово перед курсором |
| `Alt + D` | Видалити слово після курсора |
| `Ctrl + U` | Видалити все від початку рядка до курсора |
| `Ctrl + K` | Видалити все від курсора до кінця рядка |
| `Ctrl + Y` | Вставити текст, який був видалений деякими попередніми комбінаціями |
| `Alt + Backspace` | Видалити попереднє слово або його частину залежно від налаштувань |

### Приклад 1. Видалення слова

Введи команду, але поки не натискай `Enter`:

    mkdir projects/linux/practice

Перемісти курсор у кінець слова `practice` і натисни `Ctrl + W`.

Буде видалено слово перед курсором. Результат залежить від точного положення курсора.

### Приклад 2. Видалення частини рядка

Введи:

    mkdir -p projects/linux/practice

Натисни `Ctrl + A`, щоб перейти на початок рядка, а потім `Ctrl + K`.

Увесь текст праворуч від курсора буде видалено. Оскільки курсор на початку, команда стане порожньою.

### Приклад 3. Відновлення видаленого тексту

1. Введи команду, але не виконуй її.
2. Натисни `Ctrl + A`.
3. Натисни `Ctrl + K`.
4. Натисни `Ctrl + Y`.

`Ctrl + Y` вставляє текст із внутрішнього буфера Readline, якщо попередня операція помістила туди видалений текст.

> Увага: `Ctrl + D` на порожньому командному рядку Bash зазвичай завершує оболонку. Не натискай його багаторазово, якщо не хочеш вийти з термінальної сесії.

## 4. Історія команд

Bash зберігає історію введених команд. Це дозволяє повторно використовувати команди без повторного введення.

| Комбінація | Дія |
|---|---|
| `↑` | Перейти до попередньої команди |
| `↓` | Перейти до наступної команди в історії |
| `Ctrl + P` | Попередня команда |
| `Ctrl + N` | Наступна команда |
| `Ctrl + R` | Інтерактивний пошук в історії |
| `Alt + .` | Вставити останній аргумент попередньої команди |
| `Ctrl + G` | Скасувати пошук в історії та повернутися до командного рядка |

### 4.1. Перегляд попередніх команд

Виконай кілька команд:

    pwd
    ls
    whoami

Тепер натискай `↑`.

Bash послідовно показуватиме попередні команди. За допомогою `↓` можна рухатися вперед по історії.

### 4.2. Пошук через `Ctrl + R`

Це одна з найкорисніших комбінацій для щоденної роботи.

1. Натисни `Ctrl + R`.
2. Почни вводити частину раніше використаної команди.
3. Bash покаже відповідний результат із історії.
4. Натисни `Enter`, щоб виконати знайдену команду.
5. Або натисни `→`, щоб перенести команду в звичайний рядок і відредагувати її перед виконанням.

Приклад:

    ls

Пізніше натисни `Ctrl + R` і введи:

    ls

Bash спробує знайти відповідну команду в історії.

Якщо знайдено не ту команду, продовжуй натискати `Ctrl + R`, щоб перейти до попередніх збігів.

### 4.3. Вставлення останнього аргументу

Припустимо, ти виконав:

    cd ~/projects/nest-exercises

Після цього вводиш нову команду й натискаєш `Alt + .`.

Bash вставить останній аргумент попередньої команди:

    ~/projects/nest-exercises

Це корисно, коли потрібно повторно використати шлях до каталогу або назву файлу.

> Зверни увагу: історія Bash може містити команди з чутливими даними. Не вводь паролі, токени або інші секрети безпосередньо в командний рядок, якщо цього можна уникнути.

## 5. Керування виконанням команд

Ці комбінації дозволяють впливати на поточний процес або на введення команди.

| Комбінація | Дія |
|---|---|
| `Ctrl + C` | Надіслати переривання поточному процесу |
| `Ctrl + Z` | Призупинити поточний процес через сигнал зупинки |
| `Ctrl + D` | Передати ознаку завершення введення (EOF); у Bash на порожньому рядку зазвичай завершує оболонку |
| `Ctrl + S` | У типовій конфігурації може призупинити виведення термінала |
| `Ctrl + Q` | Відновити виведення після `Ctrl + S`, якщо воно було призупинене таким способом |

### 5.1. `Ctrl + C` — перервати виконання

Запусти команду:

    sleep 30

Вона чекатиме приблизно 30 секунд.

Натисни `Ctrl + C`.

Виконання команди буде перервано, і ти повернешся до запрошення Bash.

Ця комбінація корисна, якщо:

- команда виконується занадто довго;
- програма зависла;
- потрібно зупинити локальний сервер;
- ти випадково запустив не ту команду.

Наприклад, під час розробки Node.js можна запустити сервер:

    npm run dev

Щоб зупинити сервер у цьому терміналі, зазвичай використовують `Ctrl + C`.

### 5.2. `Ctrl + Z` — призупинити процес

Запусти:

    sleep 100

Натисни `Ctrl + Z`.

Bash призупинить процес і покаже повідомлення про зупинене завдання.

Важливо розуміти різницю:

- `Ctrl + C` — просить процес перервати виконання.
- `Ctrl + Z` — призупиняє процес, але не завершує його остаточно.

Переглянути завдання можна командою:

    jobs

Повернути призупинене завдання на передній план:

    fg

Відновити завдання у фоні:

    bg

Це вже не гарячі клавіші, а команди керування завданнями Bash.

### 5.3. `Ctrl + S` і `Ctrl + Q`

У деяких конфігураціях термінала `Ctrl + S` призупиняє виведення тексту, а `Ctrl + Q` відновлює його.

Якщо термінал перестав показувати новий текст після випадкового натискання `Ctrl + S`, спробуй натиснути:

    Ctrl + Q

Це пов'язано з механізмом керування потоком даних термінала, який називається XON/XOFF.

> Якщо ці комбінації не працюють, поведінка може бути змінена налаштуваннями термінала або системи.

## 6. Очищення екрана термінала

| Комбінація або команда | Дія |
|---|---|
| `Ctrl + L` | Очистити видиму область термінала |
| `clear` | Очистити екран термінала |
| `reset` | Скинути стан термінала, якщо його відображення порушено |

### 6.1. `Ctrl + L`

Натисни:

    Ctrl + L

Видима область термінала очиститься, а поточний рядок запрошення буде переміщено вгору або на початок нового екрана.

Це зручно, коли після виконання багатьох команд термінал став нечитабельним.

### 6.2. Команда `clear`

Альтернативний спосіб:

    clear

Результат подібний до `Ctrl + L`.

### 6.3. Команда `reset`

Якщо термінал неправильно відображає текст, кольори або символи, іноді допомагає:

    reset

Ця команда може змінити стан термінала та очистити екран. Використовуй її лише тоді, коли звичайного очищення недостатньо.

> `Ctrl + L` і `clear` переважно очищають видиму область, а не видаляють історію команд Bash.

## 7. Автодоповнення команд і шляхів

**Tab completion** — механізм автодоповнення, який допомагає вводити назви команд, файлів і каталогів.

| Клавіша | Дія |
|---|---|
| `Tab` | Доповнити команду, ім'я файлу або шлях, якщо це можливо |
| `Tab`, `Tab` | Показати доступні варіанти, якщо однозначне доповнення неможливе |

### 7.1. Автодоповнення каталогу

Припустимо, ти перебуваєш у домашньому каталозі й хочеш перейти в `projects`.

Введи:

    cd pro

Натисни `Tab`.

Якщо існує однозначний відповідний каталог, Bash доповнить команду.

Результат:

    cd projects/

Після цього натисни `Enter`.

### 7.2. Якщо варіантів декілька

Введи початок назви:

    cd p

Натисни `Tab` двічі.

Якщо є декілька відповідних варіантів, Bash покаже список доступних назв.

### 7.3. Навіщо потрібен Tab completion?

- Менше ручного введення.
- Менше помилок у назвах файлів.
- Зручна робота з довгими шляхами.
- Швидка навігація по проєктах.

Наприклад, у твоєму робочому каталозі:

    cd ~/projects/nest-exercises/practice/linux/

Не обов'язково вводити весь шлях вручну — можна використовувати `Tab` після кожної частини.

## 8. Робота з багаторядковими командами

Іноді команда займає кілька рядків. Це може відбуватися, коли:

- не закриті лапки;
- відкрита дужка;
- команда завершується символом `\`;
- Bash очікує продовження введення.

### 8.1. Перенесення рядка через `\`

Символ зворотної скісної риски `\` наприкінці рядка дозволяє продовжити команду на наступному рядку.

Приклад:

    mkdir -p \
      projects/linux/practice \
      projects/linux/notes

Після натискання `Enter` на першому рядку Bash чекатиме продовження команди.

Зворотна скісна риска повинна бути останнім символом рядка — після неї не потрібно ставити пробіли.

### 8.2. Як скасувати незавершене введення

Якщо Bash показує запрошення продовження введення, наприклад:

    >

і ти розумієш, що почав команду помилково, натисни:

    Ctrl + C

Bash скасує поточне введення та поверне звичайне запрошення командного рядка.

## 9. Гарячі клавіші у файловому менеджері та графічному середовищі

Не всі гарячі клавіші, які працюють у Linux, належать Bash. Частина комбінацій визначається графічним середовищем або конкретним застосунком.

| Комбінація | Типова дія |
|---|---|
| `Ctrl + C` | Копіювати виділений текст або файл у графічному застосунку |
| `Ctrl + V` | Вставити скопійований текст або файл |
| `Ctrl + X` | Вирізати виділений текст або файл |
| `Ctrl + A` | Виділити все у графічному застосунку |
| `Ctrl + Z` | Скасувати останню дію в багатьох редакторах |
| `Ctrl + Shift + C` | Часто копіювати виділений текст у терміналі |
| `Ctrl + Shift + V` | Часто вставити текст у термінал |
| `Shift + PageUp` | Переглянути попередній вміст термінала, якщо підтримується |
| `Shift + PageDown` | Переглянути наступний вміст термінала, якщо підтримується |

### Важливо: копіювання в терміналі

У багатьох графічних терміналах Linux:

- `Ctrl + C` не копіює текст, а надсилає переривання поточному процесу.
- `Ctrl + V` не вставляє текст так, як у звичайному текстовому редакторі.
- Для копіювання використовують `Ctrl + Shift + C`.
- Для вставлення використовують `Ctrl + Shift + V`.

Однак точна поведінка залежить від емулятора термінала.

У терміналі Ubuntu можна також перевірити контекстне меню правою кнопкою миші.

## 10. Мінімальний набір для щоденної роботи

Якщо ти тільки починаєш працювати з Linux, не потрібно відразу запам'ятовувати всі комбінації.

Почни з цих десяти:

| Комбінація | Для чого потрібна |
|---|---|
| `Ctrl + C` | Зупинити поточну команду або сервер |
| `Ctrl + L` | Очистити екран |
| `Ctrl + A` | Перейти на початок рядка |
| `Ctrl + E` | Перейти в кінець рядка |
| `Ctrl + U` | Видалити текст до початку рядка |
| `Ctrl + K` | Видалити текст до кінця рядка |
| `Ctrl + W` | Видалити попереднє слово |
| `↑` / `↓` | Перегляд історії команд |
| `Ctrl + R` | Знайти команду в історії |
| `Tab` | Автодоповнення команд і шляхів |

Коли ці комбінації стануть звичними, додай `Ctrl + Z`, `Ctrl + Y`, `Alt + B` і `Alt + F`.

## 11. Практика в терміналі

Мета практики — не просто прочитати таблицю, а навчитися використовувати комбінації клавіш під час реальної роботи.

### Вправа 1. Навігація по рядку

1. Введи команду, але не натискай `Enter`:

       mkdir -p projects/linux/practice

2. Натисни `Ctrl + A`.
3. Натисни `Ctrl + E`.
4. Натисни `Ctrl + A`, а потім кілька разів `Alt + F`.
5. Перевір, як змінюється положення курсора.
6. Натисни `Ctrl + C`, щоб скасувати введення команди.

Очікуваний результат: ти можеш переміщатися по команді, не видаляючи її.

### Вправа 2. Видалення частини команди

1. Введи:

       echo Hello Linux Terminal

2. Не натискай `Enter`.
3. Натисни `Ctrl + A`.
4. Натисни `Ctrl + K`.
5. Натисни `Ctrl + Y`.
6. Натисни `Ctrl + C`.

Очікуваний результат: ти побачиш, як працюють видалення та відновлення тексту.

### Вправа 3. Історія команд

Виконай команди:

    pwd
    ls
    whoami
    date

Потім:

1. Натисни `↑` кілька разів.
2. Натисни `↓`, щоб повернутися до новіших команд.
3. Натисни `Ctrl + R`.
4. Введи `pwd`.
5. Натисни `Ctrl + G`, щоб скасувати пошук.

Очікуваний результат: ти вмієш знаходити раніше використані команди.

### Вправа 4. Переривання процесу

1. Запусти:

       sleep 60

2. Натисни `Ctrl + C`.
3. Переконайся, що знову бачиш запрошення Bash.

Очікуваний результат: ти вмієш перервати процес, який виконується в терміналі.

### Вправа 5. Призупинення процесу

1. Запусти:

       sleep 100

2. Натисни `Ctrl + Z`.
3. Перевір список завдань:

       jobs

4. Поверни процес на передній план:

       fg

5. Натисни `Ctrl + C`, щоб завершити його.

Очікуваний результат: ти розумієш різницю між перериванням і призупиненням процесу.

### Вправа 6. Автодоповнення

1. Перейди в домашній каталог:

       cd ~

2. Введи:

       cd pro

3. Натисни `Tab`.
4. Якщо команда доповнилася до `projects/`, натисни `Enter`.
5. Якщо не доповнилася, натисни `Tab` двічі та перевір доступні варіанти.

Очікуваний результат: ти вмієш користуватися автодоповненням шляхів.

## 12. Типові помилки

### Помилка 1. Використання `Ctrl + C` для копіювання в терміналі

У більшості графічних терміналів `Ctrl + C` надсилає переривання процесу.

**Правильно:** для копіювання тексту часто використовують `Ctrl + Shift + C`.

### Помилка 2. Плутанина між `Ctrl + C` і `Ctrl + Z`

Ці комбінації виконують різні дії.

- `Ctrl + C` — переривання процесу.
- `Ctrl + Z` — призупинення процесу.

Призупинений процес може залишатися у списку завдань Bash.

### Помилка 3. Натискання `Ctrl + D` без розуміння наслідків

На порожньому рядку Bash `Ctrl + D` зазвичай завершує оболонку.

**Порада:** якщо хочеш лише очистити екран, використовуй `Ctrl + L`.

### Помилка 4. Очікування однакової поведінки в усіх терміналах

Графічні термінали можуть перехоплювати частину комбінацій клавіш або змінювати їхню поведінку.

**Порада:** перевіряй комбінації у своєму терміналі та вивчай налаштування застосунку.

### Помилка 5. Випадкове виконання команди під час практики

Якщо ти тренуєшся редагувати команду, не натискай `Enter`, доки не переконаєшся, що готовий її виконати.

Для скасування поточного введення використовуй `Ctrl + C`.

### Помилка 6. Введення паролів у командний рядок

Історія Bash може зберігати команди. Не варто передавати паролі або секретні токени як звичайні аргументи команд, якщо є безпечніший спосіб.

## 14. Додаткові матеріали та команди

### Перевірити поточну оболонку

    echo "$SHELL"

Ця команда показує оболонку, налаштовану як стандартну для користувача. Вона не завжди визначає оболонку, яка фактично виконується в поточній сесії.

Для перевірки поточного процесу оболонки можна використати:

    ps -p $$ -o comm=

### Переглянути історію команд

    history

Показує історію команд поточної оболонки, доступну через механізм історії Bash.

### Переглянути довідку Bash

    help

Показує список вбудованих команд Bash.

Для отримання довідки щодо конкретної вбудованої команди:

    help jobs
    help fg
    help history

### Перевірити налаштування Readline

Якщо існує файл `.inputrc` у домашньому каталозі, він може містити користувацькі налаштування клавіатури.

    cat ~/.inputrc

Якщо файл не існує, команда може повідомити про помилку. Це нормально.

Докладніше про налаштування:

    man bash

У довідці Bash шукай розділи `Readline`, `Commands for Moving`, `Commands for Killing` та `Commands for History`.

## 17. Що потрібно запам'ятати

- Гарячі клавіші допомагають швидше працювати з командним рядком.
- `Ctrl + A` і `Ctrl + E` — основні комбінації для навігації по рядку.
- `Ctrl + U`, `Ctrl + K` і `Ctrl + W` допомагають редагувати команди.
- `↑`, `↓` і `Ctrl + R` дозволяють повторно використовувати історію команд.
- `Tab` автоматично доповнює назви команд і шляхи.
- `Ctrl + C` зазвичай перериває поточний процес, а `Ctrl + Z` призупиняє його.
- `Ctrl + L` очищає видиму область термінала.
- `Ctrl + D` може завершити поточну оболонку, якщо натиснути його на порожньому рядку.
- Копіювання та вставлення в терміналі часто потребують `Ctrl + Shift + C` і `Ctrl + Shift + V`.
- Поведінка деяких комбінацій залежить від термінала, оболонки та їхніх налаштувань.

**Головна порада:** не намагайся вивчити всі комбінації за один день. Почни з `Ctrl + C`, `Ctrl + L`, `Ctrl + A`, `Ctrl + E`, `Ctrl + R` і `Tab`. Використовуй їх щодня — і поступово робота в Linux-терміналі стане швидшою та зручнішою.

# 05. ARCHIVE EXTRACTION — розпакування архівів у Linux

Розпакування архівів — це процес вилучення файлів і директорій зі стиснених або звичайних архівів у файлову систему.

У Linux для роботи з архівами використовують різні утиліти залежно від формату файлу:

- `tar` — перегляд і розпакування TAR-архівів;
- `gzip` і `gunzip` — розпакування файлів `.gz`;
- `unzip` — перегляд і розпакування ZIP-архівів;
- `7z` — робота з багатьма форматами архівів;
- `file` — визначення типу файлу;
- `find` — пошук розпакованих файлів і директорій.

Головне правило: **перед розпакуванням незнайомого архіву перевір його формат, вміст і місце призначення.**

## 1. Для чого потрібне розпакування архівів

Розпакування використовують, щоб:

- ✔ відновити файли з резервної копії;
- ✔ розпакувати завантажений архів;
- ✔ отримати вихідний код проєкту;
- ✔ відновити структуру директорій;
- ✔ витягнути окремі файли без розпакування всього архіву;
- ✔ перевірити вміст архіву перед використанням;
- ✔ розмістити файли в конкретній директорії;
- ✔ уникнути випадкового перезаписування наявних файлів.

Наприклад, завантажений файл:

    project.tar.gz

може містити таку структуру:

    project/
    ├── README.md
    ├── package.json
    └── src/
        ├── app.js
        └── styles.css

Після розпакування ця структура буде відновлена у файловій системі.

## 2. Визначення формату архіву

Перед розпакуванням потрібно визначити, з яким форматом маємо справу.

### 2.1. Переглянути назву файлу

    ls -lh

Типові розширення:

| Розширення | Формат | Основна команда |
|---|---|---|
| `.tar` | TAR-архів без додаткового стиснення | `tar -xf` |
| `.tar.gz` | TAR + GZIP | `tar -xzf` |
| `.tgz` | TAR + GZIP | `tar -xzf` |
| `.tar.bz2` | TAR + BZIP2 | `tar -xjf` |
| `.tar.xz` | TAR + XZ | `tar -xJf` |
| `.gz` | GZIP-стиснений файл | `gunzip` |
| `.zip` | ZIP-архів | `unzip` |
| `.7z` | 7-Zip-архів | `7z x` |
| `.rar` | RAR-архів | `7z x` або відповідний RAR-інструмент |

Розширення допомагає визначити формат, але не гарантує його правильність.

### 2.2. Визначити тип файлу командою `file`

    file archive.tar.gz
    file archive.zip
    file report.gz

Команда аналізує вміст файлу й показує його тип.

Наприклад, результат може бути таким:

    archive.tar.gz: gzip compressed data

### 2.3. Перевірити наявність утиліт

    command -v tar
    command -v gzip
    command -v gunzip
    command -v unzip
    command -v 7z

Якщо команда нічого не вивела, відповідна утиліта може бути не встановлена або недоступна через `PATH`.

**Важливо:** `tar` і `gzip` зазвичай уже доступні в Ubuntu. Для ZIP може знадобитися встановити `unzip`.

## 3. Перегляд вмісту перед розпакуванням

Не потрібно одразу розпаковувати архів, щоб дізнатися, що в ньому міститься.

### 3.1. Переглянути TAR

    tar -tf archive.tar

### 3.2. Переглянути TAR.GZ

    tar -tzf archive.tar.gz

### 3.3. Переглянути TAR.BZ2

    tar -tjf archive.tar.bz2

### 3.4. Переглянути TAR.XZ

    tar -tJf archive.tar.xz

### 3.5. Переглянути ZIP

    unzip -l archive.zip

Ці команди показують список файлів і директорій без повного розпакування.

### 3.6. Переглянути докладну інформацію

Для TAR:

    tar -tvf archive.tar

Для ZIP:

    unzip -lv archive.zip

Докладний список може показувати розміри, права доступу, дати та інші атрибути.

### 3.7. Що перевірити у вмісті

Перед розпакуванням зверни увагу на:

- незнайомі або несподівані назви файлів;
- надмірно глибоку структуру директорій;
- абсолютні шляхи;
- шляхи з `../`, які намагаються вийти за межі директорії;
- символічні посилання;
- дуже велику кількість файлів;
- потенційно небезпечні скрипти або виконувані файли.

Не запускай скрипти з архіву лише тому, що архів успішно розпакувався.

## 4. Розпакування TAR-архівів

### 4.1. Розпакувати `.tar`

    tar -xf archive.tar

Опції:

- `-x` — витягнути файли;
- `-f` — указати файл архіву.

Файли будуть розпаковані відносно поточної директорії відповідно до шляхів, записаних в архіві.

### 4.2. Розпакувати з відображенням файлів

    tar -xvf archive.tar

Опція `-v` показує, які файли обробляються.

### 4.3. Розпакувати `.tar.gz`

    tar -xzf archive.tar.gz

Опція `-z` вказує, що TAR-архів стиснений GZIP.

### 4.4. Розпакувати `.tar.bz2`

    tar -xjf archive.tar.bz2

Опція `-j` використовує BZIP2.

### 4.5. Розпакувати `.tar.xz`

    tar -xJf archive.tar.xz

Опція `-J` використовує XZ.

### 4.6. Розпакувати в конкретну директорію

Спочатку створи директорію:

    mkdir -p extracted

Потім розпакуй архів:

    tar -xf archive.tar -C extracted/

Для TAR.GZ:

    tar -xzf archive.tar.gz -C extracted/

Опція `-C` задає директорію, у якій потрібно виконати операцію. Вона має існувати до запуску команди.

### 4.7. Витягнути окремий файл із TAR

Припустімо, архів містить `project/README.md`.

    tar -xf archive.tar project/README.md

Команда витягне лише цей файл.

Шлях має відповідати шляху всередині архіву. Спочатку перевір його:

    tar -tf archive.tar

## 5. Розпакування GZIP

GZIP зазвичай стискає один файл, а не цілу структуру директорій.

### 5.1. Розпакувати `.gz`

    gunzip report.txt.gz

Зазвичай команда створює `report.txt` і видаляє `report.txt.gz`.

### 5.2. Розпакувати, зберігши оригінальний архів

    gunzip -k report.txt.gz

Опція `-k` залишає стиснений файл.

### 5.3. Використати `gzip -d`

    gzip -d report.txt.gz

Це альтернативний спосіб розпакування GZIP.

Зберегти архів:

    gzip -dk report.txt.gz

### 5.4. Вивести вміст без створення розпакованого файлу

    gzip -dc report.txt.gz

Щоб записати результат у новий файл:

    gzip -dc report.txt.gz > restored-report.txt

Обережно з `>`: якщо файл призначення вже існує, його вміст зазвичай буде перезаписаний.

### 5.5. Перевірити цілісність GZIP

    gzip -t report.txt.gz

Якщо перевірка проходить успішно, команда зазвичай нічого не виводить.

**Пам'ятай:** `.gz` і `.tar.gz` — це різні випадки. Для `.gz` зазвичай використовують `gunzip`, а для `.tar.gz` — `tar -xzf`.

## 6. Розпакування ZIP

### 6.1. Розпакувати в поточну директорію

    unzip archive.zip

### 6.2. Розпакувати в іншу директорію

    mkdir -p extracted
    unzip archive.zip -d extracted/

Опція `-d` задає директорію призначення.

### 6.3. Витягнути один файл

    unzip archive.zip README.md

Якщо файл міститься у вкладеній директорії:

    unzip archive.zip project/README.md

Використовуй точний шлях, який показує команда:

    unzip -l archive.zip

### 6.4. Перевірити ZIP перед розпакуванням

    unzip -t archive.zip

### 6.5. Не перезаписувати наявні файли

    unzip -n archive.zip

Опція `-n` забороняє перезаписування наявних файлів.

### 6.6. Перезаписати файли без запитань

    unzip -o archive.zip

Опція `-o` дозволяє перезаписування без підтвердження.

Використовуй її лише тоді, коли точно знаєш, що наявні файли можна замінити.

## 7. Розпакування архівів 7-Zip

Для роботи з форматом `.7z` можна використовувати утиліту `7z`.

### 7.1. Перевірити, чи встановлено 7-Zip

    command -v 7z

Якщо утиліти немає, в Ubuntu можна встановити пакет:

    sudo apt update
    sudo apt install 7zip

Назва пакета залежить від версії Ubuntu та доступних репозиторіїв. Якщо пакет із такою назвою недоступний, перевір, який пакет надає команду `7z` у твоєму випуску Ubuntu.

### 7.2. Переглянути вміст архіву

    7z l archive.7z

### 7.3. Перевірити архів

    7z t archive.7z

### 7.4. Розпакувати зі збереженням структури директорій

    7z x archive.7z

Команда `x` витягує файли зі збереженням шляхів, записаних в архіві.

### 7.5. Розпакувати в конкретну директорію

    mkdir -p extracted
    7z x archive.7z -oextracted/

Зверни увагу: у параметрі `-o` шлях указується без пробілу між опцією та значенням.

### 7.6. Витягнути файли без збереження структури директорій

    7z e archive.7z

Опція `e` витягує файли без відтворення повної структури шляхів. Якщо в різних директоріях є файли з однаковими назвами, це може спричинити конфлікти.

## 8. Розпакування RAR-архівів

RAR — це окремий формат архівів. Для нього потрібна утиліта, що підтримує RAR.

Якщо встановлено 7-Zip із підтримкою відповідного формату:

    7z l archive.rar
    7z t archive.rar
    7z x archive.rar

Якщо RAR не підтримується встановленою версією 7-Zip, потрібно використати сумісний інструмент, наприклад `unrar`, якщо він доступний у репозиторіях системи.

Перевірити наявність утиліти:

    command -v unrar

Приклади команд для `unrar`:

    unrar l archive.rar
    unrar t archive.rar
    unrar x archive.rar

Для розпакування в конкретну директорію:

    mkdir -p extracted
    unrar x archive.rar extracted/

Синтаксис і доступність інструментів залежать від встановленого пакета.

## 9. Вибір місця розпакування

Правильний вибір директорії допомагає уникнути плутанини та перезаписування файлів.

### 9.1. Перевірити поточну директорію

    pwd

### 9.2. Переглянути вміст

    ls -la

### 9.3. Створити окрему директорію для розпакування

    mkdir -p ~/tmp/archive-test

### 9.4. Розпакувати архів у неї

Для TAR.GZ:

    tar -xzf archive.tar.gz -C ~/tmp/archive-test/

Для ZIP:

    unzip archive.zip -d ~/tmp/archive-test/

### 9.5. Перевірити результат

    find ~/tmp/archive-test -maxdepth 4 -print

Опція `-maxdepth 4` обмежує глибину обходу. Це допомагає швидко перевірити структуру без виведення всіх вкладених елементів великого проєкту.

**Практичне правило:** незнайомі архіви спочатку розпаковуй у нову директорію, а вже потім переміщуй потрібні файли.

## 10. Як уникнути зайвого рівня вкладеності

Іноді архів містить директорію верхнього рівня:

    project/
    ├── README.md
    ├── package.json
    └── src/

Після розпакування в `~/projects/` отримаємо:

    ~/projects/project/
    ├── README.md
    ├── package.json
    └── src/

Це зазвичай очікувана поведінка.

Але якщо архів уже містить кілька рівнів директорій, може з'явитися структура на кшталт:

    ~/projects/project/project/src/

Щоб уникнути несподіванок, перед розпакуванням перевір список:

    tar -tf archive.tar.gz

або:

    unzip -l archive.zip

Якщо потрібно побачити файли без повного префікса, обирай місце розпакування відповідно до структури архіву. Не змінюй шляхи навмання, якщо не розумієш, які файли будуть створені.

## 11. Розпакування архіву з вкладеною директорією

Припустімо, архів містить:

    backup/
    ├── app/
    │   ├── README.md
    │   └── src/
    └── config/

Щоб розпакувати його в `~/restore/`:

    mkdir -p ~/restore
    tar -xzf backup.tar.gz -C ~/restore/

Результат:

    ~/restore/backup/app/
    ~/restore/backup/config/

Щоб витягнути лише `README.md`, спочатку перевір шлях:

    tar -tzf backup.tar.gz

Потім:

    tar -xzf backup.tar.gz -C ~/restore/ backup/app/README.md

Тут `-C` задає директорію призначення, а останній аргумент — конкретний шлях усередині архіву.

## 12. Робота з архівами у файловому менеджері Ubuntu

Архіви можна розпаковувати не лише в терміналі, а й у графічному інтерфейсі.

Залежно від файлового менеджера та встановлених утиліт:

1. Відкрий директорію з архівом.
2. Натисни на архів правою кнопкою миші.
3. Обери дію на кшталт «Витягнути сюди» або «Витягнути до…».
4. За потреби вибери директорію призначення.
5. Перевір отримані файли.

Графічний інтерфейс зручний для одноразових операцій, але термінал краще підходить для навчання, автоматизації та роботи із сервером.

## 13. Розпакування архівів із правами доступу

Архіви можуть містити інформацію про права доступу, власників і часові мітки.

### 13.1. Переглянути права в TAR

    tar -tvf archive.tar

### 13.2. Розпакувати зі збереженням прав доступу

    tar -xpf archive.tar

Опція `-p` просить зберегти права доступу. Фактичний результат залежить від прав поточного користувача та налаштувань системи.

### 13.3. Чому не варто одразу використовувати `sudo`

Команда:

    sudo tar -xpf archive.tar -C /

може змінити системні файли та права доступу. Не використовуй її для звичайного розпакування навчального проєкту.

Для більшості власних файлів достатньо працювати у своїй домашній директорії без адміністративних прав.

## 14. Безпека під час розпакування

Архів може містити небезпечні файли або несподівані шляхи.

Основні правила:

- ✔ перевіряй вміст архіву перед розпакуванням;
- ✔ використовуй окрему директорію для невідомих архівів;
- ✔ не запускай незнайомі скрипти автоматично;
- ✔ не використовуй `sudo` без реальної потреби;
- ✔ уникай автоматичного перезаписування файлів;
- ✔ перевіряй джерело архіву;
- ✔ не передавай конфіденційні дані в незахищених архівах.

### 14.1. Перевірити список файлів

    tar -tzf downloaded.tar.gz
    unzip -l downloaded.zip

### 14.2. Перевірити цілісність

    gzip -t downloaded.gz
    unzip -t downloaded.zip
    7z t downloaded.7z

Для TAR.GZ можна перевірити GZIP-стиснення:

    gzip -t downloaded.tar.gz

Це перевіряє стиснений потік, але не замінює перевірку структури TAR та безпеки його вмісту.

### 14.3. Не довіряй лише розширенню

Файл із назвою `archive.zip` не обов'язково є справжнім ZIP-архівом.

Перевір тип:

    file archive.zip

Якщо файл пошкоджений або має невідповідний формат, не намагайся бездумно застосовувати до нього всі можливі утиліти.

## 15. Типові помилки

### Помилка 1. Використовують неправильну команду для формату

Неправильно:

    unzip archive.tar.gz

Правильно:

    tar -xzf archive.tar.gz

Для ZIP:

    unzip archive.zip

### Помилка 2. Плутають `.gz` та `.tar.gz`

Для звичайного GZIP-файлу:

    gunzip report.txt.gz

Для TAR.GZ:

    tar -xzf archive.tar.gz

Перший випадок зазвичай відновлює один файл, другий — структуру архіву з файлами й директоріями.

### Помилка 3. Не перевіряють поточну директорію

    pwd

Перед розпакуванням перевір, де перебуваєш, щоб не створити файли у випадковому місці.

### Помилка 4. Розпаковують поверх важливих файлів

Краще спочатку створити нову директорію:

    mkdir -p extracted
    unzip archive.zip -d extracted/

### Помилка 5. Забувають створити директорію для `-C`

Неправильно, якщо директорії ще немає:

    tar -xf archive.tar -C extracted/

Правильно:

    mkdir -p extracted
    tar -xf archive.tar -C extracted/

### Помилка 6. Вважають, що розпакування гарантує безпеку

Навіть справний архів може містити небажані скрипти, виконувані файли або шкідливий вміст.

Перевіряй файли перед запуском.

### Помилка 7. Використовують `sudo` без потреби

Не потрібно розпаковувати звичайний архів проєкту від імені адміністратора. Це може створити файли, якими потім буде незручно керувати без `sudo`.

### Помилка 8. Не перевіряють результат

Після розпакування перевір:

    ls -la
    find extracted -maxdepth 4 -print

Якщо це резервна копія, додатково перевір, чи потрібні файли можна відкрити та використати.

## 16. Практичний приклад: відновлення проєкту

Припустімо, маємо архів:

    nest-exercises-backup.tar.gz

### Крок 1. Перевірити формат

    file nest-exercises-backup.tar.gz

### Крок 2. Переглянути вміст

    tar -tzf nest-exercises-backup.tar.gz

### Крок 3. Створити директорію для відновлення

    mkdir -p ~/restore-test

### Крок 4. Розпакувати архів

    tar -xzf nest-exercises-backup.tar.gz -C ~/restore-test/

### Крок 5. Переглянути результат

    find ~/restore-test -maxdepth 4 -print

### Крок 6. Перевірити файли проєкту

    ls -la ~/restore-test/

Якщо архів містить директорію `nest-exercises/`, перевір її:

    ls -la ~/restore-test/nest-exercises/

### Крок 7. Переконатися, що проєкт можна відновити

Якщо це Node.js-проєкт, перевір наявність `package.json` і файлів, необхідних для запуску.

    find ~/restore-test -name package.json -print

Після цього можна перейти до відповідної директорії та встановити залежності за потреби.

Не запускай автоматично невідомі скрипти з архіву, перш ніж перевіриш їхній вміст.

## 17. Мінішпаргалка

    # Визначити тип файлу
    file archive.tar.gz

    # Переглянути TAR
    tar -tf archive.tar

    # Переглянути TAR.GZ
    tar -tzf archive.tar.gz

    # Переглянути ZIP
    unzip -l archive.zip

    # Розпакувати TAR
    tar -xf archive.tar

    # Розпакувати TAR.GZ
    tar -xzf archive.tar.gz

    # Розпакувати TAR.BZ2
    tar -xjf archive.tar.bz2

    # Розпакувати TAR.XZ
    tar -xJf archive.tar.xz

    # Розпакувати TAR.GZ у конкретну директорію
    mkdir -p extracted
    tar -xzf archive.tar.gz -C extracted/

    # Розпакувати GZIP
    gunzip report.txt.gz

    # Розпакувати GZIP, залишивши архів
    gunzip -k report.txt.gz

    # Перевірити GZIP
    gzip -t report.txt.gz

    # Розпакувати ZIP
    unzip archive.zip

    # Розпакувати ZIP у конкретну директорію
    unzip archive.zip -d extracted/

    # Переглянути ZIP
    unzip -l archive.zip

    # Перевірити ZIP
    unzip -t archive.zip

    # Не перезаписувати наявні файли
    unzip -n archive.zip

    # Переглянути вміст 7-Zip
    7z l archive.7z

    # Перевірити 7-Zip
    7z t archive.7z

    # Розпакувати 7-Zip
    7z x archive.7z

## 18. Що потрібно пам'ятати

- `tar -xf` розпаковує TAR.
- `tar -xzf` розпаковує TAR.GZ.
- `tar -xjf` розпаковує TAR.BZ2.
- `tar -xJf` розпаковує TAR.XZ.
- `gunzip` розпаковує звичайний GZIP-файл.
- `unzip` розпаковує ZIP.
- `7z x` розпаковує підтримувані формати архівів.
- `file` допомагає визначити формат файлу.
- `tar -tf` і `unzip -l` показують вміст без повного розпакування.
- `gzip -t`, `unzip -t` і `7z t` перевіряють цілісність відповідних форматів.
- `-C` у TAR і `-d` в UNZIP дозволяють вибрати місце розпакування.
- Перед роботою з невідомим архівом перевіряй його вміст.
- Не розпаковуй незнайомі архіви поверх важливих файлів.
- Не використовуй `sudo`, якщо адміністративні права не потрібні.
- Успішне розпакування не гарантує, що файли безпечні або працездатні.

## 19. Шлях вивчення Archive Extraction

### Core — базовий рівень

- Розпаковувати `.tar`, `.tar.gz` і `.zip`.
- Переглядати вміст архівів.
- Визначати формат через `file`.
- Розпаковувати в окрему директорію.
- Перевіряти цілісність архівів.

### Junior — практичний рівень

- Витягувати окремі файли з архіву.
- Працювати з BZIP2, XZ та 7-Zip.
- Уникати перезаписування локальних файлів.
- Відновлювати структуру навчального проєкту.
- Перевіряти результат розпакування через `find` і `ls`.

### Middle — поглиблений рівень

- Безпечно відновлювати резервні копії.
- Розуміти вплив прав доступу та власників файлів.
- Виявляти проблеми з форматами та пошкодженими архівами.
- Планувати відновлення проєктів і даних.
- Перевіряти, чи можна реально скористатися відновленими файлами.

### Senior — системний рівень

- Розробляти процедури безпечного відновлення даних.
- Перевіряти архіви перед розгортанням.
- Враховувати права доступу, символічні посилання та структуру шляхів.
- Автоматизувати перевірку й відновлення резервних копій.
- Визначати політику відновлення для серверів і систем.

## Головне

Розпакування — це не просто запуск однієї команди. Потрібно знати формат архіву, перевіряти його вміст, обирати правильну директорію та уникати випадкового перезаписування файлів.

Для більшості щоденних задач достатньо цих команд:

    tar -tzf archive.tar.gz       # переглянути TAR.GZ
    tar -xzf archive.tar.gz       # розпакувати TAR.GZ

    unzip -l archive.zip          # переглянути ZIP
    unzip archive.zip -d out/     # розпакувати ZIP у out/

    gunzip report.txt.gz          # розпакувати GZIP
    gzip -t report.txt.gz         # перевірити GZIP

**Безпечна звичка:** спочатку переглянь вміст архіву, потім розпакуй його в окрему директорію, а після цього перевір отримані файли.

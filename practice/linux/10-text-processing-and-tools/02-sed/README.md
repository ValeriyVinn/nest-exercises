# 02. sed

`sed` (Stream Editor) — потоковий редактор тексту в Linux, який дозволяє автоматично шукати, замінювати, видаляти, вибирати та перетворювати текст.

`sed` обробляє вхідний текст рядок за рядком і за замовчуванням виводить результат у стандартний вивід (stdout), не змінюючи оригінальний файл.

`sed` використовується, коли потрібно:

- замінити текст у файлі;
- замінити всі входження слова або символу;
- видалити певні рядки;
- вибрати рядки за номером або шаблоном;
- видалити порожні рядки;
- прибрати коментарі з конфігураційних файлів;
- обробити текст за допомогою регулярних виразів;
- автоматично редагувати файли в Bash-скриптах;
- виконувати масові перетворення тексту;
- створювати прості текстові конвеєри разом із `grep`, `awk`, `cut` та іншими командами.

`sed` особливо корисний для автоматизації роботи з конфігураціями, логами, текстовими файлами та вихідним кодом.

## Що потрібно пам'ятати

• `sed` — це потоковий редактор тексту.

• За замовчуванням `sed` не змінює оригінальний файл, а виводить результат у stdout.

• Основна команда для заміни тексту — `s`.

• Загальний синтаксис заміни:

    sed 's/OLD/NEW/' file.txt

• За замовчуванням `s` замінює лише перше входження шаблону в кожному обробленому рядку.

• Прапорець `g` замінює всі входження шаблону в кожному рядку:

    sed 's/OLD/NEW/g' file.txt

• `-n` вимикає автоматичне виведення рядків.

• Команда `p` виводить вибраний рядок.

• Команда `d` видаляє рядок із поточного потоку обробки.

• Команда `q` завершує роботу `sed`.

• `-E` дозволяє використовувати Extended Regular Expressions (ERE).

• `-i` змінює файл безпосередньо, тому потрібно бути обережним.

• Щоб зберегти резервну копію під час редагування, у GNU sed можна використовувати `-i.bak`.

• Адреси дозволяють застосовувати команди до конкретних рядків або діапазонів.

• `sed` добре підходить для простих і середньої складності перетворень тексту.

• Для складної обробки колонок і структурованих даних часто зручніше використовувати `awk`.

• Для пошуку рядків без їх зміни часто достатньо `grep`.

• Під час використання `sed` у Bash важливо враховувати лапки, екранування та інтерпретацію регулярних виразів.

# Що таке sed

`sed` читає текст, обробляє його за заданими правилами та виводить результат.

Наприклад, файл `message.txt`:

    Hello Linux
    Hello Bash
    Hello Developer

Команда:

    sed 's/Hello/Welcome/' message.txt

Результат:

    Welcome Linux
    Welcome Bash
    Welcome Developer

Оригінальний файл `message.txt` залишається незмінним.

Команда:

    sed 's/Hello/Welcome/' message.txt

має такі частини:

    sed                  → запуск редактора
    s                    → команда substitution
    Hello                → шаблон пошуку
    Welcome              → текст заміни
    message.txt          → вхідний файл

Загальна модель:

    Input
      ↓
    sed command
      ↓
    Text transformation
      ↓
    Output

---

# Основний синтаксис

Загальна форма:

    sed [OPTIONS] 'COMMAND' FILE

Наприклад:

    sed 's/cat/dog/' animals.txt

Де:

    sed       → команда
    OPTIONS   → необов'язкові параметри
    COMMAND   → інструкція обробки тексту
    FILE      → вхідний файл

Можна передавати текст через stdin:

    echo 'Hello Linux' | sed 's/Linux/Bash/'

Результат:

    Hello Bash

Можна обробляти результат іншої команди:

    grep 'ERROR' app.log | sed 's/ERROR/PROBLEM/'

Тут:

    grep → вибирає рядки
    sed  → замінює текст у вибраних рядках

---

# Перший приклад

Створи файл:

    nano users.txt

Додай текст:

    user1
    user2
    user3

Заміни `user` на `developer`:

    sed 's/user/developer/' users.txt

Результат:

    developer1
    developer2
    developer3

Перевір файл:

    cat users.txt

Оригінальний текст залишиться:

    user1
    user2
    user3

Це основна особливість звичайного режиму `sed`: результат показується у stdout, а не записується назад у файл.

# Substitution — s

Команда `s` використовується для пошуку та заміни тексту.

Синтаксис:

    s/PATTERN/REPLACEMENT/FLAGS

Наприклад:

    sed 's/Linux/Ubuntu/' file.txt

Тут:

    s           → substitution
    Linux       → шаблон пошуку
    Ubuntu      → текст заміни
    FLAGS       → необов'язкові прапорці

Файл:

    I use Linux.
    Linux is powerful.
    Linux is flexible.

Команда:

    sed 's/Linux/Ubuntu/' file.txt

Результат:

    I use Ubuntu.
    Ubuntu is powerful.
    Ubuntu is flexible.

У кожному рядку замінюється перше входження шаблону.

---

# Перша заміна в рядку

За замовчуванням `sed` замінює лише перше входження шаблону в кожному рядку.

Файл:

    Linux Linux Linux

Команда:

    sed 's/Linux/Ubuntu/' file.txt

Результат:

    Ubuntu Linux Linux

Чому?

Тому що без додаткових прапорців команда `s` виконує лише першу заміну в кожному рядку.

---

# Прапорець g — Global Replacement

Прапорець `g` означає глобальну заміну всіх входжень шаблону в кожному рядку.

Команда:

    sed 's/Linux/Ubuntu/g' file.txt

Для тексту:

    Linux Linux Linux

Результат:

    Ubuntu Ubuntu Ubuntu

Порівняй:

    sed 's/Linux/Ubuntu/' file.txt

Результат:

    Ubuntu Linux Linux

А:

    sed 's/Linux/Ubuntu/g' file.txt

Результат:

    Ubuntu Ubuntu Ubuntu

Важливо: `g` означає всі відповідні входження в межах кожного обробленого рядка, а не лише перше.

---

# Заміна без урахування регістру

У GNU sed можна використати прапорець `I` для пошуку без урахування регістру.

Наприклад:

    sed 's/linux/Ubuntu/I' file.txt

Для тексту:

    Linux
    LINUX
    linux

Результат:

    Ubuntu
    Ubuntu
    Ubuntu

Щоб замінити всі входження незалежно від регістру:

    sed 's/linux/Ubuntu/gI' file.txt

Прапорець `I` є розширенням GNU sed і не належить до переносимого базового синтаксису всіх реалізацій `sed`.

---

# Заміна з різними роздільниками

У команді `s` символ `/` зазвичай використовується як роздільник.

Наприклад:

    sed 's/old/new/' file.txt

Але роздільник можна змінити.

Це особливо корисно для шляхів, URL та інших текстів, що містять `/`.

Замість:

    sed 's/\/home\/user/\/home\/developer/' paths.txt

можна використати:

    sed 's#/home/user#/home/developer#' paths.txt

Або:

    sed 's|old|new|' file.txt

Приклад із URL:

    echo 'http://example.com' | sed 's|http://|https://|'

Результат:

    https://example.com

Правило:

    s/OLD/NEW/
    s#OLD#NEW#
    s|OLD|NEW|

Роздільником може бути інший відповідний символ, якщо він не конфліктує з шаблоном або текстом заміни.

# Regex у sed

`sed` підтримує регулярні вирази для пошуку тексту.

За замовчуванням GNU sed використовує Basic Regular Expressions (BRE).

Приклад:

    sed 's/error/ERROR/' app.log

Знайде текст `error` та замінить його на `ERROR`.

Для використання Extended Regular Expressions можна додати `-E`:

    sed -E 's/[0-9]+/[NUMBER]/g' file.txt

Наприклад, для тексту:

    User 42 connected in 15 seconds

Результат:

    User [NUMBER] connected in [NUMBER] seconds

У режимі ERE:

    [0-9]+ → одна або більше цифр

---

## BRE vs ERE у sed

| Можливість | BRE | ERE через `-E` |
|---|---|---|
| Одна цифра | `[0-9]` | `[0-9]` |
| Крапка | `.` | `.` |
| Початок рядка | `^` | `^` |
| Кінець рядка | `$` | `$` |
| Один або більше | `\+` у GNU sed | `+` |
| Нуль або один | `\?` у GNU sed | `?` |
| Альтернатива | `\|` у GNU sed | `|` |
| Групування | `\(...\)` | `(...)` |
| Повторення `{n}` | `\{n\}` | `{n}` |

Для початкового рівня зручно використовувати `sed -E`, якщо шаблон містить `+`, `?`, `|`, групування або повторення.

Приклад:

    sed -E 's/(error|warning)/NOTICE/g' app.log

Це замінює `error` або `warning` на `NOTICE`.

---

# Anchors — початок і кінець рядка

Основні anchors:

    ^ → початок рядка
    $ → кінець рядка

Вони дозволяють застосовувати команди лише до рядків, які відповідають заданому розташуванню тексту.

## Замінити текст лише на початку рядка

Команда:

    sed 's/^ERROR/PROBLEM/' app.log

Текст:

    ERROR Database failed
    INFO ERROR found in message

Результат:

    PROBLEM Database failed
    INFO ERROR found in message

У другому рядку `ERROR` не стоїть на початку, тому він не змінюється.

## Замінити текст лише наприкінці рядка

    sed 's/failed$/FAILED/' app.log

Для тексту:

    Connection failed
    Connection failed again

Результат:

    Connection FAILED
    Connection failed again

## Додати текст на початок кожного рядка

    sed 's/^/INFO: /' app.log

Для тексту:

    Server started
    Request completed

Результат:

    INFO: Server started
    INFO: Request completed

## Додати текст у кінець кожного рядка

    sed 's/$/;/' file.txt

Для тексту:

    apple
    banana
    orange

Результат:

    apple;
    banana;
    orange;

# Видалення рядків — d

Команда `d` видаляє поточний рядок із потоку обробки.

Синтаксис:

    sed 'ADDRESSd' file.txt

Наприклад:

    sed '2d' file.txt

Видаляє другий рядок.

Файл:

    one
    two
    three
    four

Результат:

    one
    three
    four

Оригінальний файл не змінюється.

---

## Видалити перший рядок

    sed '1d' file.txt

## Видалити останній рядок

    sed '$d' file.txt

## Видалити перші три рядки

    sed '1,3d' file.txt

## Видалити рядки з 2-го по 5-й

    sed '2,5d' file.txt

## Видалити порожні рядки

    sed '/^$/d' file.txt

## Видалити рядки, що містять ERROR

    sed '/ERROR/d' app.log

## Видалити рядки, що починаються з #

    sed '/^#/d' config.txt

## Видалити коментарі з необов'язковими пробілами перед #

    sed -E '/^[[:space:]]*#/d' config.txt

Ця команда видаляє рядки, де після необов'язкових пробільних символів стоїть `#`.

---

# Адреси рядків — Line Addresses

Адреса визначає, до яких рядків застосовується команда `sed`.

Адресою може бути:

    номер рядка
    $
    regex pattern
    діапазон рядків

Наприклад:

    sed '3p' file.txt

Тут адреса:

    3

означає третій рядок.

Команда:

    p

означає вивести поточний рядок.

Однак без `-n` стандартний режим `sed` і так автоматично виводить кожен рядок. Тому рядок №3 буде показаний двічі.

Правильний спосіб показати лише третій рядок:

    sed -n '3p' file.txt

---

## Вибрати перший рядок

    sed -n '1p' file.txt

## Вибрати останній рядок

    sed -n '$p' file.txt

## Вибрати рядки з 2-го по 4-й

    sed -n '2,4p' file.txt

## Вибрати рядки, що містять ERROR

    sed -n '/ERROR/p' app.log

## Вибрати рядки, що починаються з INFO

    sed -n '/^INFO/p' app.log

## Вибрати рядки, що закінчуються на .js

    sed -n '/\.js$/p' files.txt

---

# Прапорець -n

За замовчуванням `sed` автоматично виводить кожен оброблений рядок.

Параметр:

    -n

вимикає автоматичне виведення.

Це корисно, коли потрібно показати лише рядки, вибрані командою `p`.

Наприклад:

    sed -n '2p' file.txt

Виведе лише другий рядок.

Інший приклад:

    sed -n '/ERROR/p' app.log

Виведе лише рядки, що містять `ERROR`.

Без `-n` команда:

    sed '/ERROR/p' app.log

виведе всі рядки, а рядки з `ERROR` — двічі.

Тому часто використовують комбінацію:

    sed -n '/PATTERN/p' file.txt

---

# Діапазони рядків

`sed` дозволяє застосовувати команду до діапазону рядків.

## Від 2-го до 5-го рядка

    sed -n '2,5p' file.txt

## Від першого до третього рядка

    sed -n '1,3p' file.txt

## Від другого рядка до кінця файлу

    sed -n '2,$p' file.txt

## Від рядка з BEGIN до рядка з END

    sed -n '/BEGIN/,/END/p' file.txt

Ця команда виводить рядки від першого рядка, що відповідає `BEGIN`, до рядка, що відповідає `END`, включно.

Якщо `END` не зустрічається, діапазон продовжується до кінця файлу.

## Видалити блок між BEGIN та END

    sed '/BEGIN/,/END/d' file.txt

## Замінити текст лише в певному діапазоні

    sed '2,5s/error/ERROR/g' app.log

Замінює `error` на `ERROR` лише в рядках із другого по п'ятий.

# Видалення та очищення тексту

`sed` часто використовують для очищення текстових файлів.

## Видалити порожні рядки

    sed '/^$/d' file.txt

## Видалити рядки, що містять лише пробіли

    sed -E '/^[[:space:]]*$/d' file.txt

## Видалити пробіли на початку рядка

    sed -E 's/^[[:space:]]+//' file.txt

## Видалити пробіли в кінці рядка

    sed -E 's/[[:space:]]+$//' file.txt

## Видалити пробіли на початку та в кінці рядка

    sed -E 's/^[[:space:]]+//; s/[[:space:]]+$//' file.txt

## Замінити послідовність пробільних символів одним пробілом

    sed -E 's/[[:space:]]+/ /g' file.txt

Ця команда також може замінити табуляції та інші пробільні символи звичайними пробілами.

## Видалити всі цифри

    sed -E 's/[0-9]//g' file.txt

## Видалити всі символи, крім цифр

    sed -E 's/[^0-9]//g' file.txt

## Видалити буквальні крапки

    sed 's/\.//g' file.txt

## Видалити коментарі, що починаються з #

    sed -E '/^[[:space:]]*#/d' config.txt

Цей шаблон видаляє цілі рядки-коментарі. Він не видаляє коментарі, розташовані після значення в тому самому рядку.

---

# Додавання тексту — i та a

`sed` має команди для вставлення нового тексту.

    i → insert: вставити текст перед адресованим рядком
    a → append: вставити текст після адресованого рядка

Синтаксис і формат перенесення рядків можуть дещо відрізнятися між реалізаціями `sed`.

## Додати рядок перед першим рядком

У GNU sed:

    sed '1i\Header' file.txt

Для тексту:

    apple
    banana

Результат:

    Header
    apple
    banana

## Додати рядок після другого рядка

    sed '2a\New line' file.txt

Для тексту:

    apple
    banana
    orange

Результат:

    apple
    banana
    New line
    orange

## Додати текст перед рядками, що містять ERROR

    sed '/ERROR/i\Attention:' app.log

## Додати текст після рядків, що містять ERROR

    sed '/ERROR/a\Check this event' app.log

# Заміна цілого рядка — c

Команда `c` замінює вибраний рядок або рядки новим текстом.

Синтаксис:

    ADDRESSc\NEW_TEXT

Наприклад:

    sed '2c\This is a new line' file.txt

Для файлу:

    apple
    banana
    orange

Результат:

    apple
    This is a new line
    orange

## Замінити рядок за шаблоном

    sed '/ERROR/c\An error was detected' app.log

Кожен рядок, який відповідає шаблону `ERROR`, буде замінений новим рядком.

Якщо відповідних рядків декілька, кожен із них буде замінений окремо.

---

# Друк рядків — p

Команда `p` виводить поточний рядок.

Найчастіше її використовують разом із `-n`.

## Вивести перший рядок

    sed -n '1p' file.txt

## Вивести останній рядок

    sed -n '$p' file.txt

## Вивести рядки з ERROR

    sed -n '/ERROR/p' app.log

## Вивести рядки з 3-го по 7-й

    sed -n '3,7p' file.txt

## Вивести рядки з цифрами

    sed -n '/[0-9]/p' file.txt

---

# Завершення роботи — q

Команда `q` завершує обробку та виходить із `sed`.

Наприклад:

    sed '5q' file.txt

Виведе перші п'ять рядків і завершить роботу.

Це може бути корисно для швидкого отримання початку великого файлу.

Однак для простого перегляду перших рядків зазвичай зрозуміліше використовувати:

    head -n 5 file.txt

Ще один приклад:

    sed -n '10q; 10p' file.txt

Ця команда виводить десятий рядок і завершує роботу після нього.

# In-place Editing — параметр -i

Параметр `-i` дозволяє змінювати файл безпосередньо.

Звичайна команда:

    sed 's/old/new/g' file.txt

Виводить змінений текст у stdout, але не змінює файл.

Команда:

    sed -i 's/old/new/g' file.txt

Записує зміни у файл `file.txt`.

**Увага:** `-i` змінює оригінальний файл. Перед використанням перевір команду без `-i`.

---

## Резервна копія під час редагування

У GNU sed можна створити резервну копію:

    sed -i.bak 's/old/new/g' file.txt

Результат:

    file.txt      → змінений файл
    file.txt.bak  → резервна копія

Це корисно для конфігураційних файлів і масових перетворень.

## Заміна порту в конфігурації

Припустимо, `config.txt` містить:

    PORT=3000

Команда:

    sed -i.bak 's/^PORT=3000$/PORT=4000/' config.txt

Після виконання:

    PORT=4000

Резервна копія залишиться у файлі:

    config.txt.bak

## Замінити всі входження в конкретному файлі

    sed -i 's/localhost/127.0.0.1/g' config.txt

Ця команда безпосередньо змінює файл.

Перед використанням на важливих даних бажано зробити резервну копію або спочатку перевірити результат без `-i`.

## Важливо про різні реалізації

Параметри `-i` та правила для резервних копій можуть відрізнятися між GNU sed у Linux та BSD/macOS sed.

Для Linux з GNU sed зазвичай працюють:

    sed -i 's/old/new/g' file.txt

    sed -i.bak 's/old/new/g' file.txt

# Backreferences — групи та посилання

Регулярні вирази дозволяють зберігати знайдені частини тексту в групах і використовувати їх у заміні.

У BRE групи записуються так:

    \(PATTERN\)

У ERE:

    (PATTERN)

У рядку заміни:

    \1

означає текст, який відповідає першій групі.

` \2 ` означає текст другої групи, ` \3 ` — третьої тощо.

## Поміняти місцями ім'я та прізвище

Файл:

    Svystun Valeriy
    Smith John

Команда GNU sed:

    sed -E 's/^([^ ]+) ([^ ]+)$/\2 \1/' names.txt

Результат:

    Valeriy Svystun
    John Smith

Пояснення:

    ^           → початок рядка
    ([^ ]+)     → перша група: перше слово
    space       → пробіл
    ([^ ]+)     → друга група: друге слово
    $           → кінець рядка

У заміні:

    \2 \1

друга група ставиться першою, а перша — другою.

## Знайти повторене слово

    sed -E 's/\b([[:alpha:]]+)[[:space:]]+\1\b/\1/g' file.txt

Цей приклад використовує `\b`, який не є переносимим POSIX ERE-синтаксисом у `sed`. У GNU sed для меж слова краще застосовувати відповідні GNU-розширення або будувати шаблон на основі явних класів символів.

Основна ідея backreferences:

    capture group → зберегти частину збігу
    \1            → використати першу групу
    \2            → використати другу групу

# Екранування символів

Деякі символи мають спеціальне значення в regex або в команді `sed`.

    .
    *
    [
    ]
    ^
    $
    /
    \

Щоб шукати буквальну крапку:

    sed 's/\.js/.ts/' files.txt

Для тексту:

    app.js

Результат:

    app.ts

Тут:

    \. → буквальна крапка

## Замінити буквальний символ $

    sed 's/\$/USD/g' prices.txt

## Замінити зірочку

    sed 's/\*/STAR/g' file.txt

## Замінити слеш у шляху

Можна екранувати `/`:

    sed 's/\/home\/user/\/home\/developer/' paths.txt

Або змінити роздільник:

    sed 's#/home/user#/home/developer#' paths.txt

Другий варіант часто читабельніший.

# Кілька команд sed

Можна виконувати кілька команд за один запуск.

## Спосіб 1 — розділити команди крапкою з комою

    sed 's/Linux/Ubuntu/g; s/Bash/Shell/g' file.txt

Ця команда:

    1. замінює Linux на Ubuntu
    2. замінює Bash на Shell

## Спосіб 2 — параметр -e

    sed -e 's/Linux/Ubuntu/g' -e 's/Bash/Shell/g' file.txt

## Приклад очищення тексту

    sed -E 's/^[[:space:]]+//; s/[[:space:]]+$//; /^$/d' file.txt

Послідовно:

    1. видаляє пробільні символи на початку рядка
    2. видаляє пробільні символи в кінці рядка
    3. видаляє порожні рядки

Важливо: команди виконуються послідовно в тому порядку, у якому записані.

# Скрипти sed у файлі

Якщо команд багато, їх можна винести в окремий файл.

Параметр:

    -f

дозволяє завантажити команди з файлу.

Створи файл:

    nano clean.sed

Вміст:

    s/Linux/Ubuntu/g
    s/Bash/Shell/g
    /^[[:space:]]*$/d

Запусти:

    sed -E -f clean.sed input.txt

`sed` застосує команди з `clean.sed` до `input.txt`.

Цей підхід корисний для повторюваних завдань, складніших перетворень і автоматизації.

# stdin, stdout та pipeline

`sed` може читати текст не лише з файлу, а й зі стандартного вводу.

## Через echo

    echo 'Hello Linux' | sed 's/Linux/Bash/'

Результат:

    Hello Bash

## Через cat

    cat file.txt | sed 's/old/new/g'

Це працює, але часто зайве.

Коротший варіант:

    sed 's/old/new/g' file.txt

## Через grep

    grep 'ERROR' app.log | sed 's/ERROR/PROBLEM/'

Спочатку `grep` відбирає рядки з `ERROR`, потім `sed` замінює текст.

## Через sort

    sort names.txt | sed 's/^/USER: /'

Додає `USER: ` на початок кожного відсортованого рядка.

## Через wc

    sed '/^$/d' file.txt | wc -l

Видаляє порожні рядки з потоку та рахує кількість рядків, що залишилися.

## Виведення у файл

    sed 's/old/new/g' input.txt > output.txt

Тут:

    input.txt  → оригінальний файл
    output.txt → файл із результатом

Оригінальний файл не змінюється.

# Практичні шаблони

## 1. Замінити слово

    sed 's/old/new/' file.txt

## 2. Замінити всі входження в рядках

    sed 's/old/new/g' file.txt

## 3. Замінити без урахування регістру в GNU sed

    sed 's/error/ERROR/Ig' file.txt

## 4. Видалити перший рядок

    sed '1d' file.txt

## 5. Видалити останній рядок

    sed '$d' file.txt

## 6. Видалити порожні рядки

    sed '/^$/d' file.txt

## 7. Видалити рядки-коментарі

    sed -E '/^[[:space:]]*#/d' config.txt

## 8. Вивести лише третій рядок

    sed -n '3p' file.txt

## 9. Вивести діапазон рядків

    sed -n '2,5p' file.txt

## 10. Замінити лише в першому рядку

    sed '1s/old/new/g' file.txt

## 11. Замінити лише в останньому рядку

    sed '$s/old/new/g' file.txt

## 12. Додати префікс до кожного рядка

    sed 's/^/PREFIX: /' file.txt

## 13. Додати суфікс до кожного рядка

    sed 's/$/;/' file.txt

## 14. Замінити числа на [NUMBER]

    sed -E 's/[0-9]+/[NUMBER]/g' file.txt

## 15. Видалити всі цифри

    sed -E 's/[0-9]//g' file.txt

## 16. Стиснути послідовності пробілів

    sed -E 's/ +/ /g' file.txt

Ця команда стискає послідовності звичайних пробілів, але не табуляцій.

## 17. Видалити пробіли на початку та в кінці рядка

    sed -E 's/^[[:space:]]+//; s/[[:space:]]+$//' file.txt

## 18. Замінити URL-протокол

    sed 's|http://|https://|g' urls.txt

## 19. Замінити розширення файлів у текстовому списку

    sed -E 's/\.js$/.ts/' files.txt

## 20. Зберегти резервну копію перед заміною

    sed -i.bak 's/old/new/g' file.txt

# sed у Bash-скриптах

`sed` часто використовується в shell-скриптах для автоматичної обробки конфігурацій та тексту.

Наприклад:

    #!/usr/bin/env bash

    set -euo pipefail

    input_file="config.txt"
    output_file="config-clean.txt"

    sed -E \
        -e '/^[[:space:]]*#/d' \
        -e '/^[[:space:]]*$/d' \
        -e 's/^[[:space:]]+//' \
        -e 's/[[:space:]]+$//' \
        "$input_file" > "$output_file"

Цей скрипт:

    1. видаляє рядки-коментарі
    2. видаляє порожні та пробільні рядки
    3. прибирає пробільні символи на початку
    4. прибирає пробільні символи в кінці
    5. записує результат у новий файл

Оригінальний `config.txt` залишається незмінним.

Важливо: такий приклад підходить для простих текстових конфігурацій, але не є універсальним парсером усіх форматів конфігурацій.

# sed vs grep vs awk

Ці команди часто використовують разом, але вони мають різні основні завдання.

| Команда | Основне призначення | Приклад |
|---|---|---|
| `grep` | Пошук і фільтрація рядків | `grep 'ERROR' app.log` |
| `sed` | Перетворення тексту та редагування потоку | `sed 's/ERROR/WARN/g' app.log` |
| `awk` | Обробка полів, колонок і текстових записів | `awk '{print $1}' file.txt` |
| `cut` | Вибір колонок або символів | `cut -d: -f1 /etc/passwd` |
| `sort` | Сортування рядків | `sort file.txt` |
| `uniq` | Обробка послідовних повторів | `sort file.txt \| uniq` |

Приклад комбінування:

    grep 'ERROR' app.log | sed 's/ERROR/PROBLEM/g'

Інший приклад:

    sed '/^#/d' config.txt | awk -F= '{print $1}'

Тут:

    sed → видаляє рядки, що починаються з #
    awk → виводить перше поле, розділене символом =

Правило:

    пошук рядків       → grep
    заміна та очищення → sed
    поля та колонки    → awk

Це спрощене правило: усі три інструменти мають ширші можливості, але воно добре підходить для початкового рівня.

# Типові помилки

## Помилка 1 — очікувати, що sed змінить файл автоматично

Команда:

    sed 's/old/new/g' file.txt

не змінює оригінальний файл.

Вона лише виводить результат.

Для запису у файл:

    sed -i 's/old/new/g' file.txt

Або без зміни оригіналу:

    sed 's/old/new/g' file.txt > output.txt

## Помилка 2 — забути прапорець g

Команда:

    sed 's/a/b/' file.txt

замінює лише перше входження `a` у кожному рядку.

Для всіх входжень:

    sed 's/a/b/g' file.txt

## Помилка 3 — використовувати -n без p

Команда:

    sed -n '3' file.txt

не виведе звичайний третій рядок, оскільки автоматичне виведення вимкнене.

Правильно:

    sed -n '3p' file.txt

## Помилка 4 — видаляти лише порожні рядки, коли потрібно видалити також рядки з пробілами

Команда:

    sed '/^$/d' file.txt

видаляє рядки без символів, але не обов'язково рядки, які містять пробіли або табуляції.

Для порожніх і пробільних рядків:

    sed -E '/^[[:space:]]*$/d' file.txt

## Помилка 5 — забути екранувати крапку

Шаблон:

    sed 's/.js/.ts/' files.txt

Може замінити будь-який символ перед `js`.

Правильно:

    sed 's/\.js/.ts/' files.txt

## Помилка 6 — плутати BRE та ERE

У BRE:

    sed 's/[0-9]\+/NUMBER/' file.txt

У GNU sed це використовує розширення BRE `\+`.

У ERE:

    sed -E 's/[0-9]+/NUMBER/' file.txt

Для початкового рівня зручніше використовувати `-E`, якщо шаблон містить ERE-оператори.

## Помилка 7 — змінювати важливий файл без резервної копії

Ризикований варіант:

    sed -i 's/old/new/g' config.txt

Безпечніший варіант для GNU sed:

    sed -i.bak 's/old/new/g' config.txt

Або спочатку перевірити результат:

    sed 's/old/new/g' config.txt

## Помилка 8 — забувати про порядок команд

Команда:

    sed 's/Linux/Ubuntu/g; s/Ubuntu/Debian/g' file.txt

спочатку замінює `Linux` на `Ubuntu`, а потім `Ubuntu` на `Debian`.

Отже, початковий текст `Linux` зрештою стане `Debian`.

Порядок команд має значення.

## Помилка 9 — неправильно обробляти слеші

Незручно:

    sed 's/\/home\/user/\/home\/developer/' file.txt

Читабельніше:

    sed 's#/home/user#/home/developer#' file.txt

## Помилка 10 — використовувати sed для складного структурованого формату

`sed` добре підходить для текстових перетворень, але складні HTML, JSON, XML та інші структуровані дані краще обробляти спеціалізованими інструментами, коли потрібно враховувати їхню структуру.

# Міні-шпаргалка

## Заміна тексту

    sed 's/old/new/' file.txt

## Заміна всіх входжень у рядках

    sed 's/old/new/g' file.txt

## Заміна через ERE

    sed -E 's/[0-9]+/[NUMBER]/g' file.txt

## Видалити перший рядок

    sed '1d' file.txt

## Видалити останній рядок

    sed '$d' file.txt

## Видалити порожні рядки

    sed '/^$/d' file.txt

## Видалити порожні та пробільні рядки

    sed -E '/^[[:space:]]*$/d' file.txt

## Показати перший рядок

    sed -n '1p' file.txt

## Показати останній рядок

    sed -n '$p' file.txt

## Показати рядки з 2-го по 5-й

    sed -n '2,5p' file.txt

## Замінити лише перший рядок

    sed '1s/old/new/g' file.txt

## Замінити лише останній рядок

    sed '$s/old/new/g' file.txt

## Додати префікс

    sed 's/^/PREFIX: /' file.txt

## Додати суфікс

    sed 's/$/;/' file.txt

## Прибрати пробіли на початку

    sed -E 's/^[[:space:]]+//' file.txt

## Прибрати пробіли в кінці

    sed -E 's/[[:space:]]+$//' file.txt

## Видалити коментарі

    sed -E '/^[[:space:]]*#/d' config.txt

## Замінити безпосередньо у файлі

    sed -i 's/old/new/g' file.txt

## Зберегти резервну копію

    sed -i.bak 's/old/new/g' file.txt

## Змінити роздільник

    sed 's#/old/path#/new/path#' paths.txt

## Кілька команд

    sed -e 's/old/new/g' -e '/^$/d' file.txt

## Взяти результат іншої команди

    grep 'ERROR' app.log | sed 's/ERROR/PROBLEM/g'

## Записати результат у новий файл

    sed 's/old/new/g' input.txt > output.txt

# Основні правила

    s/OLD/NEW/  → замінити перше входження в кожному рядку
    s/OLD/NEW/g → замінити всі входження в кожному рядку
    -n           → вимкнути автоматичне виведення
    p            → вивести вибраний рядок
    d            → видалити рядок із потоку
    q            → завершити обробку
    i            → вставити текст перед рядком
    a            → додати текст після рядка
    c            → замінити вибраний рядок
    -E           → використовувати Extended Regular Expressions
    -i           → змінювати файл безпосередньо
    -e           → передати додаткову команду
    -f           → прочитати команди з файлу

# Головне

• `sed` — це потоковий редактор тексту, який широко використовується в Linux.

• Основне призначення `sed` — пошук, заміна, видалення та перетворення тексту.

• Команда `s` виконує заміну за шаблоном.

• Без `g` замінюється лише перше входження в кожному рядку.

• `-n` вимикає автоматичне виведення, а `p` дозволяє виводити вибрані рядки.

• `d` видаляє рядки з потоку обробки.

• Адреси дозволяють працювати з конкретними рядками, діапазонами та рядками, що відповідають шаблону.

• `-E` дозволяє використовувати Extended Regular Expressions.

• `-i` змінює оригінальний файл, тому його потрібно застосовувати обережно.

• `-i.bak` у GNU sed дозволяє зберегти резервну копію перед змінами.

• Альтернативні роздільники роблять команди з файловими шляхами читабельнішими.

• `sed` можна використовувати разом із `grep`, `awk`, `sort`, `cut` та іншими командами через pipeline.

• Для повторюваних перетворень команди можна зберігати в окремому sed-скрипті.

• `sed` добре підходить для автоматизації простих і середньої складності текстових перетворень.

• Для складної логіки, обробки колонок і структурованих даних часто зручніше використовувати `awk`, Python або спеціалізовані інструменти.

• Перед редагуванням важливих файлів потрібно перевіряти результат без `-i` або створювати резервну копію.

• Основна модель роботи:

    Input text
        ↓
    Address / pattern
        ↓
    sed command
        ↓
    Text transformation
        ↓
    stdout або змінений файл

• Головне правило: спочатку зрозуміти, які рядки потрібно вибрати, потім визначити операцію, і лише після перевірки результату застосовувати зміни до оригінального файлу.

# 03. AWK

`awk` — це інструмент командного рядка Linux для обробки структурованого тексту. Він дозволяє читати текст построково, розділяти кожен рядок на поля, відбирати потрібні записи, виконувати обчислення, форматувати результати та створювати звіти.

`awk` особливо корисний для роботи з:

- текстовими файлами;
- CSV-подібними даними;
- логами;
- таблицями, сформованими в терміналі;
- результатами інших команд Linux;
- списками користувачів, процесів, файлів та мережевих з'єднань;
- статистикою та агрегованими даними.

Основні можливості `awk`:

    field processing
    pattern matching
    filtering
    arithmetic operations
    string processing
    variables
    conditions
    loops
    formatted output
    data aggregation
    report generation

### Що потрібно пам'ятати

• `awk` зазвичай читає вхідні дані построково.

• Один рядок вхідних даних називається `record`.

• Поля всередині запису називаються `fields`.

• `$0` — весь поточний рядок.

• `$1` — перше поле, `$2` — друге поле, `$3` — третє поле.

• `NF` — кількість полів у поточному записі.

• `NR` — загальна кількість прочитаних записів у поточному запуску програми.

• `FNR` — номер поточного запису в поточному файлі.

• `FS` визначає роздільник полів під час читання.

• `OFS` визначає роздільник полів під час виведення через `print`.

• `BEGIN` виконується перед обробкою вхідних записів.

• `END` виконується після обробки всіх вхідних записів.

• `pattern { action }` означає: якщо запис відповідає шаблону, виконати дію.

• Якщо `pattern` відсутній, дія виконується для кожного запису.

• Якщо `action` відсутній, відповідні записи виводяться повністю.

• `print` виводить дані, а `printf` дозволяє форматувати їх.

• `awk` може виконувати математичні обчислення, перевірки умов та цикли.

• `awk` підтримує регулярні вирази.

• `awk` зручно використовувати разом із `cat`, `grep`, `sort`, `uniq`, `cut` та іншими командами Linux.

# Що таке awk

`awk` — це мова програмування та інструмент обробки тексту, який працює з записами й полями.

Наприклад, маємо файл `users.txt`:

    alice 25 developer
    bob 30 designer
    carol 28 tester

Вивести весь файл:

    awk '{ print }' users.txt

Вивести перше поле:

    awk '{ print $1 }' users.txt

Результат:

    alice
    bob
    carol

Вивести перше та третє поля:

    awk '{ print $1, $3 }' users.txt

Результат:

    alice developer
    bob designer
    carol tester

Вивести друге поле:

    awk '{ print $2 }' users.txt

Результат:

    25
    30
    28

`awk` автоматично розділяє рядки на поля, використовуючи пробільні символи за замовчуванням.

---

# Основний синтаксис

Загальна структура програми:

    awk 'pattern { action }' file.txt

Тут:

    awk       → команда
    pattern   → умова відбору записів
    action    → дія, яку потрібно виконати
    file.txt  → вхідний файл

Наприклад:

    awk '$2 > 25 { print $1, $2 }' users.txt

Ця команда виводить ім'я та вік користувачів, яким більше ніж 25 років.

Результат:

    bob 30
    carol 28

---

# Як працює awk

Розглянемо команду:

    awk '$2 >= 25 { print $1 }' users.txt

Алгоритм роботи:

    1. Відкрити вхідний файл.
    2. Прочитати перший рядок.
    3. Розділити рядок на поля.
    4. Перевірити умову $2 >= 25.
    5. Якщо умова істинна, виконати print $1.
    6. Перейти до наступного рядка.
    7. Повторювати, поки не закінчаться дані.

Загальна модель:

    Input
      ↓
    Read record
      ↓
    Split into fields
      ↓
    Evaluate pattern
      ↓
    Execute action
      ↓
    Next record
      ↓
    End of input

# Record

`record` — один запис вхідних даних.

За замовчуванням `awk` вважає кожен рядок окремим записом.

Наприклад:

    alice 25 developer
    bob 30 designer
    carol 28 tester

Тут є три записи.

Для кожного запису `awk` послідовно виконує програму.

Вивести весь поточний запис:

    awk '{ print $0 }' users.txt

`$0` містить весь поточний рядок.

---

# Fields

`field` — окреме поле поточного запису.

За замовчуванням роздільниками полів є послідовності пробілів і табуляцій.

Наприклад:

    alice 25 developer

Поля:

    $1 → alice
    $2 → 25
    $3 → developer
    $0 → alice 25 developer

Приклад:

    awk '{ print $1 }' users.txt

Вивести друге поле:

    awk '{ print $2 }' users.txt

Вивести третє поле:

    awk '{ print $3 }' users.txt

Вивести перше та друге поля:

    awk '{ print $1, $2 }' users.txt

Вивести всі поля, крім першого:

    awk '{ for (i = 2; i <= NF; i++) print $i }' users.txt

---

# $0

`$0` — увесь поточний запис.

Приклад:

    awk '{ print $0 }' users.txt

Це еквівалентно:

    awk '{ print }' users.txt

Вивести рядок лише тоді, коли він містить `developer`:

    awk '/developer/ { print $0 }' users.txt

Результат:

    alice 25 developer

---

# $1, $2, $3 та інші поля

Номер після `$` визначає поле.

Наприклад:

    awk '{ print $1, $3 }' users.txt

Виводить перше та третє поля.

Номер поля може бути змінним:

    awk '{ print $2 }' users.txt

Або обчислюватися:

    awk '{ print $(NF - 1) }' users.txt

Ця команда виводить передостаннє поле кожного запису.

Приклад для рядка:

    alice 25 developer

Результат:

    25

Важливо: для динамічного номера поля використовуй дужки, наприклад `$(NF - 1)`.

---

# NF

`NF` — кількість полів у поточному записі.

Наприклад:

    alice 25 developer

Тут:

    NF = 3

Приклад:

    awk '{ print NF }' users.txt

Результат:

    3
    3
    3

Якщо кількість полів у рядках різна, `NF` також може відрізнятися.

Вивести кількість полів і весь рядок:

    awk '{ print NF, $0 }' users.txt

Вивести лише записи, у яких більше трьох полів:

    awk 'NF > 3 { print }' file.txt

Вивести останнє поле:

    awk '{ print $NF }' users.txt

Вивести передостаннє поле:

    awk 'NF >= 2 { print $(NF - 1) }' users.txt

Перевірка `NF >= 2` потрібна, щоб не намагатися отримати передостаннє поле в записі, де його немає.

---

# NR

`NR` — загальна кількість прочитаних записів у поточному запуску `awk`.

За стандартного режиму роботи, коли один запис відповідає одному рядку, `NR` зазвичай збігається з номером поточного рядка.

Приклад:

    awk '{ print NR, $0 }' users.txt

Результат:

    1 alice 25 developer
    2 bob 30 designer
    3 carol 28 tester

Вивести лише перший рядок:

    awk 'NR == 1 { print }' users.txt

Вивести перші три рядки:

    awk 'NR <= 3 { print }' users.txt

Вивести рядки з другого по четвертий:

    awk 'NR >= 2 && NR <= 4 { print }' file.txt

Пропустити перший рядок:

    awk 'NR > 1 { print }' file.txt

Цей прийом часто використовують, щоб пропустити заголовок таблиці.

---

# FNR

`FNR` — номер поточного запису в поточному файлі.

На відміну від `NR`, лічильник `FNR` починається заново для кожного нового файлу.

Приклад:

    awk '{ print FNR, $0 }' file1.txt file2.txt

Якщо в кожному файлі є два рядки, результат матиме таку структуру:

    1 рядок з file1.txt
    2 рядок з file1.txt
    1 рядок з file2.txt
    2 рядок з file2.txt

Вивести номер запису та назву файлу:

    awk '{ print FNR, FILENAME, $0 }' file1.txt file2.txt

Де:

    FNR      → номер запису в поточному файлі
    FILENAME → назва поточного файлу
    NR       → загальний номер запису

---

# NR vs FNR

Це важлива відмінність.

`NR`:

    загальний лічильник записів

`FNR`:

    лічильник записів поточного файлу

Для одного файлу:

    NR і FNR зазвичай однакові

Для декількох файлів:

    NR продовжує рахувати
    FNR починає рахувати заново

Приклад:

    awk '{ print NR, FNR, $0 }' file1.txt file2.txt

Якщо обидва файли мають по два рядки:

    1 1 перший рядок file1
    2 2 другий рядок file1
    3 1 перший рядок file2
    4 2 другий рядок file2

---

# FS — Field Separator

`FS` визначає, як `awk` розділяє вхідний запис на поля.

За замовчуванням:

    FS = " "

У цьому режимі послідовності пробільних символів розділяють поля.

Наприклад:

    alice 25 developer

Поля:

    $1 → alice
    $2 → 25
    $3 → developer

Щоб використовувати двокрапку як роздільник:

    awk -F ':' '{ print $1, $3 }' /etc/passwd

Або:

    awk 'BEGIN { FS = ":" } { print $1, $3 }' /etc/passwd

Обидва варіанти встановлюють двокрапку як роздільник полів.

---

# Параметр -F

Параметр `-F` дозволяє задати роздільник полів безпосередньо в командному рядку.

Роздільник — кома:

    awk -F ',' '{ print $1, $2 }' data.csv

Роздільник — двокрапка:

    awk -F ':' '{ print $1, $6 }' /etc/passwd

Роздільник — вертикальна риска:

    awk -F '|' '{ print $1, $2 }' data.txt

Роздільник — табуляція:

    awk -F '\t' '{ print $1, $2 }' data.tsv

Важливо: простий `-F ','` не є повноцінним CSV-парсером. Якщо CSV містить коми всередині полів у лапках, наприклад `"Smith, John"`, для коректного розбору краще використовувати спеціальний CSV-парсер.

---

# OFS — Output Field Separator

`OFS` визначає роздільник між аргументами команди `print`.

За замовчуванням:

    OFS = " "

Приклад:

    awk '{ print $1, $3 }' users.txt

Результат:

    alice developer
    bob designer
    carol tester

Змінити роздільник виведення на кому:

    awk 'BEGIN { OFS = "," } { print $1, $2, $3 }' users.txt

Результат:

    alice,25,developer
    bob,30,designer
    carol,28,tester

Змінити роздільник на вертикальну риску:

    awk 'BEGIN { OFS = "|" } { print $1, $2, $3 }' users.txt

Результат:

    alice|25|developer
    bob|30|designer
    carol|28|tester

Важливо: `OFS` використовується між аргументами `print`, а не між частинами одного рядка, сформованого через конкатенацію.

---

# RS та ORS

`RS` — Record Separator, роздільник записів під час читання.

За замовчуванням:

    RS = "\n"

Тобто звичайний запис закінчується символом нового рядка.

`ORS` — Output Record Separator, роздільник записів під час виведення через `print`.

За замовчуванням:

    ORS = "\n"

Приклад:

    awk 'BEGIN { ORS = "\n---\n" } { print $0 }' users.txt

Між записами буде додано роздільник:

    ---

`RS` та `ORS` корисні, коли потрібно обробляти дані, розділені не лише рядками.

На початковому рівні достатньо пам'ятати:

    FS  → розділяє поля під час читання
    OFS → розділяє поля під час print
    RS  → розділяє записи під час читання
    ORS → розділяє записи під час виведення

---

# BEGIN

`BEGIN` — спеціальний блок, який виконується перед обробкою вхідних записів.

Він використовується для:

    ініціалізації змінних
    налаштування FS та OFS
    виведення заголовків
    підготовки звіту

Приклад:

    awk 'BEGIN { print "User report" } { print $1 }' users.txt

Результат:

    User report
    alice
    bob
    carol

Налаштування роздільника:

    awk 'BEGIN { FS = ":" } { print $1 }' /etc/passwd

Вивести заголовок таблиці:

    awk 'BEGIN {
        print "NAME AGE ROLE"
    }
    {
        print $1, $2, $3
    }' users.txt

---

# END

`END` — спеціальний блок, який виконується після обробки всіх вхідних записів.

Він використовується для:

    підрахунку результатів
    виведення підсумків
    формування звітів
    виведення статистики

Приклад:

    awk 'END { print "Total records:", NR }' users.txt

Результат:

    Total records: 3

Підрахунок записів:

    awk '{ count++ } END { print count }' users.txt

Підрахунок суми другого поля:

    awk '{ sum += $2 } END { print sum }' users.txt

Для файлу `users.txt` результат:

    83

---

# BEGIN, основний блок та END

Програма `awk` може складатися з трьох основних частин:

    BEGIN
        ↓
    основна обробка записів
        ↓
    END

Приклад:

    awk '
    BEGIN {
        print "Starting report"
        count = 0
    }

    {
        count++
        print NR, $0
    }

    END {
        print "Total:", count
    }
    ' users.txt

Тут:

    BEGIN → початкова підготовка
    { }   → обробка кожного запису
    END   → фінальний підсумок

---

# Pattern

`pattern` — умова, яка визначає, для яких записів потрібно виконати дію.

Наприклад:

    awk '$2 > 25 { print $1 }' users.txt

Виводить імена користувачів, вік яких більший за 25.

Якщо запис відповідає умові:

    виконати action

Якщо не відповідає:

    перейти до наступного запису

---

# Pattern без action

Якщо вказати лише шаблон, `awk` виведе весь запис, який відповідає умові.

Приклад:

    awk '$2 > 25' users.txt

Це еквівалентно:

    awk '$2 > 25 { print $0 }' users.txt

Ще один приклад:

    awk 'NR == 1' users.txt

Виводить перший запис.

---

# Action без pattern

Якщо вказати дію без шаблону, вона виконується для кожного запису.

Приклад:

    awk '{ print $1 }' users.txt

Виводить перше поле кожного рядка.

Ще один приклад:

    awk '{ print NR, NF }' users.txt

Виводить номер запису та кількість полів для кожного рядка.

---

# Comparison Operators

`awk` підтримує оператори порівняння.

    ==  → дорівнює
    !=  → не дорівнює
    >   → більше
    <   → менше
    >=  → більше або дорівнює
    <=  → менше або дорівнює

Приклади:

    awk '$2 == 25 { print }' users.txt

    awk '$2 != 25 { print }' users.txt

    awk '$2 > 25 { print }' users.txt

    awk '$2 < 30 { print }' users.txt

    awk '$2 >= 28 { print }' users.txt

    awk '$2 <= 28 { print }' users.txt

Якщо поле містить числа, `awk` може виконувати числове порівняння.

Якщо поле містить текст, результат залежить від типів операндів та правил перетворення AWK.

---

# Logical Operators

Логічні оператори дозволяють поєднувати умови.

    && → AND
    || → OR
    !  → NOT

Приклад AND:

    awk '$2 > 20 && $2 < 30 { print $1 }' users.txt

Виводить імена користувачів віком більше 20 і менше 30 років.

Приклад OR:

    awk '$3 == "developer" || $3 == "tester" { print }' users.txt

Приклад NOT:

    awk '!($2 < 25) { print }' users.txt

Логічні оператори дозволяють створювати складніші фільтри.

---

# String Comparison

Порівнювати можна не лише числа, а й текстові значення.

Приклад:

    awk '$3 == "developer" { print $1 }' users.txt

Результат:

    alice

Вивести всіх, хто не є розробником:

    awk '$3 != "developer" { print $1 }' users.txt

Зверни увагу: текстове значення в AWK зазвичай записують у подвійних лапках.

---

# Regular Expressions

`awk` підтримує регулярні вирази для пошуку текстових шаблонів.

Загальний синтаксис:

    awk '/regex/ { action }' file.txt

Приклад:

    awk '/developer/ { print }' users.txt

Вивести рядки, які містять слово `alice`:

    awk '/alice/ { print }' users.txt

Вивести рядки, які починаються з `a`:

    awk '/^a/ { print }' users.txt

Вивести рядки, які закінчуються на `tester`:

    awk '/tester$/ { print }' users.txt

Основні символи:

    ^   → початок рядка
    $   → кінець рядка
    .   → будь-який символ
    *   → нуль або більше повторень
    +   → одне або більше повторень у POSIX ERE
    ?   → нуль або одне повторення у POSIX ERE
    []  → набір символів
    |   → альтернатива у POSIX ERE
    ()  → групування у POSIX ERE

`awk` зазвичай використовує розширені регулярні вирази POSIX (ERE).

---

# Matching Operator ~

Оператор `~` перевіряє, чи відповідає значення поля регулярному виразу.

Приклад:

    awk '$3 ~ /dev/ { print $1, $3 }' users.txt

Виводить записи, де третє поле містить `dev`.

Оператор `!~` перевіряє, що значення не відповідає регулярному виразу.

    awk '$3 !~ /dev/ { print $1, $3 }' users.txt

Приклад пошуку рядків, де перше поле починається з літери `a`:

    awk '$1 ~ /^a/ { print }' users.txt

---

# Filtering

Фільтрація — одна з основних можливостей `awk`.

Маємо:

    alice 25 developer
    bob 30 designer
    carol 28 tester
    david 22 developer

Вибрати користувачів, яким більше 25 років:

    awk '$2 > 25 { print }' users.txt

Вибрати розробників:

    awk '$3 == "developer" { print }' users.txt

Вибрати користувачів віком від 25 років включно:

    awk '$2 >= 25 { print $1, $2 }' users.txt

Вибрати рядки, що містять `developer`:

    awk '/developer/ { print }' users.txt

Вибрати рядки, у яких більше двох полів:

    awk 'NF > 2 { print }' users.txt

---

# if / else

`if` дозволяє виконувати дію залежно від умови.

Синтаксис:

    if (condition) {
        statements
    }

Приклад:

    awk '{
        if ($2 >= 25) {
            print $1, "adult"
        }
    }' users.txt

Використання `else`:

    awk '{
        if ($2 >= 25) {
            print $1, "25 or older"
        } else {
            print $1, "younger than 25"
        }
    }' users.txt

Можна використовувати `else if`:

    awk '{
        if ($2 < 18) {
            print $1, "minor"
        } else if ($2 < 60) {
            print $1, "adult"
        } else {
            print $1, "senior"
        }
    }' users.txt

---

# Variables

AWK дозволяє створювати змінні без попереднього оголошення типу.

Приклад:

    awk '{
        age = $2
        print $1, age
    }' users.txt

Змінна `age` зберігає значення другого поля.

Ініціалізація змінної:

    awk 'BEGIN {
        count = 0
        sum = 0
    }
    {
        count++
        sum += $2
    }
    END {
        print "Count:", count
        print "Sum:", sum
    }' users.txt

Змінні можна використовувати для:

    лічильників
    сум
    середніх значень
    проміжних результатів
    накопичення статистики

---

# Arithmetic Operations

AWK підтримує арифметичні оператори.

    +   → додавання
    -   → віднімання
    *   → множення
    /   → ділення
    %   → остача від ділення
    ++  → збільшення на 1
    --  → зменшення на 1
    +=  → додавання зі збереженням
    -=  → віднімання зі збереженням
    *=  → множення зі збереженням
    /=  → ділення зі збереженням

Приклад:

    awk 'BEGIN {
        a = 10
        b = 3

        print a + b
        print a - b
        print a * b
        print a / b
        print a % b
    }'

Результат:

    13
    7
    30
    3.33333
    1

---

# Sum

Щоб обчислити суму числового поля, використовують змінну-накопичувач.

Файл `scores.txt`:

    alice 80
    bob 90
    carol 70

Команда:

    awk '{ sum += $2 } END { print sum }' scores.txt

Результат:

    240

Логіка:

    sum = 0
    sum = sum + 80
    sum = sum + 90
    sum = sum + 70
    print sum

---

# Average

Середнє значення обчислюється як сума, поділена на кількість записів.

    awk '{
        sum += $2
        count++
    }
    END {
        if (count > 0) {
            print sum / count
        }
    }' scores.txt

Результат:

    80

Перевірка `count > 0` запобігає діленню на нуль, якщо вхідних записів немає.

---

# Count

Порахувати кількість записів:

    awk 'END { print NR }' users.txt

Альтернативний спосіб:

    awk '{ count++ } END { print count }' users.txt

Порахувати рядки, у яких друге поле більше 25:

    awk '$2 > 25 { count++ } END { print count + 0 }' users.txt

`count + 0` дозволяє отримати числовий нуль, якщо жоден запис не відповідає умові.

---

# Minimum and Maximum

Знайти мінімальне значення другого поля:

    awk '
    NR == 1 || $2 < min {
        min = $2
    }
    END {
        if (NR > 0) {
            print min
        }
    }' scores.txt

Знайти максимальне значення:

    awk '
    NR == 1 || $2 > max {
        max = $2
    }
    END {
        if (NR > 0) {
            print max
        }
    }' scores.txt

У цих прикладах перший запис ініціалізує змінну, а наступні записи можуть її змінювати.

---

# printf

`printf` дозволяє форматувати виведення.

Синтаксис:

    printf "format", value1, value2

Приклад:

    awk '{ printf "%s is %d years old\n", $1, $2 }' users.txt

Тут:

    %s → рядок
    %d → ціле число
    %f → число з плаваючою крапкою
    \n → новий рядок

Форматування десяткового числа:

    awk 'BEGIN {
        value = 3.14159
        printf "%.2f\n", value
    }'

Результат:

    3.14

Форматування таблиці:

    awk '{
        printf "%-10s %5d %s\n", $1, $2, $3
    }' users.txt

Тут:

    %-10s → рядок завширшки 10 символів, вирівнювання ліворуч
    %5d   → ціле число завширшки 5 символів
    %s    → рядок
    \n    → новий рядок

На відміну від `print`, `printf` не додає новий рядок автоматично.

---

# print vs printf

`print`:

    awk '{ print $1, $2 }' users.txt

Автоматично додає `OFS` між аргументами та `ORS` після запису.

`printf`:

    awk '{ printf "%s: %d\n", $1, $2 }' users.txt

Дозволяє контролювати формат виведення, але новий рядок потрібно вказати самостійно.

Використовуй:

    print  → просте виведення
    printf → форматоване виведення

---

# String Concatenation

В AWK рядки можна об'єднувати без спеціального оператора конкатенації.

Приклад:

    awk '{
        full = $1 " " $3
        print full
    }' users.txt

Можна також виводити кілька значень через `print`:

    awk '{ print $1, $3 }' users.txt

Різниця:

    $1 " " $3 → явне формування рядка
    $1, $3    → аргументи print, розділені OFS

---

# String Functions

AWK має вбудовані функції для роботи з рядками.

Основні функції:

    length()
    substr()
    index()
    split()
    tolower()
    toupper()
    sub()
    gsub()

---

# length()

`length()` повертає довжину рядка або кількість символів у значенні.

Приклад:

    awk '{ print $1, length($1) }' users.txt

Для окремого значення:

    awk 'BEGIN {
        print length("developer")
    }'

Результат:

    9

---

# substr()

`substr()` повертає частину рядка.

Синтаксис:

    substr(string, start, length)

Приклад:

    awk 'BEGIN {
        print substr("JavaScript", 1, 4)
    }'

Результат:

    Java

Індексація в `substr()` починається з 1.

Отримати перші три символи першого поля:

    awk '{ print substr($1, 1, 3) }' users.txt

---

# index()

`index()` повертає позицію першого входження підрядка.

Синтаксис:

    index(string, substring)

Приклад:

    awk 'BEGIN {
        print index("JavaScript", "Script")
    }'

Результат:

    5

Якщо підрядок не знайдено, функція повертає `0`.

---

# tolower() та toupper()

`tolower()` перетворює літери на нижній регістр.

    awk '{ print tolower($1) }' users.txt

`toupper()` перетворює літери на верхній регістр.

    awk '{ print toupper($1) }' users.txt

Приклад:

    awk 'BEGIN {
        print tolower("HELLO")
        print toupper("hello")
    }'

Результат:

    hello
    HELLO

---

# sub()

`sub()` замінює перше входження регулярного виразу.

Синтаксис:

    sub(regex, replacement, target)

Приклад:

    awk '{
        sub(/developer/, "programmer", $3)
        print
    }' users.txt

Функція змінює лише перше відповідне входження у вказаному значенні.

Якщо третій аргумент відсутній, `sub()` працює з `$0`.

Приклад:

    awk '{
        sub(/old/, "new")
        print
    }' file.txt

Це змінює перше входження `old` у поточному записі.

---

# gsub()

`gsub()` замінює всі входження регулярного виразу у вказаному значенні.

Приклад:

    awk 'BEGIN {
        text = "one one one"
        gsub(/one/, "two", text)
        print text
    }'

Результат:

    two two two

Змінити всі дефіси на підкреслення:

    awk '{
        gsub(/-/, "_")
        print
    }' file.txt

Як і `sub()`, `gsub()` змінює `$0`, якщо цільове значення не вказано.

---

# split()

`split()` розділяє рядок на елементи масиву.

Синтаксис:

    split(string, array, separator)

Приклад:

    awk 'BEGIN {
        text = "apple,banana,orange"
        count = split(text, fruits, ",")

        print count
        print fruits[1]
        print fruits[2]
        print fruits[3]
    }'

Результат:

    3
    apple
    banana
    orange

Функція повертає кількість отриманих елементів.

Приклад із двокрапкою:

    awk 'BEGIN {
        split("name:25:developer", fields, ":")
        print fields[1]
        print fields[2]
        print fields[3]
    }'

---

# Arrays

AWK підтримує масиви, які використовуються для зберігання значень за індексами або ключами.

Приклад:

    awk 'BEGIN {
        fruits[1] = "apple"
        fruits[2] = "banana"
        fruits[3] = "orange"

        print fruits[1]
        print fruits[2]
        print fruits[3]
    }'

Результат:

    apple
    banana
    orange

На відміну від звичайного JavaScript-масиву, масиви AWK є асоціативними: їхні індекси можуть бути рядковими ключами.

---

# Associative Arrays

Асоціативні масиви зберігають значення за ключами.

Приклад:

    awk 'BEGIN {
        scores["alice"] = 80
        scores["bob"] = 90
        scores["carol"] = 70

        print scores["alice"]
        print scores["bob"]
    }'

Результат:

    80
    90

Асоціативні масиви зручні для:

    підрахунку частоти
    групування даних
    підрахунку значень за категоріями
    зберігання статистики

---

# Підрахунок частоти

Порахувати, скільки разів зустрічається кожне слово в першому полі:

    awk '{
        count[$1]++
    }
    END {
        for (name in count) {
            print name, count[name]
        }
    }' users.txt

Цей приклад групує записи за першим полем.

Важливо: порядок обходу асоціативного масиву через `for (key in array)` не гарантований.

Якщо потрібен відсортований результат, його можна передати в `sort`.

---

# Membership Test

Перевірити, чи існує ключ в асоціативному масиві:

    key in array

Приклад:

    awk 'BEGIN {
        users["alice"] = 1

        if ("alice" in users) {
            print "Found"
        }

        if (!("bob" in users)) {
            print "Not found"
        }
    }'

Це дозволяє перевіряти наявність ключа без порівняння його значення.

---

# for Loop

AWK підтримує цикл `for`.

Синтаксис:

    for (initialization; condition; update) {
        statements
    }

Приклад:

    awk 'BEGIN {
        for (i = 1; i <= 5; i++) {
            print i
        }
    }'

Результат:

    1
    2
    3
    4
    5

Цикл можна використовувати для проходження полів:

    awk '{
        for (i = 1; i <= NF; i++) {
            print i, $i
        }
    }' users.txt

Ця команда виводить номер і значення кожного поля.

---

# for...in для масивів

У AWK конструкція:

    for (key in array)

перебирає ключі асоціативного масиву.

Приклад:

    awk 'BEGIN {
        scores["alice"] = 80
        scores["bob"] = 90
        scores["carol"] = 70

        for (name in scores) {
            print name, scores[name]
        }
    }'

Порядок результатів не визначений.

На відміну від JavaScript, тут `for...in` — це звичайний синтаксис AWK для обходу ключів масиву.

---

# while Loop

`while` виконує блок, поки умова істинна.

Приклад:

    awk 'BEGIN {
        i = 1

        while (i <= 5) {
            print i
            i++
        }
    }'

Результат:

    1
    2
    3
    4
    5

Як і в інших мовах, потрібно стежити, щоб умова циклу зрештою стала хибною.

---

# next

`next` припиняє обробку поточного запису та переходить до наступного.

Приклад:

    awk '$2 < 25 { next } { print $1, $2 }' users.txt

Це виводить лише записи, у яких друге поле не менше 25.

Той самий результат можна отримати простішим фільтром:

    awk '$2 >= 25 { print $1, $2 }' users.txt

`next` особливо корисний у складніших програмах, коли потрібно пропустити кілька подальших дій для певного запису.

---

# exit

`exit` завершує виконання програми `awk`.

Приклад:

    awk 'NR == 5 { print; exit }' file.txt

Команда виведе п'ятий запис і завершить роботу.

Важливо: після `exit` блок `END`, якщо він визначений, зазвичай усе одно виконується.

Приклад:

    awk '
    NR == 3 {
        print "Stopping"
        exit
    }
    END {
        print "Finished"
    }
    ' file.txt

# Обробка CSV-подібних файлів

Маємо файл `employees.csv`:

    name,age,role
    alice,25,developer
    bob,30,designer
    carol,28,tester

Вивести імена:

    awk -F ',' '{ print $1 }' employees.csv

Однак команда також виведе заголовок:

    name
    alice
    bob
    carol

Пропустити заголовок:

    awk -F ',' 'NR > 1 { print $1 }' employees.csv

Вивести ім'я та роль:

    awk -F ',' 'NR > 1 { print $1, $3 }' employees.csv

Вивести лише працівників старше 25 років:

    awk -F ',' 'NR > 1 && $2 > 25 { print $1, $2 }' employees.csv

Важливо: це приклади для простого CSV без ком у лапкованих полях. Для складних CSV використовуй спеціалізовані інструменти.

---

# Відокремлення заголовка

Часто текстові таблиці мають перший рядок із назвами колонок.

Наприклад:

    NAME AGE ROLE
    alice 25 developer
    bob 30 designer
    carol 28 tester

Вивести всі записи без заголовка:

    awk 'NR > 1 { print }' employees.txt

Вивести заголовок окремо, а потім записи:

    awk '
    NR == 1 {
        print "Header:", $0
        next
    }
    {
        print "Data:", $0
    }
    ' employees.txt

# Робота зі стандартним введенням

`awk` може читати дані не лише з файлу, а й зі стандартного введення.

Наприклад:

    cat users.txt | awk '{ print $1 }'

Або без `cat`:

    awk '{ print $1 }' < users.txt

Для обробки результатів іншої команди:

    ps aux | awk '{ print $1, $2, $11 }'

Ця команда виводить перше, друге та одинадцяте поля результату `ps aux`.

Пам'ятай: позиції полів залежать від формату виведення конкретної команди. Для команд із вирівняними колонками або полями, які містять пробіли, просте розділення за пробілами може бути ненадійним.

---

# awk та grep

`grep` переважно шукає рядки, що відповідають текстовому шаблону.

`awk` дозволяє перевіряти конкретні поля та виконувати обчислення.

Наприклад:

    grep 'developer' users.txt

Шукає рядки, що містять `developer`.

А:

    awk '$3 == "developer" { print $1 }' users.txt

Перевіряє саме третє поле.

Комбінування:

    grep 'developer' users.txt | awk '{ print $1 }'

Але якщо достатньо одного `awk`, краще уникати зайвої команди:

    awk '$3 == "developer" { print $1 }' users.txt

---

# awk та cut

`cut` зручний для простого вилучення колонок із даних, що мають стабільний роздільник.

Наприклад:

    cut -d ',' -f 1,3 employees.csv

Подібна операція в `awk`:

    awk -F ',' '{ print $1, $3 }' employees.csv

Переваги `awk`:

    умови
    арифметика
    складні фільтри
    перетворення полів
    форматування
    підрахунки

Для простого вилучення полів `cut` часто достатньо.

---

# awk та sed

`sed` переважно використовується для потокового редагування тексту.

`awk` переважно використовується для роботи із записами, полями, умовами та обчисленнями.

Приклад заміни тексту через `sed`:

    sed 's/old/new/g' file.txt

Приклад заміни в `awk`:

    awk '{ gsub(/old/, "new"); print }' file.txt

Для простих замін зазвичай зручніше `sed`.

Для складної обробки структурованого тексту часто зручніше `awk`.

---

# awk та sort

`awk` може підготувати дані, а `sort` — відсортувати їх.

Приклад:

    awk '{ print $2, $1 }' users.txt | sort -n

Ця команда переставляє поля та сортує результат за першим числовим полем.

Сортування за другим полем:

    sort -k2,2n users.txt

Для числового сортування результатів, сформованих через `awk`, можна використовувати:

    awk '{ print $2, $1 }' users.txt | sort -n

---

# awk та uniq

`uniq` дозволяє прибирати сусідні повторення або підраховувати їх.

Порахувати частоту значень у першому полі:

    awk '{ print $1 }' users.txt | sort | uniq -c

Приклад підрахунку ролей:

    awk '{ print $3 }' users.txt | sort | uniq -c

Типовий ланцюжок:

    extract
      ↓
    sort
      ↓
    uniq -c

Для складнішого групування можна використати асоціативні масиви безпосередньо в `awk`.

---

# awk та xargs

`xargs` передає дані зі стандартного введення як аргументи іншої команди.

Наприклад:

    awk '{ print $1 }' users.txt | xargs -r printf '%s\n'

Цей приклад передає перші поля як аргументи `printf`.

Однак для складного тексту, що містить пробіли або спеціальні символи, звичайний поділ аргументів може бути небезпечним або давати неправильні результати.

Для роботи зі шляхами файлів, особливо якщо вони містять пробіли чи символи нового рядка, віддавай перевагу нульовим роздільникам у тих командах, які їх підтримують, наприклад `find -print0` разом із `xargs -0`.

# awk у Linux Logs

`awk` корисний для швидкого аналізу логів.

Наприклад, якщо лог має структуру:

    INFO application started
    ERROR database connection failed
    INFO request completed
    ERROR request timeout

Знайти рядки з `ERROR`:

    awk '$1 == "ERROR" { print }' app.log

Порахувати кількість рядків `ERROR`:

    awk '$1 == "ERROR" { count++ } END { print count + 0 }' app.log

Вивести лише повідомлення після рівня логування:

    awk '{ $1 = ""; sub(/^ /, ""); print }' app.log

У цьому прикладі змінюється `$1`, а потім видаляється початковий пробіл із `$0`.

Зверни увагу: присвоєння окремому полю може перебудувати `$0` із використанням поточного `OFS`. Тому початкове форматування рядка може змінитися.

# Аналіз access logs

Припустімо, що маємо спрощений access log:

    192.168.1.10 GET /index.html 200
    192.168.1.11 GET /about.html 200
    192.168.1.10 POST /login 401
    192.168.1.12 GET /api/users 500

Порахувати кількість запитів:

    awk 'END { print NR }' access.log

Вивести IP-адреси:

    awk '{ print $1 }' access.log

Вивести запити зі статусом `500`:

    awk '$4 == 500 { print }' access.log

Порахувати помилки `500`:

    awk '$4 == 500 { count++ } END { print count + 0 }' access.log

Вивести метод та шлях запиту:

    awk '{ print $2, $3 }' access.log

Це навчальний приклад із простим форматом. У реальних HTTP access logs поля можуть містити лапки, пробіли та інші особливості, тому позиції полів треба визначати відповідно до конкретного формату журналу.

# Підрахунок запитів за IP

Для наведеного `access.log`:

    awk '{
        count[$1]++
    }
    END {
        for (ip in count) {
            print ip, count[ip]
        }
    }' access.log

Приклад результату:

    192.168.1.10 2
    192.168.1.11 1
    192.168.1.12 1

Порядок рядків не гарантований.

Щоб відсортувати за кількістю запитів:

    awk '{ count[$1]++ }
    END {
        for (ip in count) {
            print count[ip], ip
        }
    }' access.log | sort -nr

Маємо файл `temperatures.txt`:

    Kyiv 18
    Lviv 16
    Odesa 22
    Vinnytsia 19

Вивести міста, де температура більша за 18:

    awk '$2 > 18 { print $1, $2 }' temperatures.txt

Знайти середню температуру:

    awk '{
        sum += $2
        count++
    }
    END {
        if (count > 0) {
            printf "Average: %.2f\n", sum / count
        }

Знайти максимальну температуру:

    awk '
    NR == 1 || $2 > max {
        max = $2
        city = $1
    }
    END {
        if (NR > 0) {
            print city, max
        }
    }' temperatures.txt

# Відновлення рядка після зміни полів

Якщо змінити поле, `awk` може перебудувати весь запис.

Приклад:

    awk '{
        $2 = $2 + 10
        print $0
    }' users.txt

У другому полі додається 10.

Якщо поле містить число, зміна буде числовою.

Якщо присвоїти поле:

    $1 = "USER"

то виведений рядок починатиметься з `USER`.

Під час перебудови запису між полями використовується `OFS`.

Це важливо, якщо потрібно змінити окреме поле, зберігши решту структури даних.

---

# Видалення поля

AWK дозволяє змінювати кількість полів.

Наприклад:

    awk '{
        $2 = ""
        print
    }' users.txt

Це не видаляє друге поле зі структури, а присвоює йому порожнє значення.

Для видалення останнього поля:

    awk '{
        NF--
        print
    }' users.txt

Зменшення `NF` відкидає останнє поле.

Для видалення перших полів часто зручніше перебудувати рядок явно:

    awk '{
        for (i = 2; i <= NF; i++) {
            printf "%s%s", (i == 2 ? "" : OFS), $i
        }
        printf ORS
    }' users.txt

---

# Обробка порожніх рядків

Порожні рядки можуть бути корисними для перевірки структури файлу.

Вивести порожні рядки:

    awk 'NF == 0 { print }' file.txt

Вивести непорожні рядки:

    awk 'NF > 0 { print }' file.txt

Порахувати непорожні рядки:

    awk 'NF > 0 { count++ } END { print count + 0 }' file.txt

Видалити порожні рядки:

    awk 'NF > 0' file.txt

Останній приклад виводить лише записи, що містять поля.

# Пропуск коментарів

Припустімо, що файл містить:

    # Users
    alice 25 developer
    # Test account
    bob 30 designer

Пропустити рядки, що починаються з `#`:

    awk '!/^#/ { print }' users.txt

Пропустити також порожні рядки:

    awk '!/^#/ && NF > 0 { print }' users.txt

Важливо: якщо перед `#` можуть бути пробіли, краще використати:

    awk '!/^[[:space:]]*#/ && NF > 0 { print }' users.txt

`[[:space:]]` відповідає пробільним символам у POSIX-сумісному регулярному виразі.

# Використання змінних із командного рядка

Параметр `-v` передає значення змінної в програму `awk`.

Приклад:

    awk -v limit=25 '$2 > limit { print $1, $2 }' users.txt

Тут `limit` дорівнює `25`.

Інший приклад:

    awk -v role="developer" '$3 == role { print $1 }' users.txt

Змінні через `-v` зручно використовувати, коли значення потрібно змінювати без редагування програми.

Наприклад:

    awk -v min_age=25 '$2 >= min_age { print $1 }' users.txt

---

# Використання змінних Shell

Змінні Bash і змінні AWK — це різні змінні.

Небажано бездумно вставляти значення Bash безпосередньо в програму `awk`, особливо якщо значення може містити лапки або інші спеціальні символи.

Краще:

    min_age=25

    awk -v limit="$min_age" '$2 >= limit { print $1 }' users.txt

Тут:

    min_age → змінна Bash
    limit   → змінна AWK

Параметр `-v` є зручним способом передавання простих значень із Shell у програму `awk`.

# Робота з кількома файлами

`awk` може послідовно обробляти декілька файлів.

Приклад:

    awk '{ print FILENAME, FNR, $0 }' file1.txt file2.txt

Тут:

    FILENAME → поточний файл
    FNR      → номер запису в поточному файлі
    $0       → поточний запис

Порахувати загальну кількість записів:

    awk 'END { print NR }' file1.txt file2.txt

Порахувати кількість записів у кожному файлі:

    awk '
    FNR == 1 {
        if (FNR > 1) {
            print FILENAME, count
        }
        count = 0
    }
    {
        count++
    }
    END {
        print FILENAME, count
    }' file1.txt file2.txt

Для точного й простого підрахунку окремо по кожному файлу можна також використовувати:

    wc -l file1.txt file2.txt

# Виведення заголовків у звітах

AWK дозволяє формувати читабельні звіти.

Приклад:

    awk '
    BEGIN {
        printf "%-12s %5s %-12s\n", "NAME", "AGE", "ROLE"
        print "-------------------------------"
    }
    {
        printf "%-12s %5d %-12s\n", $1, $2, $3
    }
    END {
        print "-------------------------------"
        printf "Total users: %d\n", NR
    }' users.txt

Це дозволяє створювати таблиці з вирівнюванням колонок і підсумковою статистикою.

# Типові шаблони awk

## Вивести перше поле

    awk '{ print $1 }' file.txt

## Вивести останнє поле

    awk '{ print $NF }' file.txt

## Вивести перші два поля

    awk '{ print $1, $2 }' file.txt

## Вивести перший рядок

    awk 'NR == 1 { print }' file.txt

## Пропустити заголовок

    awk 'NR > 1 { print }' file.txt

## Вивести рядки, де друге поле більше 100

    awk '$2 > 100 { print }' file.txt

## Вивести рядки, що містять error

    awk '/error/ { print }' file.txt

## Порахувати рядки

    awk 'END { print NR }' file.txt

## Порахувати непорожні рядки

    awk 'NF > 0 { count++ } END { print count + 0 }' file.txt

## Порахувати суму другого поля

    awk '{ sum += $2 } END { print sum }' file.txt

## Порахувати середнє другого поля

    awk '{ sum += $2; count++ }
    END {
        if (count > 0) {
            print sum / count
        }
    }' file.txt

## Вивести унікальні значення першого поля

    awk '!seen[$1]++ { print $1 }' file.txt

Цей шаблон виводить перше входження кожного значення першого поля.

# Типові помилки

## ❌ Плутати $0 та $1

    $0 → увесь запис
    $1 → перше поле

## ❌ Плутати NR та NF

    NR → номер поточного запису
    NF → кількість полів поточного запису

## ❌ Плутати NR та FNR

    NR  → загальна кількість прочитаних записів
    FNR → номер запису в поточному файлі

## ❌ Неправильно задавати роздільник

Наприклад:

    awk '{ print $2 }' data.csv

Якщо файл розділений комами, ця команда не розбере CSV на окремі колонки належним чином.

Правильно для простого CSV:

    awk -F ',' '{ print $2 }' data.csv

## ❌ Використовувати неправильний номер поля

Наприклад:

    awk '{ print $4 }' file.txt

Якщо запис має лише три поля, `$4` буде порожнім.

## ❌ Забувати перевірку перед діленням

Неправильно:

    awk '{ sum += $2; count++ }
    END {
        print sum / count
    }' file.txt

Якщо записів немає, `count` буде нульовим.

Краще:

    awk '{ sum += $2; count++ }
    END {
        if (count > 0) {
            print sum / count
        }
    }' file.txt

## ❌ Забувати новий рядок у printf

    awk '{ printf "%s", $1 }' file.txt

Результати можуть зливатися в один рядок.

Краще:

    awk '{ printf "%s\n", $1 }' file.txt

## ❌ Вважати, що awk автоматично розуміє складний CSV

Команда:

    awk -F ',' '{ print $1 }' data.csv

не гарантує правильного розбору полів, які містять коми в лапках.

Для складних CSV використовуй спеціалізований парсер.

## ❌ Розраховувати на порядок асоціативного масиву

    for (key in array)

не гарантує сортування за ключами.

Для впорядкованого результату використовуй `sort` або відповідні можливості реалізації AWK.

## ❌ Змінювати $0 і очікувати збереження початкового форматування

Присвоєння полю, наприклад `$2 = "new"`, може перебудувати весь запис із використанням `OFS`.

Якщо точне збереження форматування важливе, потрібно враховувати цю поведінку.

## ❌ Використовувати awk для кожного завдання

Для простого пошуку може бути достатньо `grep`.

Для простої заміни — `sed`.

Для простого вилучення колонок — `cut`.

Для числових обчислень, роботи з полями, складних умов і статистики часто зручніший `awk`.

---

# Безпека та надійність

`awk` зазвичай використовується для читання та обробки даних, але деякі операції можуть створювати файли або запускати зовнішні команди.

Під час роботи:

- перевіряй, які саме файли передаєш на обробку;
- спочатку тестуй команди на невеликих прикладах;
- не запускай невідомі команди, отримані з ненадійних джерел;
- не передавай ненадійні дані безпосередньо в Shell-команди;
- обережно використовуй `system()` та оператори перенаправлення AWK;
- перед масовою обробкою важливих файлів перевіряй результат на копії.

Для безпечного навчання починай із команд, які лише читають файли та виводять результат у термінал.

## Основна структура

    awk 'pattern { action }' file.txt

## Увесь рядок

    $0

## Поля

    $1
    $2
    $3

## Кількість полів

    NF

## Номер запису

    NR

## Номер запису поточного файлу

    FNR

## Назва поточного файлу

    FILENAME

## Роздільник полів

    awk -F ':' '{ print $1 }' file.txt

## BEGIN

    awk 'BEGIN { print "Start" } { print }' file.txt

## END

    awk '{ count++ } END { print count }' file.txt

## Фільтрація

    awk '$2 > 10 { print }' file.txt

## Регулярний вираз

    awk '/error/ { print }' file.txt

## Порівняння поля з regex

    awk '$1 ~ /^a/ { print }' file.txt

## Сума

    awk '{ sum += $2 } END { print sum }' file.txt

## Середнє

    awk '{ sum += $2; count++ }
    END {
        if (count > 0) {
            print sum / count
        }
    }' file.txt

## Форматований вивід

    awk '{ printf "%-10s %5d\n", $1, $2 }' file.txt

## Пропуск заголовка

    awk 'NR > 1 { print }' file.txt

## Пропуск порожніх рядків

    awk 'NF > 0' file.txt

## Заміна тексту

    awk '{ gsub(/old/, "new"); print }' file.txt

## Підрахунок за ключем

    awk '{ count[$1]++ }
    END {
        for (key in count) {
            print key, count[key]
        }
    }' file.txt

## Передавання змінної

    awk -v limit=25 '$2 >= limit { print }' file.txt

# Мінішпаргалка

## Основний синтаксис

    awk 'pattern { action }' file.txt

## Поля

    $0 → увесь рядок
    $1 → перше поле
    $2 → друге поле
    $NF → останнє поле
    NF → кількість полів

## Лічильники

    NR  → загальна кількість прочитаних записів
    FNR → номер запису поточного файлу

## Роздільники

    FS  → роздільник полів під час читання
    OFS → роздільник полів під час print
    RS  → роздільник записів під час читання
    ORS → роздільник записів під час виведення

## Спеціальні блоки

    BEGIN → перед обробкою записів
    END   → після обробки записів

## Фільтрація

    awk '$2 > 10 { print }' file.txt

## Регулярні вирази

    awk '/error/ { print }' file.txt

## Підрахунок

    awk 'END { print NR }' file.txt

## Сума

    awk '{ sum += $2 } END { print sum }' file.txt

## Середнє

    awk '{ sum += $2; count++ }
    END {
        if (count > 0) {
            print sum / count
        }
    }' file.txt

## Форматування

    awk '{ printf "%-10s %5d\n", $1, $2 }' file.txt

## Заміна

    awk '{ gsub(/old/, "new"); print }' file.txt

## Асоціативний масив

    awk '{ count[$1]++ }
    END {

# Головне

• `awk` — інструмент для обробки тексту, записів і полів.

• Основна модель роботи:

    input
      ↓
    record
      ↓
    fields
      ↓
    pattern
      ↓
    action
      ↓
    output

• `$0` містить увесь поточний запис.

• `$1`, `$2`, `$3` та інші позначають окремі поля.

• `NF` — кількість полів у поточному записі.

• `NR` — загальний номер прочитаного запису.

• `FNR` — номер запису в поточному файлі.

• `FS` визначає, як розділяються вхідні поля.

• `OFS` визначає роздільник між аргументами `print`.

• `BEGIN` виконується до обробки даних.

• `END` виконується після обробки даних.

• `pattern { action }` дозволяє фільтрувати записи та виконувати над ними дії.

• `print` використовується для простого виведення.

• `printf` використовується для форматованого виведення.

• `awk` підтримує регулярні вирази, умови, цикли, змінні та арифметичні операції.

• Асоціативні масиви зручні для підрахунку частоти та групування даних.

• `awk` може читати файли, обробляти стандартне введення та працювати в Shell-пайплайнах.

• Для простого пошуку часто достатньо `grep`.

• Для простих текстових замін часто зручніший `sed`.

• Для простого вилучення колонок часто достатньо `cut`.

• Для обчислень, фільтрації за полями, агрегації та звітів `awk` є особливо корисним.

• Простий `awk -F ','` не замінює повноцінного CSV-парсера.

• Основна перевага `awk` — можливість виконувати багато операцій над текстовими даними в одній компактній програмі.

• Головна модель мислення під час роботи з `awk`:

    прочитати запис
          ↓
    розділити на поля
          ↓
    перевірити умову
          ↓
    обробити дані
          ↓
    вивести результат
          ↓
    перейти до наступного запису

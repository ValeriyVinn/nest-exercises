# Bash Scripting — Loops

У цьому розділі розглядаємо цикли Bash: `for`, `while`, `until`, а також керування виконанням циклів за допомогою `break` і `continue`.

Цикли дають змогу багаторазово виконувати команди без дублювання коду. Вони потрібні для обробки списків файлів, аргументів командного рядка, рядків тексту, числових діапазонів, каталогів і результатів виконання команд.

У Linux автоматизація часто починається саме з циклів: наприклад, перевірити наявність декількох програм, створити резервні копії файлів, обробити список користувачів або виконати одну команду для кожного елемента.

---

## 1. Основи циклів

### ✔ Що потрібно знати

- `for` — повторює команди для кожного елемента списку.
- `while` — виконує команди, поки умова істинна.
- `until` — виконує команди, поки умова хибна.
- `do` — починає тіло циклу.
- `done` — завершує цикл.
- `break` — достроково завершує цикл.
- `continue` — пропускає решту поточної ітерації та переходить до наступної.
- `"$@"` — передає кожен позиційний параметр окремо.
- `$(command)` — підставляє результат виконання команди.
- `(( ... ))` — використовується для арифметичних обчислень і перевірок.
- `[[ ... ]]` — використовується для перевірки умов у Bash.
- `read` — читає дані зі стандартного вводу.
- `seq` — генерує послідовність чисел, хоча для простих числових циклів Bash часто достатньо арифметичного `for`.

### ✔ Загальна логіка циклу

    початок циклу
        перевірка або отримання наступного елемента
        виконання команд
    кінець циклу

Цикл повторюється, доки не закінчаться елементи списку або доки умова дозволяє продовжувати виконання.

### ✔ Три основні типи

| Цикл | Коли використовувати |
|---|---|
| `for` | Відомий список елементів або діапазон |
| `while` | Потрібно повторювати, поки умова істинна |
| `until` | Потрібно повторювати, поки умова хибна |

## 2. Цикл `for` зі списком значень

Цикл `for` перебирає елементи списку по одному.

### ✔ Синтаксис

    for variable in value1 value2 value3; do
        # Команди
    done

Змінна `variable` отримує значення кожного елемента послідовно.

### ✔ Простий приклад

    #!/usr/bin/env bash

    for name in Alice Bob Charlie; do
        echo "Привіт, $name!"
    done

Результат:

    Привіт, Alice!
    Привіт, Bob!
    Привіт, Charlie!

### ✔ Перебір мов програмування

    #!/usr/bin/env bash

    for language in JavaScript TypeScript Python Bash; do
        echo "Вивчаю: $language"
    done

Результат:

    Вивчаю: JavaScript
    Вивчаю: TypeScript
    Вивчаю: Python
    Вивчаю: Bash

### ✔ Перебір назв каталогів

    #!/usr/bin/env bash

    for directory in src public practice; do
        echo "Каталог проєкту: $directory"
    done

### ✔ Перебір слів у змінній

    #!/usr/bin/env bash

    tools="git node npm"

    for tool in $tools; do
        echo "Інструмент: $tool"
    done

Цей приклад працює, тому що значення містить слова, розділені пробілами. Але загалом **не варто використовувати звичайний рядок як універсальний список**, якщо елементи можуть містити пробіли або інші спеціальні символи.

Для надійного зберігання списку в Bash краще використовувати масиви.

---

## 3. Цикл `for` із масивом

Масив дає змогу зберігати кілька окремих значень в одній змінній.

### ✔ Приклад

    #!/usr/bin/env bash

    tools=("git" "node" "npm" "python3")

    for tool in "${tools[@]}"; do
        echo "Інструмент: $tool"
    done

Вираз `"${tools[@]}"` передає кожен елемент масиву як окреме значення, навіть якщо він містить пробіли.

### ✔ Масив із пробілами

    #!/usr/bin/env bash

    files=("report.txt" "my notes.txt" "backup archive.tar.gz")

    for file in "${files[@]}"; do
        echo "Файл: $file"
    done

Результат:

    Файл: report.txt
    Файл: my notes.txt
    Файл: backup archive.tar.gz

### ✔ Індекси масиву

    #!/usr/bin/env bash

    languages=("JavaScript" "TypeScript" "Python")

    for index in "${!languages[@]}"; do
        echo "$index: ${languages[index]}"
    done

Результат:

    0: JavaScript
    1: TypeScript
    2: Python

Пояснення:

- `${languages[@]}` — усі значення масиву.
- `${!languages[@]}` — усі індекси масиву.
- `languages[index]` — елемент за заданим індексом.

Індекси звичайного Bash-масиву починаються з `0`.

## 4. Цикл `for` із числовим діапазоном

Bash підтримує арифметичну форму циклу `for`.

### ✔ Синтаксис

    for (( initialization; condition; update )); do
        # Команди
    done

Три частини:

1. `initialization` — початкове значення лічильника.
2. `condition` — умова продовження циклу.
3. `update` — зміна лічильника після кожної ітерації.

### ✔ Рахунок від 1 до 5

    #!/usr/bin/env bash

    for (( i = 1; i <= 5; i++ )); do
        echo "$i"
    done

Результат:

    1
    2
    3
    4
    5

### ✔ Рахунок від 0 до 10 із кроком 2

    #!/usr/bin/env bash

    for (( i = 0; i <= 10; i += 2 )); do
        echo "$i"
    done

Результат:

    0
    2
    4
    6
    8
    10

### ✔ Зворотний відлік

    #!/usr/bin/env bash

    for (( i = 5; i >= 1; i-- )); do
        echo "$i"
    done

    echo "Старт!"

### ✔ Таблиця множення

    #!/usr/bin/env bash

    number=7

    for (( i = 1; i <= 10; i++ )); do
        echo "$number × $i = $((number * i))"
    done

Пояснення:

- `i++` збільшує `i` на одиницю.
- `i--` зменшує `i` на одиницю.
- `i += 2` збільшує `i` на два.
- `$((number * i))` обчислює добуток.

Арифметична форма `for (( ... ))` — це конструкція Bash, а не POSIX-сумісний синтаксис для всіх оболонок.

## 5. Цикл `for` із розгортанням файлів

Bash може перебирати файли, які відповідають шаблону.

### ✔ Усі файли `.txt` у поточному каталозі

    #!/usr/bin/env bash

    for file in *.txt; do
        echo "$file"
    done

Шаблон `*.txt` розгортається Bash у список відповідних імен файлів.

Але є важлива особливість: якщо відповідних файлів немає, за стандартних налаштувань Bash шаблон може залишитися нерозгорнутим, і цикл один раз отримає буквальне значення `*.txt`.

### ✔ Безпечніша перевірка за допомогою `nullglob`

    #!/usr/bin/env bash

    shopt -s nullglob

    for file in *.txt; do
        echo "$file"
    done

`nullglob` змушує шаблон без збігів розгортатися в порожній список.

Це налаштування діє в поточній оболонці, тому в окремому скрипті зазвичай не створює проблем для інших програм.

### ✔ Обробка файлів із пробілами в назвах

    #!/usr/bin/env bash

    shopt -s nullglob

    for file in *.txt; do
        if [[ -f "$file" ]]; then
            echo "Знайдено файл: $file"
        fi
    done

Використовуй `"$file"` у командах, щоб назва з пробілами залишалася одним аргументом.

### ✔ Пошук файлів у каталозі

    #!/usr/bin/env bash

    directory="documents"

    if [[ ! -d "$directory" ]]; then
        echo "Помилка: каталогу $directory не знайдено"
        exit 1
    fi

    shopt -s nullglob

    for file in "$directory"/*.txt; do
        [[ -f "$file" ]] || continue
        echo "Текстовий файл: $file"
    done

Тут шаблон `"${directory}"/*.txt` можна записати як `"$directory"/*.txt`: змінна береться в лапки, а `*.txt` залишається поза лапками, щоб Bash міг виконати розгортання шаблону.

### ✔ Важливе правило

Не використовуй конструкцію `for file in $(ls)` для перебору файлів.

    # Не рекомендується
    for file in $(ls); do
        echo "$file"
    done

Вона неправильно обробляє назви з пробілами, табуляціями та іншими спеціальними символами.

Для простого перебору файлів краще використовувати шаблони Bash, а для рекурсивного або складнішого пошуку — `find`.

## 6. Цикл `while`

`while` повторює команди, поки умова істинна.

### ✔ Синтаксис

    while [[ умова ]]; do
        # Команди
    done

Перед кожною ітерацією перевіряється умова. Якщо вона хибна, цикл завершується.

### ✔ Лічильник

    #!/usr/bin/env bash

    i=1

    while (( i <= 5 )); do
        echo "$i"
        ((i++))
    done

Результат:

    1
    2
    3
    4
    5

### ✔ Як працює цикл

1. `i=1` створює початкове значення.
2. `(( i <= 5 ))` перевіряє умову.
3. `echo "$i"` виводить поточне число.
4. `((i++))` збільшує лічильник.
5. Після цього Bash знову перевіряє умову.

Коли `i` стане `6`, умова буде хибною і цикл завершиться.

### ✔ Зворотний відлік через `while`

    #!/usr/bin/env bash

    i=5

    while (( i > 0 )); do
        echo "$i"
        ((i--))
    done

    echo "Готово!"

### ✔ Важливо: не забувай змінювати умову

Неправильно:

    i=1

    while (( i <= 5 )); do
        echo "$i"
    done

Значення `i` не змінюється, тому цикл стає нескінченним.

Правильно:

    i=1

    while (( i <= 5 )); do
        echo "$i"
        ((i++))
    done

## 7. Цикл `until`

`until` працює протилежно до `while`: повторює команди, поки умова хибна.

### ✔ Синтаксис

    until [[ умова ]]; do
        # Команди
    done

Цикл завершується, коли умова стає істинною.

### ✔ Приклад

    #!/usr/bin/env bash

    i=1

    until (( i > 5 )); do
        echo "$i"
        ((i++))
    done

Результат:

    1
    2
    3
    4
    5

Умова `i > 5` спочатку хибна, тому цикл працює. Коли `i` стане `6`, умова стане істинною і цикл завершиться.

### ✔ `while` проти `until`

    # while: повторювати, поки умова істинна
    while (( i <= 5 )); do
        echo "$i"
        ((i++))
    done

    # until: повторювати, поки умова хибна
    until (( i > 5 )); do
        echo "$i"
        ((i++))
    done

Обидва приклади можуть виконувати однакову роботу.

### ✔ Коли використовувати `until`

`until` часто зручно читати, коли очікується певна подія:

    until [[ -f "ready.flag" ]]; do
        sleep 1
    done

    echo "Файл ready.flag з'явився"

Але в реальних скриптах очікування варто обмежувати часом або кількістю спроб, щоб програма не чекала нескінченно.

## 8. `break` — дострокове завершення циклу

`break` негайно завершує поточний цикл.

### ✔ Приклад

    #!/usr/bin/env bash

    for (( i = 1; i <= 10; i++ )); do
        if (( i == 6 )); then
            break
        fi

        echo "$i"
    done

Результат:

    1
    2
    3
    4
    5

Коли `i` стає `6`, виконується `break`, і цикл завершується.

### ✔ Пошук елемента

    #!/usr/bin/env bash

    target="node"

    for tool in git node npm python3; do
        if [[ "$tool" == "$target" ]]; then
            echo "Знайдено: $tool"
            break
        fi
    done

Після знаходження потрібного елемента немає сенсу продовжувати пошук у цьому списку.

### ✔ Вихід із вкладених циклів

За замовчуванням `break` завершує лише найближчий цикл.

    #!/usr/bin/env bash

    for (( i = 1; i <= 3; i++ )); do
        for (( j = 1; j <= 3; j++ )); do
            if (( i == 2 && j == 2 )); then
                break
            fi

            echo "i=$i, j=$j"
        done
    done

`break 2` завершує два рівні вкладених циклів:

    break 2

Використовуй цей варіант лише тоді, коли справді потрібно вийти з декількох рівнів циклів.

## 9. `continue` — перехід до наступної ітерації

`continue` пропускає решту поточного проходу циклу й переходить до наступної ітерації.

### ✔ Приклад

    #!/usr/bin/env bash

    for (( i = 1; i <= 5; i++ )); do
        if (( i == 3 )); then
            continue
        fi

        echo "$i"
    done

Результат:

    1
    2
    4
    5

Число `3` не виводиться, оскільки команда `echo` пропускається для цієї ітерації.

### ✔ Виведення лише парних чисел

    #!/usr/bin/env bash

    for (( i = 1; i <= 10; i++ )); do
        if (( i % 2 != 0 )); then
            continue
        fi

        echo "$i"
    done

Результат:

    2
    4
    6
    8
    10

### ✔ `break` і `continue`

| Команда | Дія |
|---|---|
| `break` | Завершує цикл |
| `continue` | Пропускає решту поточної ітерації |
| `break 2` | Завершує два рівні вкладених циклів |
| `continue 2` | Переходить до наступної ітерації циклу на два рівні вище |

## 10. Читання даних через `read` у циклі

Цикли часто використовують для обробки рядків, які користувач вводить у терміналі.

### ✔ Читання одного значення

    #!/usr/bin/env bash

    read -r -p "Введи своє ім'я: " name

    echo "Привіт, $name!"

Пояснення:

- `read` читає рядок зі стандартного вводу.
- `-r` вимикає спеціальну обробку зворотних слешів.
- `-p` виводить запрошення перед читанням.

### ✔ Цикл введення

    #!/usr/bin/env bash

    while true; do
        read -r -p "Введи команду (quit для виходу): " command

        if [[ "$command" == "quit" ]]; then
            break
        fi

        echo "Ти ввів: $command"
    done

`while true` створює цикл, який повторюється, доки його не завершить `break` або інша зовнішня умова.

### ✔ Обмеження кількості спроб

    #!/usr/bin/env bash

    attempts=0
    max_attempts=3

    while (( attempts < max_attempts )); do
        read -r -p "Введи пароль: " password

        if [[ "$password" == "linux" ]]; then
            echo "Правильно"
            exit 0
        fi

        echo "Неправильно"
        ((attempts++))
    done

    echo "Спроби закінчилися"
    exit 1

Це лише навчальний приклад. Не зберігай реальні паролі у відкритому вигляді в скриптах.

## 11. Читання файлу рядок за рядком

Bash дає змогу обробляти текстові файли за допомогою `while read`.

### ✔ Базовий приклад

    #!/usr/bin/env bash

    while read -r line; do
        echo "Рядок: $line"
    done < "data.txt"

Пояснення:

- `read -r line` читає один рядок.
- `line` містить прочитаний текст.
- `< "data.txt"` перенаправляє вміст файлу на стандартний ввід циклу.
- Цикл повторюється, поки `read` успішно читає рядки.

### ✔ Надійніший варіант для файлів без символу нового рядка наприкінці

    #!/usr/bin/env bash

    while IFS= read -r line || [[ -n "$line" ]]; do
        printf 'Рядок: %s\n' "$line"
    done < "data.txt"

Цей варіант також обробляє останній непорожній рядок, якщо файл не закінчується символом нового рядка.

Пояснення:

- `IFS=` запобігає видаленню пробілів на початку й у кінці рядка під час читання.
- `read -r` зберігає зворотні слеші як звичайні символи.
- `|| [[ -n "$line" ]]` дає змогу обробити останній рядок, навіть якщо `read` повернув ненульовий статус через кінець файлу.

### ✔ Приклад: підрахунок рядків

    #!/usr/bin/env bash

    file="data.txt"

    if [[ ! -f "$file" ]]; then
        echo "Помилка: файл не знайдено"
        exit 1
    fi

    count=0

    while IFS= read -r line || [[ -n "$line" ]]; do
        ((count += 1))
    done < "$file"

    echo "Кількість рядків: $count"

### ✔ Чого не варто робити

    # Не рекомендується
    cat data.txt | while read line; do
        count=$((count + 1))
    done

У Bash цикл, який отримує ввід через конвеєр, часто виконується в окремій підоболонці. Зміни змінних усередині такого циклу можуть бути недоступні після його завершення.

Краще використовувати перенаправлення:

    while IFS= read -r line; do
        ((count += 1))
    done < "data.txt"

## 12. Перебір аргументів командного рядка

У Bash можна перебирати аргументи, які передали скрипту.

### ✔ Використання `"$@"`

    #!/usr/bin/env bash

    for argument in "$@"; do
        echo "Аргумент: $argument"
    done

Запуск:

    ./script.sh Alice 25 "Hello world"

Результат:

    Аргумент: Alice
    Аргумент: 25
    Аргумент: Hello world

`"$@"` зберігає кожен аргумент як окремий елемент, навіть якщо він містить пробіли.

### ✔ Чому не варто використовувати `$*` без лапок

    # Не рекомендується
    for argument in $*; do
        echo "$argument"
    done

Такий код може розбивати аргументи за пробілами й розгортати шаблони файлів.

Для стандартного перебору аргументів використовуй:

    for argument in "$@"; do
        echo "$argument"
    done

### ✔ Перевірка кількості аргументів

    #!/usr/bin/env bash

    if [[ $# -eq 0 ]]; then
        echo "Не передано жодного аргументу"
        exit 1
    fi

    for argument in "$@"; do
        echo "$argument"
    done

### ✔ Передавання аргументів іншій команді

    #!/usr/bin/env bash

    process_arguments() {
        for argument in "$@"; do
            printf 'Отримано: %s\n' "$argument"
        done
    }

    process_arguments "$@"

Тут аргументи скрипта передаються функції без втрати меж між аргументами.

## 13. Вкладені цикли

Вкладений цикл — це цикл усередині іншого циклу.

### ✔ Приклад: координати

    #!/usr/bin/env bash

    for (( row = 1; row <= 3; row++ )); do
        for (( col = 1; col <= 3; col++ )); do
            echo "Рядок $row, стовпець $col"
        done
    done

Зовнішній цикл керує рядками, а внутрішній — стовпцями.

### ✔ Таблиця множення

    #!/usr/bin/env bash

    for (( i = 1; i <= 5; i++ )); do
        for (( j = 1; j <= 5; j++ )); do
            printf '%4d' "$((i * j))"
        done

        printf '\n'
    done

`printf` дає змогу форматувати вивід і вирівнювати числа за шириною.

### ✔ Скільки разів виконається внутрішній цикл?

Якщо зовнішній цикл має 3 ітерації, а внутрішній — 4, то тіло внутрішнього циклу виконається:

    3 × 4 = 12 разів

Вкладені цикли корисні для роботи з таблицями, матрицями, наборами комбінацій і структурованими даними.

Але зайва вкладеність може ускладнювати код, тому використовуй її лише тоді, коли вона справді потрібна.

## 14. Цикли та арифметика

Bash підтримує цілочисельну арифметику.

### ✔ Сума чисел від 1 до 10

    #!/usr/bin/env bash

    sum=0

    for (( i = 1; i <= 10; i++ )); do
        ((sum += i))
    done

    echo "Сума: $sum"

Результат:

    Сума: 55

### ✔ Підрахунок парних чисел

    #!/usr/bin/env bash

    count=0

    for (( i = 1; i <= 20; i++ )); do
        if (( i % 2 == 0 )); then
            ((count += 1))
        fi
    done

    echo "Кількість парних чисел: $count"

### ✔ Факторіал

    #!/usr/bin/env bash

    number=5
    result=1

    for (( i = 1; i <= number; i++ )); do
        ((result *= i))
    done

    echo "$number! = $result"

Результат:

    5! = 120

Усі арифметичні обчислення Bash виконуються над цілими числами. Для великих значень потрібно враховувати обмеження діапазону цілих чисел у системі.

### ✔ Важливо про `(( expression ))`

У Bash арифметична команда `(( expression ))` повертає статус `1`, якщо результат виразу дорівнює нулю, і `0`, якщо результат ненульовий.

Наприклад:

    (( i++ ))

Якщо початкове значення `i` дорівнює `0`, постінкремент повертає старе значення `0`, тому статус арифметичної команди буде `1`, хоча `i` вже збільшиться до `1`.

Це може мати значення, якщо використовується `set -e`.

Для простого навчання це не проблема, але в скриптах із суворим режимом можна використовувати, наприклад:

    ((i += 1))

Або:

    i=$((i + 1))

Поведінка `set -e` має винятки, зокрема в умовах циклів і логічних виразах, тому не слід вважати його універсальним механізмом обробки всіх помилок.

## 15. Очікування події з обмеженням часу

Іноді скрипту потрібно дочекатися появи файлу або готовності ресурсу.

### ✔ Очікування файлу з обмеженням кількості спроб

    #!/usr/bin/env bash

    file="ready.flag"
    max_attempts=10
    attempts=0

    until [[ -f "$file" ]]; do
        if (( attempts >= max_attempts )); then
            echo "Помилка: файл не з'явився вчасно"
            exit 1
        fi

        echo "Очікування файлу..."
        sleep 1
        ((attempts += 1))
    done

    echo "Файл готовий"

Скрипт перевіряє файл до десяти разів, роблячи паузу в одну секунду між перевірками.

### ✔ Чому потрібне обмеження?

Без обмеження цикл може чекати нескінченно:

    until [[ -f "ready.flag" ]]; do
        sleep 1
    done

Якщо файл ніколи не з'явиться, скрипт не завершиться самостійно.

Для очікування сервісів або мережевих ресурсів у реальних проєктах також потрібно враховувати тайм-аути, помилки команд і можливість переривання.

## 16. Практичний проєкт: перевірка інструментів розробника

Створимо `check-tools.sh`, який перевіряє наявність основних інструментів у системі.

### ✔ Код

    #!/usr/bin/env bash

    tools=("git" "node" "npm" "python3" "bash")

    missing=0

    for tool in "${tools[@]}"; do
        if command -v "$tool" >/dev/null 2>&1; then
            printf '[OK]      %s\n' "$tool"
        else
            printf '[MISSING] %s\n' "$tool"
            ((missing += 1))
        fi
    done

    echo

    if (( missing == 0 )); then
        echo "Усі інструменти знайдено"
        exit 0
    else
        echo "Не знайдено інструментів: $missing"
        exit 1
    fi

### ✔ Що тут використано?

- Масив `tools` зберігає список команд.
- `for` перебирає кожну команду.
- `command -v` перевіряє доступність команди в `PATH`.
- `if / else` визначає, чи знайдено команду.
- `missing` рахує відсутні інструменти.
- `exit 0` повертає успішний результат, якщо всі інструменти доступні.
- `exit 1` сигналізує, що деяких інструментів немає.

### ✔ Запуск

    chmod +x check-tools.sh
    ./check-tools.sh

Такий скрипт можна розширити, додавши перевірку версій інструментів або перевірку необхідних каталогів проєкту.

## 17. Практичний проєкт: резервне копіювання файлів

Створимо навчальний скрипт `backup-txt.sh`, який копіює всі текстові файли з указаного каталогу в каталог резервних копій.

### ✔ Код

    #!/usr/bin/env bash

    if [[ $# -ne 2 ]]; then
        echo "Використання: $0 SOURCE_DIR BACKUP_DIR"
        exit 1
    fi

    source_dir=$1
    backup_dir=$2

    if [[ ! -d "$source_dir" ]]; then
        echo "Помилка: каталог-джерело не знайдено"
        exit 1
    fi

    if ! mkdir -p -- "$backup_dir"; then
        echo "Помилка: не вдалося створити каталог резервних копій"
        exit 1
    fi

    shopt -s nullglob

    files=("$source_dir"/*.txt)

    if (( ${#files[@]} == 0 )); then
        echo "Текстових файлів не знайдено"
        exit 0
    fi

    for file in "${files[@]}"; do
        if cp -- "$file" "$backup_dir/"; then
            echo "Скопійовано: $file"
        else
            echo "Помилка копіювання: $file"
            exit 1
        fi
    done

    echo "Резервне копіювання завершено"

### ✔ Запуск

    chmod +x backup-txt.sh
    ./backup-txt.sh documents backup

### ✔ Чого навчає цей проєкт?

- Перевіряти кількість аргументів.
- Перевіряти існування каталогу.
- Створювати каталог через `mkdir -p`.
- Перебирати файли через масив.
- Використовувати `nullglob`, щоб уникнути буквального `*.txt`, коли збігів немає.
- Обробляти помилки команд.
- Використовувати `for` для повторення операцій.

Це навчальний приклад. Для повноцінного резервного копіювання потрібно додатково продумати перезапис файлів, права доступу, символічні посилання, підкаталоги, журнали та відновлення даних.

## 18. Практичний проєкт: меню в терміналі

Створимо `menu.sh`, який показує меню й повторює його, поки користувач не вибере вихід.

### ✔ Код

    #!/usr/bin/env bash

    while true; do
        echo
        echo "=== Меню ==="
        echo "1. Показати поточний каталог"
        echo "2. Показати дату"
        echo "3. Показати користувача"
        echo "0. Вихід"

        read -r -p "Обери пункт: " choice

        case "$choice" in
            1)
                pwd
                ;;
            2)
                date
                ;;
            3)
                whoami
                ;;
            0)
                echo "До побачення!"
                break
                ;;
            *)
                echo "Невідомий пункт меню"
                ;;
        esac
    done

### ✔ Як це працює?

1. `while true` запускає меню без обмеження кількості повторень.
2. `read -r` отримує вибір користувача.
3. `case` визначає, яку команду виконати.
4. `break` завершує цикл після вибору `0`.
5. Якщо введено невідоме значення, скрипт повідомляє про помилку й показує меню знову.

Це поширений шаблон для невеликих інтерактивних Bash-утиліт.

## 19. Поширені помилки

### ✔ Помилка 1. Забули змінити лічильник

Неправильно:

    i=1

    while (( i <= 5 )); do
        echo "$i"
    done

Цикл нескінченний, оскільки `i` не змінюється.

Правильно:

    i=1

    while (( i <= 5 )); do
        echo "$i"
        ((i += 1))
    done

### ✔ Помилка 2. Неправильна умова завершення

    for (( i = 1; i < 5; i++ )); do
        echo "$i"
    done

Цей цикл виведе числа від `1` до `4`, а не до `5`.

Щоб включити `5`, потрібно:

    for (( i = 1; i <= 5; i++ )); do
        echo "$i"
    done

### ✔ Помилка 3. Переплутали `while` і `until`

`while` повторюється, поки умова істинна.

`until` повторюється, поки умова хибна.

Перед написанням циклу сформулюй умову словами: «повторювати, поки...» — це допомагає вибрати правильну конструкцію.

### ✔ Помилка 4. Використали `"$@"` неправильно

Для перебору аргументів потрібно:

    for argument in "$@"; do
        echo "$argument"
    done

Не прибирай лапки навколо `"$@"`, якщо хочеш зберегти межі аргументів.

### ✔ Помилка 5. Використали `$(ls)`

Неправильно:

    for file in $(ls); do
        echo "$file"
    done

Це може неправильно обробляти назви файлів із пробілами або спеціальними символами.

Для звичайного перебору файлів:

    shopt -s nullglob

    for file in *.txt; do
        echo "$file"
    done

### ✔ Помилка 6. Неправильно прочитали файл

Ризикований варіант:

    while read line; do
        echo "$line"
    done < data.txt

Краще:

    while IFS= read -r line || [[ -n "$line" ]]; do
        printf '%s\n' "$line"
    done < data.txt

Так зберігаються пробіли на початку й у кінці рядків, зворотні слеші та останній непорожній рядок без завершального символу нового рядка.

### ✔ Помилка 7. Забули `done`

Неправильно:

    for name in Alice Bob; do
        echo "$name"

Правильно:

    for name in Alice Bob; do
        echo "$name"
    done

### ✔ Помилка 8. Неправильно використовують `break`

`break` завершує цикл, а не лише поточну ітерацію.

Якщо потрібно пропустити один елемент, використовуй `continue`.

### ✔ Помилка 9. Проблема з `set -e` і арифметикою

У скриптах із `set -e` деякі арифметичні команди, які повертають ненульовий статус, можуть призвести до завершення скрипта.

Наприклад:

    ((count++))

Якщо `count` спочатку дорівнює `0`, постінкремент поверне попереднє значення `0`, тому статус арифметичної команди буде ненульовим.

Для збільшення лічильника можна використовувати:

    ((count += 1))

Проте `set -e` має контекстні винятки й не замінює явну перевірку помилок.

### ✔ Помилка 10. Не врахували пробіли в шляхах

Неправильно:

    for file in $directory/*.txt; do
        echo "$file"
    done

Якщо значення `directory` містить пробіли, такий код може працювати неправильно.

Правильно:

    for file in "$directory"/*.txt; do
        echo "$file"
    done

## 20. Як перевіряти цикли

### ✔ Перевірка синтаксису

    bash -n script.sh

Перевіряє синтаксис скрипта без виконання його основної логіки.

### ✔ Запуск із трасуванням

    bash -x script.sh

Показує команди та їхні розгорнуті значення під час виконання. Це допомагає зрозуміти, скільки разів виконується цикл і чому він завершується.

### ✔ Перевірка за допомогою ShellCheck

    shellcheck script.sh

ShellCheck допомагає виявляти типові помилки в Bash-скриптах.

### ✔ Переривання нескінченного циклу

У терміналі зазвичай можна натиснути:

    Ctrl + C

Це надсилає сигнал переривання поточному процесу, хоча скрипт може мати власну обробку сигналів.

Краще не допускати нескінченних циклів через правильні умови завершення, лічильники та обмеження часу.

## 23. Що потрібно пам'ятати

- `for` перебирає список елементів.
- `for (( ... ))` зручний для числових циклів.
- `while` виконується, поки умова істинна.
- `until` виконується, поки умова хибна.
- `do` починає тіло циклу.
- `done` завершує цикл.
- `break` завершує цикл.
- `continue` пропускає решту поточної ітерації.
- `break 2` завершує два рівні вкладених циклів.
- `continue 2` переходить до наступної ітерації циклу на два рівні вище.
- `"${array[@]}"` перебирає елементи масиву окремо.
- `"$@"` перебирає аргументи скрипта, зберігаючи їхні межі.
- `$(command)` підставляє результат виконання команди.
- `read -r` читає рядок без спеціальної обробки зворотних слешів.
- `while IFS= read -r line` — поширений шаблон читання текстового файлу.
- `shopt -s nullglob` дозволяє шаблонам без збігів розгортатися в порожній список.
- `"$directory"/*.txt` дає змогу використовувати каталог із пробілами в назві й залишати шаблон доступним для розгортання.
- Не використовуй `for file in $(ls)` для надійної обробки файлів.
- Завжди перевіряй умову завершення циклу.
- Для очікування подій використовуй обмеження часу або кількості спроб.
- `bash -n script.sh` перевіряє синтаксис.
- `bash -x script.sh` допомагає відстежити виконання.
- `shellcheck script.sh` допомагає знайти типові помилки.

## 24. Міні-шпаргалка

    # Перебір списку
    for item in one two three; do
        echo "$item"
    done

    # Перебір масиву
    items=("one" "two words" "three")

    for item in "${items[@]}"; do
        echo "$item"
    done

    # Числовий цикл
    for (( i = 1; i <= 10; i++ )); do
        echo "$i"
    done

    # Цикл із кроком
    for (( i = 0; i <= 20; i += 2 )); do
        echo "$i"
    done

    # while
    i=1

    while (( i <= 5 )); do
        echo "$i"
        ((i += 1))
    done

    # until
    i=1

    until (( i > 5 )); do
        echo "$i"
        ((i += 1))
    done

    # break
    for item in one two three; do
        [[ "$item" == "two" ]] && break
        echo "$item"
    done

    # continue
    for (( i = 1; i <= 5; i++ )); do
        (( i == 3 )) && continue
        echo "$i"
    done

    # Перебір аргументів
    for argument in "$@"; do
        echo "$argument"
    done

    # Перебір текстових файлів
    shopt -s nullglob

    for file in *.txt; do
        echo "$file"
    done

    # Читання файлу
    while IFS= read -r line || [[ -n "$line" ]]; do
        printf '%s\n' "$line"
    done < "data.txt"

    # Очікування файлу з обмеженням
    attempts=0

    until [[ -f "ready.flag" ]]; do
        if (( attempts >= 10 )); then
            echo "Час очікування вичерпано"
            exit 1
        fi

        sleep 1
        ((attempts += 1))
    done

    # Перевірка синтаксису
    bash -n script.sh

    # Трасування
    bash -x script.sh

## 25. Підсумок

Цикли — один із головних інструментів автоматизації в Bash. Вони дозволяють повторювати команди, обробляти списки даних і файлів, читати текст, рахувати значення та створювати інтерактивні сценарії.

Після опанування цієї теми ти маєш уміти:

- використовувати `for` для перебору списків, масивів і числових діапазонів;
- застосовувати `while` та `until` залежно від умови продовження;
- керувати виконанням за допомогою `break` і `continue`;
- перебирати аргументи через `"$@"`;
- безпечно обробляти файли з пробілами в назвах;
- читати текстові файли рядок за рядком;
- створювати цикли з лічильниками та обмеженням кількості спроб;
- перевіряти результати команд усередині циклів;
- використовувати цикли в практичних скриптах для Linux.

**Головне правило:** перед написанням циклу визнач, що саме повторюється, за якої умови цикл продовжується і що гарантує його завершення.

Наступна тема: `05-functions` — функції Bash, параметри функцій, `return`, локальні змінні та повторне використання коду.

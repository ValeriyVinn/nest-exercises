# Bash Scripting — 06. Arrays

Масиви (`arrays`) у Bash — це структура даних, яка дозволяє зберігати кілька значень під одним ім’ям і звертатися до кожного елемента за індексом або ключем.

Масиви корисні, коли Bash-скрипт повинен працювати зі списками файлів, аргументів, каталогів, команд, користувачів або інших значень.

## 1. Основи масивів

### 1.1. Що таке масив

Звичайна змінна зберігає одне значення:

    name="Valeriy"

    echo "$name"

Результат:

    Valeriy

Масив дозволяє зберігати декілька значень:

    names=("Valeriy" "Olena" "Ivan")

Кожне значення має власний індекс:

    # Індекс:  0          1        2
    names=("Valeriy" "Olena" "Ivan")

У Bash індексація масивів починається з `0`.

    echo "${names[0]}"    # Valeriy
    echo "${names[1]}"    # Olena
    echo "${names[2]}"    # Ivan

✔ Масив — це набір елементів під одним ім’ям.
✔ Кожен елемент має індекс.
✔ Індекси звичайного індексованого масиву починаються з `0`.
✔ Для доступу до елементів використовують `${array[index]}`.

### 1.2. Основні типи масивів у Bash

Bash підтримує два основні типи масивів:

| Тип | Призначення | Приклад |
|---|---|---|
| Indexed array | Елементи з числовими індексами | `colors=("red" "green" "blue")` |
| Associative array | Елементи з текстовими ключами | `declare -A user` |

Індексовані масиви використовують для впорядкованих списків значень.

Асоціативні масиви використовують, коли потрібно пов’язати ключ із певним значенням, наприклад ім’я налаштування з його значенням.

## 2. Створення індексованих масивів

### 2.1. Створення масиву з усіма елементами

Найпростіший спосіб — записати значення в круглих дужках через пробіли.

    colors=("red" "green" "blue")

    echo "${colors[0]}"
    echo "${colors[1]}"
    echo "${colors[2]}"

Результат:

    red
    green
    blue

Важливо: значення розділяються пробілами, а не комами.

Правильно:

    numbers=(10 20 30)

Неправильно, якщо потрібні три окремі числові елементи:

    numbers=(10, 20, 30)

У другому випадку коми стають частиною значень, а не роздільниками масиву.

### 2.2. Створення порожнього масиву

    files=()

Додати елементи можна пізніше:

    files+=("index.html")
    files+=("styles.css")
    files+=("script.js")

Перевірити вміст:

    declare -p files

Приблизний результат:

    declare -a files=([0]="index.html" [1]="styles.css" [2]="script.js")

Команда `declare -p` показує оголошення змінної та її значення.

### 2.3. Створення масиву з окремими індексами

Масив можна заповнювати не послідовно:

    numbers[0]=10
    numbers[1]=20
    numbers[5]=60

    echo "${numbers[0]}"
    echo "${numbers[1]}"
    echo "${numbers[5]}"

Результат:

    10
    20
    60

Між індексами `1` і `5` можуть залишатися незаповнені позиції.

Не варто вважати, що кількість елементів завжди дорівнює найбільшому індексу плюс один.

## 3. Доступ до елементів масиву

### 3.1. Отримання одного елемента

Для доступу до конкретного елемента використовують конструкцію `${array[index]}`.

    languages=("JavaScript" "Python" "Bash")

    echo "${languages[0]}"    # JavaScript
    echo "${languages[1]}"    # Python
    echo "${languages[2]}"    # Bash

Змінна масиву без індексу не є правильним способом отримати всі його елементи.

    echo "$languages"

Цей запис зазвичай виводить лише перший елемент.

Щоб отримати всі елементи, використовуй:

    echo "${languages[@]}"

А для надійного перебору значень, зокрема тих, що містять пробіли:

    printf '%s\n' "${languages[@]}"

### 3.2. Отримання всіх елементів

Для виведення всіх елементів:

    colors=("red" "green" "blue")

    printf '%s\n' "${colors[@]}"

Результат:

    red
    green
    blue

У подвійних лапках `"${colors[@]}"` кожен елемент масиву передається як окреме слово.

Це особливо важливо, якщо елемент містить пробіли:

    files=("index.html" "main styles.css" "app.js")

    printf '<%s>\n' "${files[@]}"

Результат:

    <index.html>
    <main styles.css>
    <app.js>

Кожен елемент залишається окремим аргументом.

### 3.3. Різниця між `${array[@]}` і `${array[*]}`

Обидва вирази пов’язані з отриманням усіх елементів, але мають важливу відмінність у подвійних лапках.

    colors=("red" "green" "blue")

    printf '<%s>\n' "${colors[@]}"

Результат:

    <red>
    <green>
    <blue>

Тепер:

    printf '<%s>\n' "${colors[*]}"

У подвійних лапках `"${colors[*]}"` усі елементи об’єднуються в один рядок, використовуючи перший символ змінної `IFS` як роздільник.

За стандартного `IFS` результат буде таким:

    <red green blue>

Порівняння:

| Вираз | Поведінка в подвійних лапках |
|---|---|
| `"${array[@]}"` | Кожен елемент — окреме слово |
| `"${array[*]}"` | Усі елементи — одне слово |

✔ Для циклів, аргументів команд і більшості практичних операцій використовуй `"${array[@]}"`.

### 3.4. Отримання довжини масиву

Щоб отримати кількість елементів, використовують `${#array[@]}`.

    languages=("JavaScript" "Python" "Bash")

    echo "${#languages[@]}"

Результат:

    3

Важливо: це кількість наявних елементів, а не обов’язково найбільший індекс плюс один.

    numbers=([0]=10 [5]=60)

    echo "${#numbers[@]}"    # 2
    echo "${!numbers[@]}"    # 0 5

У цьому масиві два елементи, хоча найбільший індекс дорівнює `5`.

### 3.5. Отримання індексів масиву

Конструкція `${!array[@]}` повертає індекси, які використовуються в масиві.

    colors=([0]="red" [2]="blue" [5]="green")

    printf '%s\n' "${!colors[@]}"

Результат:

    0
    2
    5

Це корисно для масивів із пропущеними індексами.

## 4. Додавання, зміна та видалення елементів

### 4.1. Додавання елемента

Оператор `+=` додає новий елемент до індексованого масиву.

    fruits=("apple" "banana")

    fruits+=("orange")

    printf '%s\n' "${fruits[@]}"

Результат:

    apple
    banana
    orange

Додавання декількох елементів:

    fruits+=("pear" "grape")

    printf '%s\n' "${fruits[@]}"

### 4.2. Зміна елемента

Щоб змінити значення, присвой нове значення відповідному індексу.

    colors=("red" "green" "blue")

    colors[1]="yellow"

    printf '%s\n' "${colors[@]}"

Результат:

    red
    yellow
    blue

### 4.3. Видалення елемента

Команда `unset` видаляє елемент за індексом.

    colors=("red" "green" "blue")

    unset 'colors[1]'

    printf '%s\n' "${!colors[@]}"
    printf '%s\n' "${colors[@]}"

Після видалення індекси автоматично не перенумеровуються.

Наприклад, якщо видалити елемент з індексом `1`, індекси `0` і `2` залишаться такими самими.

Щоб видалити весь масив:

    unset colors

Після цього масив `colors` більше не містить попередніх значень.

### 4.4. Очищення масиву

Для видалення всіх елементів можна присвоїти порожній масив:

    colors=("red" "green" "blue")

    colors=()

    echo "${#colors[@]}"    # 0

На відміну від `unset colors`, змінна залишається масивом, але без елементів.

## 5. Перебір масиву за допомогою `for`

Цикл `for` — один із найважливіших інструментів роботи з масивами в Bash.

### 5.1. Перебір усіх елементів

    fruits=("apple" "banana" "orange")

    for fruit in "${fruits[@]}"; do
        echo "$fruit"
    done

Результат:

    apple
    banana
    orange

Тут:

- `fruits` — масив.
- `fruit` — тимчасова змінна для поточного елемента.
- `"${fruits[@]}"` — усі елементи масиву.
- `do` — початок тіла циклу.
- `done` — кінець циклу.

### 5.2. Перебір масиву з індексами

Якщо потрібні і значення, і індекси, використовуй `${!array[@]}`.

    colors=("red" "green" "blue")

    for index in "${!colors[@]}"; do
        printf 'Індекс: %s, значення: %s\n' \
            "$index" "${colors[$index]}"
    done

Результат:

    Індекс: 0, значення: red
    Індекс: 1, значення: green
    Індекс: 2, значення: blue

Цей підхід також працює з масивами, в яких індекси пропущені.

### 5.3. Обробка кожного файлу в масиві

    files=("index.html" "styles.css" "script.js")

    for file in "${files[@]}"; do
        if [[ -f "$file" ]]; then
            echo "Файл існує: $file"
        else
            echo "Файл не знайдено: $file"
        fi
    done

Конструкція `[[ -f "$file" ]]` перевіряє, чи існує звичайний файл із відповідним шляхом.

### 5.4. Обробка елементів, що містять пробіли

    files=("index.html" "main styles.css" "my script.js")

    for file in "${files[@]}"; do
        printf 'Обробляємо файл: %s\n' "$file"
    done

Завдяки `"${files[@]}"` кожне ім’я залишається одним елементом.

Не використовуй:

    for file in ${files[@]}; do
        echo "$file"
    done

Без подвійних лапок Bash може розбивати значення за пробілами та виконувати розкриття шаблонів імен файлів. Це може пошкодити обробку даних.

## 6. Передавання масиву в функції

### 6.1. Основна проблема

У Bash звичайні позиційні параметри функції — `$1`, `$2` тощо — не перетворюють автоматично переданий список на окремий масив.

Наприклад:

    print_items() {
        printf '%s\n' "$@"
    }

    items=("HTML" "CSS" "JavaScript")

    print_items "${items[@]}"

У цьому випадку кожен елемент передається функції як окремий аргумент.

`"$@"` усередині функції представляє всі передані аргументи окремо.

### 6.2. Функція, яка приймає кілька аргументів

    print_items() {
        local item

        for item in "$@"; do
            printf '%s\n' "$item"
        done
    }

    items=("HTML" "CSS" "JavaScript")

    print_items "${items[@]}"

Результат:

    HTML
    CSS
    JavaScript

### 6.3. Передавання масиву разом з іншими параметрами

Припустимо, функція повинна отримати ім’я користувача та список його навичок.

    print_skills() {
        local username="$1"
        shift

        printf 'Користувач: %s\n' "$username"
        printf 'Навички:\n'

        local skill

        for skill in "$@"; do
            printf -- '- %s\n' "$skill"
        done
    }

    skills=("HTML" "CSS" "JavaScript")

    print_skills "Valeriy" "${skills[@]}"

Тут:

- `$1` — ім’я користувача.
- `shift` видаляє перший позиційний параметр зі списку аргументів функції.
- Після `shift` у `$@` залишаються передані навички.

### 6.4. Важливе обмеження

Не передавай масив як звичайний рядок, якщо потрібно зберегти межі його елементів.

    items=("one two" "three")

    # Правильно:
    some_function "${items[@]}"

    # Небажано:
    some_function "${items[*]}"

У другому випадку всі елементи передаються як один об’єднаний аргумент.

## 7. Масиви та аргументи командного рядка

### 7.1. Збереження аргументів скрипту в масиві

У Bash `$@` представляє аргументи, передані скрипту.

Щоб зберегти їх в індексованому масиві:

    #!/usr/bin/env bash

    args=("$@")

    printf 'Кількість аргументів: %s\n' "${#args[@]}"

    for arg in "${args[@]}"; do
        printf 'Аргумент: %s\n' "$arg"
    done

Приклад запуску:

    bash script.sh one "two words" three

Результат:

    Кількість аргументів: 3
    Аргумент: one
    Аргумент: two words
    Аргумент: three

Кожен аргумент зберігається окремо.

### 7.2. Передавання аргументів іншій команді

Масив корисний для формування списку параметрів команди.

    options=("-l" "-h")

    ls "${options[@]}"

Тут параметри `-l` і `-h` передаються команді `ls` окремо.

### 7.3. Динамічне формування параметрів

    options=()

    if [[ -n "${SHOW_HIDDEN:-}" ]]; then
        options+=("-a")
    fi

    options+=("-l")

    ls "${options[@]}"

Якщо `SHOW_HIDDEN` непорожня, команда отримає параметри `-a` та `-l`.

Вираз `${SHOW_HIDDEN:-}` повертає значення змінної, якщо вона встановлена й непорожня, або порожній рядок в іншому випадку.

Використовуй масиви замість складання команди в один рядок, коли параметри потрібно передавати окремими аргументами.

## 8. Асоціативні масиви

Асоціативний масив зберігає значення за текстовими ключами, а не за числовими індексами.

Для асоціативних масивів потрібен Bash 4 або новіший.

### 8.1. Створення асоціативного масиву

Спочатку оголошують тип масиву через `declare -A`.

    declare -A user

    user[name]="Valeriy"
    user[city]="Vinnytsia"
    user[role]="developer"

    echo "${user[name]}"
    echo "${user[city]}"
    echo "${user[role]}"

Результат:

    Valeriy
    Vinnytsia
    developer

Для простих прикладів ключі записані без пробілів. Якщо ключі містять пробіли або спеціальні символи, використовуй лапки.

    declare -A settings

    settings["project name"]="Linux practice"
    settings["editor"]="VS Code"

    echo "${settings["project name"]}"

### 8.2. Ініціалізація асоціативного масиву

    declare -A user=(
        [name]="Valeriy"
        [city]="Vinnytsia"
        [role]="developer"
    )

    printf 'Ім’я: %s\n' "${user[name]}"
    printf 'Місто: %s\n' "${user[city]}"
    printf 'Роль: %s\n' "${user[role]}"

Використовуй `declare -A` для явного оголошення асоціативного масиву.

### 8.3. Отримання всіх значень

    declare -A ports=(
        [http]=80
        [https]=443
        [ssh]=22
    )

    for service in "${!ports[@]}"; do
        printf '%s: %s\n' "$service" "${ports[$service]}"
    done

Тут `${!ports[@]}` повертає ключі асоціативного масиву.

Порядок обходу асоціативного масиву не слід вважати гарантованим.

### 8.4. Перевірка наявності ключа

Щоб перевірити, чи існує ключ, можна використати конструкцію `[[ -v array[key] ]]`.

    declare -A user=(
        [name]="Valeriy"
        [role]="developer"
    )

    if [[ -v user[name] ]]; then
        echo "Ключ name існує"
    fi

    if [[ -v user[email] ]]; then
        echo "Ключ email існує"
    else
        echo "Ключ email відсутній"
    fi

Підтримка `[[ -v ... ]]` залежить від версії Bash. Для навчання та сучасних Bash-скриптів це корисний спосіб перевірки.

### 8.5. Зміна та видалення значення

    declare -A user=(
        [name]="Valeriy"
        [role]="student"
    )

    user[role]="developer"

    unset 'user[name]'

    declare -p user

Присвоєння змінює значення за ключем, а `unset` видаляє конкретний елемент.

## 9. Перевірка масивів

### 9.1. Перевірка кількості елементів

    files=("index.html" "styles.css" "script.js")

    if (( ${#files[@]} > 0 )); then
        echo "Масив містить елементи"
    else
        echo "Масив порожній"
    fi

Усередині арифметичного контексту Bash використовують `(( ... ))`.

### 9.2. Перевірка наявності значення

Для простого масиву можна пройтися по елементах і порівняти кожен із потрібним значенням.

    contains() {
        local target="$1"
        shift

        local item

        for item in "$@"; do
            if [[ "$item" == "$target" ]]; then
                return 0
            fi
        done

        return 1
    }

    colors=("red" "green" "blue")

    if contains "green" "${colors[@]}"; then
        echo "Значення знайдено"
    else
        echo "Значення не знайдено"
    fi

У Bash код завершення `0` означає успіх, а ненульовий код — невдачу.

### 9.3. Перевірка існування індексу

    numbers=([0]=10 [5]=60)

    if [[ -v numbers[5] ]]; then
        echo "Індекс 5 існує"
    fi

    if [[ -v numbers[2] ]]; then
        echo "Індекс 2 існує"
    else
        echo "Індекс 2 відсутній"
    fi

Не перевіряй існування елемента лише за його значенням: порожній рядок теж може бути значенням наявного елемента.

## 10. Сортування масивів

Bash не має універсальної вбудованої команди сортування масиву. Для простих задач можна використати зовнішню команду `sort`.

### 10.1. Сортування текстових значень

    fruits=("orange" "apple" "banana")

    mapfile -t sorted_fruits < <(
        printf '%s\n' "${fruits[@]}" | sort
    )

    printf '%s\n' "${sorted_fruits[@]}"

Результат:

    apple
    banana
    orange

`mapfile -t` читає рядки зі стандартного вводу в масив, прибираючи символ нового рядка наприкінці кожного рядка.

Процесна підстановка `< <(...)` передає результат команди `printf ... | sort` у `mapfile`.

Цей спосіб зручний для рядкових значень, які не містять символів нового рядка всередині одного елемента.

### 10.2. Числове сортування

    numbers=(30 5 100 12)

    mapfile -t sorted_numbers < <(
        printf '%s\n' "${numbers[@]}" | sort -n
    )

    printf '%s\n' "${sorted_numbers[@]}"

Результат:

    5
    12
    30
    100

Параметр `-n` вмикає числове сортування.

### 10.3. Зворотне сортування

    mapfile -t sorted_numbers < <(
        printf '%s\n' "${numbers[@]}" | sort -nr
    )

Параметр `-r` змінює порядок сортування на зворотний.

## 11. Масиви та цикли `while`

Для послідовної обробки масиву можна використовувати `while`, але важливо правильно керувати індексом.

    fruits=("apple" "banana" "orange")

    index=0

    while (( index < ${#fruits[@]} )); do
        printf '%s\n' "${fruits[index]}"
        ((index += 1))
    done

Такий приклад працює для щільного масиву з послідовними індексами від `0`.

Для масиву з пропущеними індексами краще перебирати фактичні індекси:

    numbers=([0]=10 [3]=40 [7]=80)

    for index in "${!numbers[@]}"; do
        printf '%s: %s\n' "$index" "${numbers[$index]}"
    done

У більшості випадків `for item in "${array[@]}"` простіший і безпечніший для звичайного перебору.

## 12. Масиви в реальних Bash-скриптах

### 12.1. Список каталогів для перевірки

    #!/usr/bin/env bash

    directories=(
        "$HOME/projects"
        "$HOME/Documents"
        "$HOME/Downloads"
    )

    for directory in "${directories[@]}"; do
        if [[ -d "$directory" ]]; then
            printf 'Існує: %s\n' "$directory"
        else
            printf 'Відсутній: %s\n' "$directory"
        fi
    done

Масив дозволяє зберігати список шляхів, не створюючи окрему змінну для кожного каталогу.

### 12.2. Список команд для перевірки

    #!/usr/bin/env bash

    commands=("bash" "git" "node" "npm" "psql")

    for command_name in "${commands[@]}"; do
        if command -v "$command_name" >/dev/null 2>&1; then
            printf 'Встановлено: %s\n' "$command_name"
        else
            printf 'Не знайдено: %s\n' "$command_name"
        fi
    done

`command -v` перевіряє, чи доступна команда в поточному середовищі.

Перенаправлення `>/dev/null 2>&1` приховує її стандартний вивід і повідомлення про помилки.

### 12.3. Динамічний список файлів

    #!/usr/bin/env bash

    files=()

    for file in ./*.txt; do
        if [[ -f "$file" ]]; then
            files+=("$file")
        fi
    done

    printf 'Знайдено файлів: %s\n' "${#files[@]}"

    for file in "${files[@]}"; do
        printf '%s\n' "$file"
    done

У Bash шаблон `./*.txt` зазвичай розкривається в список відповідних шляхів.

Якщо збігів немає, шаблон може залишитися нерозкритим. Тому перевірка `[[ -f "$file" ]]` допомагає не додати цей шаблон до масиву як звичайний файл.

### 12.4. Передавання параметрів команді `find`

Масив також зручний для зберігання аргументів:

    find_options=(
        "."
        "-type"
        "f"
        "-name"
        "*.js"
    )

    find "${find_options[@]}"

Команда отримає кожен елемент масиву як окремий аргумент.

Однак не потрібно механічно записувати в масив усі частини кожної команди. Використовуй його там, де список параметрів формується динамічно або має бути збережений для повторного використання.

## 13. Важливі особливості Bash-масивів

### 13.1. Масиви — не рядки

Масив:

    files=("index.html" "main styles.css")

Рядок:

    files="index.html main styles.css"

У першому випадку є два окремі елементи.

У другому — одна змінна-рядок, яка містить текст із пробілами.

Не перетворюй масив на рядок і назад через `echo`, якщо потрібно надійно зберегти межі елементів.

### 13.2. Завжди використовуй подвійні лапки

Рекомендований запис:

    for item in "${items[@]}"; do
        printf '%s\n' "$item"
    done

Небажаний запис:

    for item in ${items[@]}; do
        printf '%s\n' "$item"
    done

Подвійні лапки зберігають кожен елемент окремим аргументом, зокрема коли він містить пробіли або символи шаблонів.

### 13.3. Масиви не передаються дочірнім процесам як масиви

Звичайні змінні масивів Bash не експортуються як повноцінні масиви через `export`.

Якщо потрібно передати список іншому процесу, зазвичай використовують окремі аргументи команди, файл або інший формат обміну даними.

### 13.4. Масиви та `read`

Для читання рядка в масив можна використати `read -a`.

    read -r -a words <<< "Bash arrays are useful"

    printf '%s\n' "${words[@]}"

Результат:

    Bash
    arrays
    are
    useful

`read -a` розділяє рядок за символами `IFS`, тому це не універсальний спосіб розбору довільних форматів із пробілами в полях.

Для складніших форматів потрібен відповідний парсер.

### 13.5. Читання файлу в масив

Для читання файлу, в якому кожен рядок має стати окремим елементом масиву, можна використати `mapfile`.

    mapfile -t lines < "data.txt"

    printf 'Рядків: %s\n' "${#lines[@]}"

    for line in "${lines[@]}"; do
        printf '%s\n' "$line"
    done

`-t` видаляє завершальний символ нового рядка з кожного прочитаного рядка.

Важливо: цей спосіб зберігає порожні рядки, але не призначений для довільних бінарних даних або збереження байтів у всіх можливих випадках.

### 13.6. Сумісність версій Bash

Індексовані масиви доступні в Bash давно. Асоціативні масиви через `declare -A` з’явилися в Bash 4.

Перевірити версію:

    bash --version

Поточну версію Bash у скрипті можна отримати так:

    printf '%s\n' "$BASH_VERSION"

Якщо скрипт має працювати в старих середовищах, перевіряй сумісність потрібних можливостей.

## 14. Типові помилки

### Помилка 1. Забули подвійні лапки

    files=("index.html" "main styles.css")

    for file in ${files[@]}; do
        echo "$file"
    done

Проблема: елемент `main styles.css` може розбитися на два слова.

Правильно:

    for file in "${files[@]}"; do
        echo "$file"
    done

### Помилка 2. Використали `$array` замість `${array[@]}`

    colors=("red" "green" "blue")

    echo "$colors"

Проблема: зазвичай виводиться лише перший елемент.

Правильно:

    printf '%s\n' "${colors[@]}"

### Помилка 3. Очікують автоматичного перенумерування

    numbers=([0]=10 [5]=60)

    unset 'numbers[0]'

    echo "${!numbers[@]}"

Проблема: індекс `5` не змінюється на `0`.

У Bash видалення елемента не перенумеровує решту елементів автоматично.

### Помилка 4. Застосували коми як роздільники

    numbers=(10, 20, 30)

Проблема: коми залишаються частиною значень.

Правильно:

    numbers=(10 20 30)

### Помилка 5. Спробували використовувати асоціативний масив без оголошення

    user[name]="Valeriy"

Для надійного оголошення асоціативного масиву використовуй:

    declare -A user
    user[name]="Valeriy"

Без `declare -A` Bash може трактувати змінну як індексований масив, що призведе до іншої поведінки.

### Помилка 6. Втратили межі елементів під час передавання функції

    items=("one two" "three")

    print_items "${items[*]}"

Проблема: функція отримає один об’єднаний аргумент.

Правильно:

    print_items "${items[@]}"

### Помилка 7. Припустили, що індекси завжди послідовні

    numbers=([0]=10 [3]=40 [7]=80)

    for ((i = 0; i < ${#numbers[@]}; i++)); do
        echo "${numbers[i]}"
    done

Проблема: кількість елементів дорівнює `3`, але індекси `1` і `2` відсутні, а елемент з індексом `7` не буде оброблений цим циклом.

Правильно:

    for i in "${!numbers[@]}"; do
        printf '%s\n' "${numbers[$i]}"
    done

### Помилка 8. Очікували гарантованого порядку асоціативного масиву

    declare -A ports=(
        [http]=80
        [https]=443
        [ssh]=22
    )

Порядок перебору ключів не гарантований. Якщо важливий визначений порядок, використовуй окремий індексований масив ключів.

## 15. Налагодження Bash-скриптів із масивами

### 15.1. Перевірка синтаксису

    bash -n script.sh

Команда перевіряє синтаксис, не виконуючи скрипт.

### 15.2. Покроковий вивід команд

    bash -x script.sh

Параметр `-x` показує виконувані команди та розкриті значення змінних.

Це допомагає зрозуміти, які аргументи фактично передаються в цикли та команди.

### 15.3. Виведення структури масиву

    declare -p files

Наприклад:

    declare -a files=([0]="index.html" [1]="main styles.css")

Для асоціативного масиву:

    declare -p user

Це один із найзручніших способів перевірити вміст масиву під час розробки.

### 15.4. Перевірка стилю та типових проблем

    shellcheck script.sh

ShellCheck може виявляти багато помилок Bash-скриптів, зокрема проблеми з лапками, розкриттям змінних і сумісністю.

## 18. Що потрібно запам’ятати

✔ Індексований масив створюється, наприклад, так: `items=("one" "two" "three")`.

✔ Доступ до елемента: `${items[0]}`.

✔ Отримання всіх елементів: `"${items[@]}"`.

✔ Кількість елементів: `${#items[@]}`.

✔ Фактично наявні індекси: `${!items[@]}`.

✔ Додавання елемента: `items+=("four")`.

✔ Зміна елемента: `items[1]="new value"`.

✔ Видалення елемента: `unset 'items[1]'`.

✔ Перебір елементів: `for item in "${items[@]}"; do ...; done`.

✔ Асоціативний масив оголошується через `declare -A`.

✔ `mapfile -t` дозволяє читати рядки файлу в масив.

✔ Подвійні лапки допомагають зберегти межі елементів.

✔ Для масивів із пропущеними індексами перебирай `${!array[@]}`, а не просто числа від `0` до кількості елементів мінус один.

## 20. Підсумок

Масиви в Bash потрібні для зберігання та обробки списків даних. Вони особливо корисні в автоматизації: під час перевірки файлів і каталогів, формування параметрів команд, роботи з аргументами скриптів і збирання результатів виконання команд.

Для впевненої роботи з масивами потрібно вміти:

- створювати індексовані й асоціативні масиви;
- читати, додавати, змінювати та видаляти елементи;
- перебирати значення й індекси;
- передавати елементи у функції та зовнішні команди;
- зберігати межі елементів за допомогою подвійних лапок;
- читати рядки файлів у масив;
- налагоджувати проблеми з індексами та розкриттям змінних.

Головне правило: **для передавання всіх елементів масиву зазвичай використовуй `"${array[@]}"`, а для перебору фактично наявних індексів — `"${!array[@]}"`.**
